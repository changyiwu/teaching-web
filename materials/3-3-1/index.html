3-1 利用提公因式與乘法公式做因式分解

走進蒙德里安的色塊拼板工作室：幾塊紅、藍、黃色塊拼成一個長方形，長和寬就是它的因式。這一節先用除法認識因式與倍式，知道什麼叫因式分解；再學三種分解的方法：提公因式（含先變號再提）、平方差公式、和的平方與差的平方公式。第一章的乘法公式，這一節要倒過來用。

因式與倍式 從乘積讀 因式分解 求係數 公因式 提公因式 變號再提 平方差 整組當 a 和的平方 差的平方

課前暖身漫畫：六塊色塊拼成長方形

小格在工作室的桌上倒出六塊色塊：一塊紅色大正方形（邊長 \(x\)）、三條藍色長條（\(x\) 乘 \(1\)）、兩塊黃色小方塊（\(1\) 乘 \(1\)），合起來的面積是 \(x^2 + 3x + 2\)。阿方試了幾次，終於把它們拼成一個完整的長方形，量出長是 \(x + 2\)、寬是 \(x + 1\)。把一個式子寫成「長 × 寬」，就是這一節要學的因式分解。

重點 1：因式與倍式——用除法看能不能整除

重點整理與敘述

  • 先回想整數：\(16\) 能被 \(2\) 整除，所以 \(2\) 是 \(16\) 的因數、\(16\) 是 \(2\) 的倍數。
  • 多項式也一樣：兩個不為 \(0\) 的多項式 \(A\)、\(B\)，用長除法算 \(A \div B\)。
  • 餘式是 \(0\)（\(A\) 能被 \(B\) 整除）：\(B\) 是 \(A\) 的因式，\(A\) 是 \(B\) 的倍式。
  • 餘式不是 \(0\)：\(B\) 不是 \(A\) 的因式，\(A\) 也不是 \(B\) 的倍式。
  • 例：\(x^2 + 7x + 12\) 除以 \(x + 3\)，商式 \(x + 4\)、餘式 \(0\)，所以 \(x + 3\) 是 \(x^2 + 7x + 12\) 的因式；除以 \(x + 2\)，商式 \(x + 5\)、餘式 \(2\)，所以 \(x + 2\) 不是它的因式。
  • 注意：多項式的整除只看餘式是不是 \(0\)，商式的係數可以是分數，這點和整數不一樣。

形成性評量 (因式與倍式)

Q1. 下列哪一個是 \(2x^2 + 3x - 5\) 的因式？

解析：答案為 D。用長除法：\(2x^2 + 3x - 5\) 除以 \(2x + 5\)，商式 \(x - 1\)、餘式 \(0\)，能整除，所以 \(2x + 5\) 是因式。
A 錯：除以 \(x + 1\)，商式 \(2x + 1\)、餘式 \(-6\)。
B 錯：除以 \(2x - 5\)，商式 \(x + 4\)、餘式 \(15\)。
C 錯：除以 \(x - 5\)，商式 \(2x + 13\)、餘式 \(60\)。

Q2. 判斷 \(x - 2\) 是不是 \(3x^2 - 5x + 4\) 的因式，下列敘述何者正確？

解析：答案為 B。長除法的第一步，商 \(3x\)，\(3x(x - 2) = 3x^2 - 6x\)，相減剩 \(x + 4\)；第二步，商 \(1\)，相減： \[\begin{aligned} & (x + 4) - (x - 2) \\ &= x + 4 - x + 2 = 6 \end{aligned}\] 餘式是 \(6\)，不是 \(0\)，所以 \(x - 2\) 不是因式。
A 錯：餘式不是 \(0\)。
C 錯：減 \((x - 2)\) 時漏了變號，寫成 \(x + 4 - x - 2 = 2\)。
D 錯：商式確實是 \(3x + 1\)，但判斷因式要看餘式是不是 \(0\)，不是看商式。

重點 2：從乘積讀出因式與倍式——A = B × C

重點整理與敘述

KEY POINT・因式與倍式 若多項式 \(A\)、\(B\)、\(C\) 都不為 \(0\)，且 \(A = B \times C\)，則
\(B\)、\(C\) 是 \(A\) 的因式；\(A\) 是 \(B\)、\(C\) 的倍式。
  • 已經寫成乘積時，不必再做除法：乘號兩邊的式子都是因式。
  • 例：\(2x^2 - x - 6 = (2x + 3)(x - 2)\)，所以 \(2x + 3\)、\(x - 2\) 都是 \(2x^2 - x - 6\) 的因式，\(2x^2 - x - 6\) 是它們的倍式。
  • 兩個因式同時變號，乘積不變：\((-2x - 3)(-x + 2)\) 也等於 \(2x^2 - x - 6\)，所以 \(-2x - 3\) 也是因式。
  • 自己是自己的因式：\(A = A \times 1\)，所以 \(A\) 是 \(A\) 的因式，也是 \(A\) 的倍式。
  • 方向別說反：「因式」是小的那一個（乘號兩邊的），「倍式」是乘出來的那一個。

Q3. 已知 \(3x^2 - 7x - 6 = (3x + 2)(x - 3)\)，下列敘述何者正確？

解析：答案為 C。乘號兩邊的 \(3x + 2\)、\(x - 3\) 是因式，乘出來的 \(3x^2 - 7x - 6\) 是倍式。
A 錯：方向說反了，\(3x^2 - 7x - 6\) 是 \(3x + 2\) 的倍式。
B 錯：\(x - 3\) 和 \(3x + 2\) 是並列的兩個因式，彼此沒有倍式關係（\(x - 3\) 除以 \(3x + 2\) 的餘式不是 \(0\)）。
D 錯：因式是 \(x - 3\)，不是 \(x + 3\)；\(3x^2 - 7x - 6\) 除以 \(x + 3\) 的餘式是 \(42\)。

Q4. 已知 \(2x^2 + 5x - 3 = (2x - 1)(x + 3)\)，下列何者不是 \(2x^2 + 5x - 3\) 的因式？

解析：答案為 A。\(2x + 1\) 和因式 \(2x - 1\) 只差一個正負號，不能混用；\(2x^2 + 5x - 3\) 除以 \(2x + 1\)，商式 \(x + 2\)、餘式 \(-5\)，不是因式。
B 是因式：兩個因式同時變號，\((-2x + 1)(-x - 3)\)\({}= 2x^2 + 5x - 3\)。
C 是因式：它就是 \(2x^2 + 5x - 3\) 自己，\(A = A \times 1\)。
D 是因式：理由同 B。

重點 3：因式分解——寫成兩個一次式的乘積

重點整理與敘述

  • 因式分解：把一個二次式寫成兩個一次式的乘積。
  • 乘積展開是反方向：把乘積乘開，寫回一個多項式。
兩個方向 因式分解：\(x^2 + 5x + 4\)\({}\rightarrow (x + 1)(x + 4)\)
乘積展開：\((x + 1)(x + 4)\)\({}\rightarrow x^2 + 5x + 4\)
  • 用除法分解：先判斷某個一次式是不是因式；能整除，就寫成「除式 \(\times\) 商式」。
  • 例：\(6x^2 + 11x + 3\) 除以 \(3x + 1\)，商式 \(2x + 3\)、餘式 \(0\)，所以 \[\begin{aligned} & 6x^2 + 11x + 3 \\ &= (3x + 1)(2x + 3) \end{aligned}\]
  • 分解完就停：寫成乘積就是答案，不要再乘開；乘開又回到原式，等於白做。
  • 等號兩邊都要是乘積才算：\(x^2 + 5x + 4 = x(x + 5) + 4\) 最後還是「加 \(4\)」，不是乘積。

形成性評量 (因式分解)

Q5. 判別 \(3x - 4\) 是不是 \(6x^2 - 5x - 4\) 的因式；若是，將 \(6x^2 - 5x - 4\) 因式分解。下列何者正確？

解析：答案為 B。長除法：商 \(2x\)，\(2x(3x - 4) = 6x^2 - 8x\)，相減剩 \(3x - 4\)；再商 \(1\)，相減餘 \(0\)。能整除，商式是 \(2x + 1\)： \[6x^2 - 5x - 4 = (3x - 4)(2x + 1)\] A 錯：乘開是 \(6x^2 - 11x + 4\)，不是原式。
C 錯：餘式是 \(0\)，\(3x - 4\) 是因式。
D 錯：乘開是 \(6x^2 + 5x - 4\)，\(x\) 項的符號相反。

Q6. 下列哪一個式子是把 \(3x^2 + 2x - 8\) 因式分解？

解析：答案為 C。把一個二次式寫成兩個一次式的乘積，才叫因式分解；C 的右邊是乘積，而且乘開確實等於 \(3x^2 + 2x - 8\)。
A 錯：方向相反，這是把乘積乘開，叫乘積展開。
B 錯：右邊最後還是「減 \(8\)」，整個式子不是乘積。
D 錯：\((3x - 4)(x + 2)\) 乘開是 \(3x^2 + 2x - 8\)，不等於左邊的 \(3x^2 - 2x - 8\)，等式根本不成立。

重點 4：已知一個因式，求未知的係數

重點整理與敘述

  • 題型：已知 \(3x^2 + 7x + 2\) 可以因式分解成 \((3x + 1)(x + m)\)，求 \(m\)。
  • 方法一：用除法。\(3x^2 + 7x + 2\) 能被 \(3x + 1\) 整除，做長除法得到商式 \(x + 2\)，和 \(x + m\) 比較，\(m = 2\)。
  • 方法二：比較係數。把右邊乘開，和左邊的每一項逐項比對： \[\begin{aligned} & (3x + 1)(x + m) \\ &= 3x^2 + (3m + 1)x + m \end{aligned}\] 常數項 \(m = 2\)，再用 \(x\) 項驗算：\(3 \times 2 + 1 = 7\) ✓。
  • 兩種方法答案一樣，挑順手的用；比較係數時，\(x^2\) 項、\(x\) 項、常數項三項都要對得上。
  • 題目有兩個未知數（例如 \(ax^2 + bx + c\) 的 \(a\)、\(b\)）時，直接把已知的乘積乘開，再逐項讀出係數。

形成性評量 (求未知係數)

Q7. 已知多項式 \(4x^2 + 9x - 9\) 可以因式分解成 \((4x - 3)(x + m)\)，則 \(m\) 為多少？

解析：答案為 D。乘開比較係數： \[\begin{aligned} & (4x - 3)(x + m) \\ &= 4x^2 + (4m - 3)x - 3m \end{aligned}\] 常數項 \(-3m = -9\)，得 \(m = 3\)；驗算 \(x\) 項：\(4 \times 3 - 3 = 9\) ✓。
A 錯：\(-3m = -9\) 時漏看了負號。
B 錯：把 \(x\) 項寫成 \(4m + 3 = 9\)，常數 \(-3\) 的負號弄丟了。
C 錯：\(4m - 3 = 9\) 得到 \(4m = 12\) 後，忘了再除以 \(4\)。

Q8. 已知多項式 \(ax^2 + bx - 10\) 可以因式分解成 \((2x + 5)(x - 2)\)，則 \(a + b\) 為多少？

解析：答案為 A。把右邊乘開： \[\begin{aligned} & (2x + 5)(x - 2) \\ &= 2x^2 - 4x + 5x - 10 \\ &= 2x^2 + x - 10 \end{aligned}\] 所以 \(a = 2\)、\(b = 1\)，\(a + b = 3\)。
B 錯：把 \(5\) 和 \(-2\) 直接相加當成 \(b = 3\)，那不是乘開。
C 錯：\(5x\) 的符號弄錯，算成 \(b = -4 - 5 = -9\)。
D 錯：漏了 \(5 \times x = 5x\) 這一項，只算到 \(b = -4\)。

重點 5：公因式——兩個式子共同的因式

重點整理與敘述

KEY POINT・公因式 若多項式 \(A\)、\(B\)、\(C\) 都不為 \(0\)，且 \(C\) 同時是 \(A\) 和 \(B\) 的因式，
則 \(C\) 是 \(A\) 和 \(B\) 的公因式。
  • 先拆成乘法：\(-4x^2 = (-1) \cdot 2 \cdot 2 \cdot x \cdot x\)、\(6x = 2 \cdot 3 \cdot x\)，兩邊都有的是 \(2\) 和 \(x\)。
  • 所以 \(x\)、\(2x\)、\(-x\)、\(-2x\) 都是 \(-4x^2\) 和 \(6x\) 的公因式；把共同的積木全部乘起來的 \(2x\) 是最大的。
  • 公因式也可以是多項式：\((x + 1)(x - 3)\) 和 \((x - 3)^2\) 都有 \(x - 3\)，\(x - 3\) 就是它們的公因式。
  • 平方要拆成兩個：\((x - 3)^2 = (x - 3)(x - 3)\)，但另一個式子只有一個 \(x - 3\)，所以公因式只有一個 \(x - 3\)，不是 \((x - 3)^2\)。
  • 公因式的係數可以是正的，也可以是負的。

形成性評量 (公因式)

Q9. 下列何者不是 \(8x^2\) 和 \(-12x^3\) 的公因式？

解析：答案為 C。\(8x^2\) 只有兩個 \(x\)，\(x^3\) 有三個 \(x\)，\(8x^2\) 除以 \(x^3\) 除不盡，所以 \(x^3\) 不是 \(8x^2\) 的因式，更不是公因式。
A 是：\(8x^2 = 4x^2 \cdot 2\)，\(-12x^3 = 4x^2 \cdot (-3x)\)。
B 是：\(8x^2 = (-2x)(-4x)\)，\(-12x^3 = (-2x)(6x^2)\)。
D 是：\(8x^2 = 4 \cdot 2x^2\)，\(-12x^3 = 4 \cdot (-3x^3)\)。

Q10. 下列何者是 \((x + 2)(3x - 1)\) 和 \((3x - 1)^2\) 的公因式？

解析：答案為 B。拆成積木：\((x + 2)(3x - 1)\) 有一個 \(3x - 1\)，\((3x - 1)^2 = (3x - 1)(3x - 1)\) 有兩個，共同的只有一個 \(3x - 1\)。
A 錯：\((3x - 1)^2\) 裡沒有 \(x + 2\)。
C 錯：\((x + 2)(3x - 1)\) 只有一個 \(3x - 1\)，不能被 \((3x - 1)^2\) 整除。
D 錯：\((3x - 1)^2\) 裡沒有 \(x + 2\)。

重點 6：提公因式——分配律倒過來用

重點整理與敘述

提公因式 \(A \cdot B + A \cdot C \xrightarrow{\text{因式分解}} A(B + C)\)
  • 步驟：找出每一項都有的公因式，把每一項寫成「公因式 × 剩下的」，再把公因式提到括號外。
  • 例：\(6x^2 + 9x\)\({}= 3x \cdot 2x + 3x \cdot 3\)\({}= 3x(2x + 3)\)。
  • 通常提出最大的公因式：只提 \(x\) 寫成 \(x(6x + 9)\) 也對，但括號裡還有公因數 \(3\)，要再提出來才乾淨。
  • 整項提出時留下 \(1\)，不是 \(0\)：\(4x^2 - x\)\({}= x \cdot 4x - x \cdot 1\)\({}= x(4x - 1)\)，不是 \(x(4x - 0)\)。
  • 公因式可以是多項式：把整個括號當成一塊，例如 \[\begin{aligned} & 3(x + 2)^2 - (x + 2) \\ &= (x + 2)[3(x + 2) - 1] \\ &= (x + 2)(3x + 5) \end{aligned}\]

形成性評量 (提公因式)

Q11. 將 \(9x^2 - x\) 因式分解，下列何者正確？

解析：答案為 C。兩項的公因式是 \(x\)：\(9x^2 = x \cdot 9x\)，\(x = x \cdot 1\)，所以 \(9x^2 - x = x(9x - 1)\)。
A 錯：\(x\) 整項被提走後留下的是 \(1\)，不是 \(0\)；\(x(9x - 0) = 9x^2\)。
B 錯：\(9\) 不是第二項 \(x\) 的因數；\(9x(x - 1) = 9x^2 - 9x\)。
D 錯：\(-x(9x + 1) = -9x^2 - x\)，第一項的符號不對。

Q12. 將 \(2(2x - 1)^2 + 3(2x - 1)\) 因式分解，下列何者正確？

解析：答案為 D。把整個 \((2x - 1)\) 當公因式提出來： \[\begin{aligned} & 2(2x - 1)^2 + 3(2x - 1) \\ &= (2x - 1)[2(2x - 1) + 3] \\ &= (2x - 1)(4x - 2 + 3) \\ &= (2x - 1)(4x + 1) \end{aligned}\] A 錯：\(2(2x - 1)\) 只乘到 \(2x\)，寫成 \(4x - 1\)，再加 \(3\) 變成 \(4x + 2\)。
B 錯：提出後忘了第一項還有係數 \(2\)，寫成 \((2x - 1) + 3\)。
C 錯：\(2 \times (-1)\) 算成 \(+2\)，得到 \(4x + 2 + 3\)。

重點 7：先變號，再提公因式

重點整理與敘述

  • 有些式子乍看沒有公因式，因為兩項的括號只差一個正負號，像 \(x - 4\) 和 \(4 - x\)。
變號的兩條規則 \(a - x = -(x - a)\)　　\((a - x)^2 = (x - a)^2\)
  • 一次方：括號裡兩項都變號，括號前要多一個負號，所以前面的加減號要反過來。
  • 例： \[\begin{aligned} & (2x + 3)(x - 4) \\ & \quad - (4 - x)(x + 1) \\ &= (x - 4)(2x + 3) \\ & \quad + (x - 4)(x + 1) \\ &= (x - 4)[(2x + 3) + (x + 1)] \\ &= (x - 4)(3x + 4) \end{aligned}\]
  • 平方：平方之後負號不見，\((1 - x)^2\) 直接換成 \((x - 1)^2\)，前面的加減號不變。
  • 例： \[\begin{aligned} & (x - 1)(4x + 3) - (1 - x)^2 \\ &= (x - 1)(4x + 3) - (x - 1)^2 \\ &= (x - 1)[(4x + 3) - (x - 1)] \\ &= (x - 1)(3x + 4) \end{aligned}\]
  • 注意：三次方就不一樣了，\((a - x)^3 = -(x - a)^3\)，負號會留下來。

Q13. 將 \((x - 6)(3x + 1) + (6 - x)(x - 4)\) 因式分解，下列何者正確？

解析：答案為 B。\(6 - x = -(x - 6)\)，所以「\(+\)」要變成「\(-\)」： \[\begin{aligned} & (x - 6)(3x + 1) - (x - 6)(x - 4) \\ &= (x - 6)[(3x + 1) - (x - 4)] \\ &= (x - 6)(2x + 5) \end{aligned}\] A 錯：沒有變號，直接寫成 \((3x + 1) + (x - 4) = 4x - 3\)。
C 錯：變號了，但 \(-(x - 4)\) 去括號寫成 \(-x - 4\)，得到 \(2x - 3\)。
D 錯：\((6 - x)(2x + 5)\)\({}= -(x - 6)(2x + 5)\)，整個差了一個負號。

Q14. 將 \((2x + 3)(x - 7) - (7 - x)^2\) 因式分解，下列何者正確？

解析：答案為 A。平方之後負號不見：\((7 - x)^2 = (x - 7)^2\)，前面的「\(-\)」不變： \[\begin{aligned} & (x - 7)(2x + 3) - (x - 7)^2 \\ &= (x - 7)[(2x + 3) - (x - 7)] \\ &= (x - 7)(x + 10) \end{aligned}\] B 錯：把 \((7 - x)^2\) 當成 \(-(x - 7)^2\)，前面的號反過來，得到 \((2x + 3) + (x - 7) = 3x - 4\)。
C 錯：\(-(x - 7)\) 去括號寫成 \(-x - 7\)，得到 \(x - 4\)。
D 錯：\((7 - x)(x + 10)\)\({}= -(x - 7)(x + 10)\)，差了一個負號。

重點 8：平方差公式——a² − b² = (a + b)(a − b)

重點整理與敘述

  • 第一章的乘法公式 \((a + b)(a - b) = a^2 - b^2\)，等號兩邊對調，右邊就是左邊的因式分解。
平方差公式 \(a^2 - b^2 = (a + b)(a - b)\)
  • 先寫成「誰的平方減誰的平方」，再看 \(a\)、\(b\) 各是什麼。\(a\)、\(b\) 可以是數字，也可以是含文字的式子。
  • 例：\(x^2 - 49\)\({}= x^2 - 7^2\)\({}= (x + 7)(x - 7)\)。
  • 例：\(9x^2 - 4y^2\)\({}= (3x)^2 - (2y)^2\)\({}= (3x + 2y)(3x - 2y)\)，係數也要開平方。
  • 順序不要弄反：\(16 - x^2\)\({}= 4^2 - x^2\)\({}= (4 + x)(4 - x)\)，這裡 \(a = 4\)、\(b = x\)。
  • 中間一定是減號：\(x^2 + 49\) 是兩個平方「相加」，不能用平方差公式。

Q15. 將 \(64x^2 - 49y^2\) 因式分解，下列何者正確？

解析：答案為 C。\(64x^2 - 49y^2 = (8x)^2 - (7y)^2\)，\(a = 8x\)、\(b = 7y\)： \[\begin{aligned} & 64x^2 - 49y^2 \\ &= (8x + 7y)(8x - 7y) \end{aligned}\] A 錯：\((8x - 7y)^2\)\({}= 64x^2 - 112xy + 49y^2\)，多了中間項。
B 錯：係數沒有開平方；乘開是 \(4096x^2 - 2401y^2\)。
D 錯：\((8x + 7y)^2\)\({}= 64x^2 + 112xy + 49y^2\)，而且中間是加號。

Q16. 將 \(121 - 25x^2\) 因式分解，下列何者正確？

解析：答案為 D。\(121 - 25x^2 = 11^2 - (5x)^2\)，這次 \(a = 11\)、\(b = 5x\)： \[\begin{aligned} & 121 - 25x^2 \\ &= (11 + 5x)(11 - 5x) \end{aligned}\] A 錯：\(a\)、\(b\) 弄反了；\((5x + 11)(5x - 11)\)\({}= 25x^2 - 121\)，和原式差一個負號。
B 錯：\((11 - 5x)^2\) 乘開會多出中間項 \(-110x\)。
C 錯：沒有開平方。

重點 9：平方差公式——整組括號當成一個 a

重點整理與敘述

  • 平方差公式的 \(a\)、\(b\) 可以是一整組括號。先把括號整組看成一塊，套公式，最後才去括號合併。
  • 例：\((x + 2)^2 - 25\)，把 \((x + 2)\) 看成 \(a\)、\(5\) 看成 \(b\)： \[\begin{aligned} & (x + 2)^2 - 5^2 \\ &= [(x + 2) + 5][(x + 2) - 5] \\ &= (x + 7)(x - 3) \end{aligned}\]
  • 數字在前時，減的是一整組：\(9 - (x + 4)^2\) 的 \(a = 3\)、\(b = (x + 4)\)， \[\begin{aligned} & 3^2 - (x + 4)^2 \\ &= [3 + (x + 4)][3 - (x + 4)] \\ &= (x + 7)(3 - x - 4) \\ &= (x + 7)(-x - 1) \end{aligned}\] 第二個括號裡的 \(x\) 和 \(4\) 都要變號。也可以把負號提到最前面，寫成 \(-(x + 7)(x + 1)\)。
  • 先寫方括號，再去括號：一下子就去掉括號，最容易漏變號。

Q17. 將 \((3x - 2)^2 - 36\) 因式分解，下列何者正確？

解析：答案為 A。\((3x - 2)\) 整組看成 \(a\)，\(36 = 6^2\)： \[\begin{aligned} & (3x - 2)^2 - 6^2 \\ &= [(3x - 2) + 6][(3x - 2) - 6] \\ &= (3x + 4)(3x - 8) \end{aligned}\] B 錯：\(36\) 沒有寫成 \(6^2\)，直接把 \(36\) 當成 \(b\)。
C 錯：漏掉了括號裡的 \(-2\)，算的是 \((3x)^2 - 36\)。
D 錯：把 \(-2\) 看成 \(+2\)，算的是 \((3x + 2)^2 - 36\)。

Q18. 將 \(36 - (3x + 1)^2\) 因式分解，下列何者正確？

解析：答案為 B。\(a = 6\)、\(b = (3x + 1)\)： \[\begin{aligned} & 6^2 - (3x + 1)^2 \\ &= [6 + (3x + 1)][6 - (3x + 1)] \\ &= (3x + 7)(6 - 3x - 1) \\ &= (3x + 7)(5 - 3x) \end{aligned}\] A 錯：減一整組時只變了 \(3x\) 的號，寫成 \(6 - 3x + 1 = 7 - 3x\)。
C 錯：把 \(+1\) 看成 \(-1\)，算的是 \(36 - (3x - 1)^2\)。
D 錯：漏掉了括號裡的 \(+1\)。

重點 10：和的平方公式——拼成一個正方形

重點整理與敘述

和的平方公式 \(a^2 + 2ab + b^2 = (a + b)^2\)
  • 三個條件都要成立：首項是某個式子 \(a\) 的平方、末項是某個數 \(b\) 的平方、中間項剛好是 \(2ab\)，而且是正的。
  • 例：\(x^2 + 10x + 25\)\({}= x^2 + 2 \cdot x \cdot 5 + 5^2\)\({}= (x + 5)^2\)。
  • 例：\(9x^2 + 30x + 25\)\({}= (3x)^2 + 2 \cdot 3x \cdot 5 + 5^2\)\({}= (3x + 5)^2\)，首項的係數也要開平方。
  • 中間項不是 \(2ab\) 就不行：\(x^2 + 5x + 25\) 的首末項都是平方，但 \(2 \cdot x \cdot 5 = 10x\)，不是 \(5x\)，不能用這個公式。
  • 用色塊看：\(a^2\) 是大正方形、\(2ab\) 是兩條長方形、\(b^2\) 是小正方形，長條的數量剛好時，四塊才拼得成一個大正方形。

Q19. 將 \(81x^2 + 36x + 4\) 因式分解，下列何者正確？

解析：答案為 A。首項 \((9x)^2\)、末項 \(2^2\)，中間項 \(2 \cdot 9x \cdot 2 = 36x\) ✓： \[81x^2 + 36x + 4 = (9x + 2)^2\] B 錯：末項 \(4\) 沒有開平方；\((9x + 4)^2 = 81x^2 + 72x + 16\)。
C 錯：首項的係數 \(81\) 沒有開平方。
D 錯：中間項是正的，是和的平方；\((9x - 2)^2\) 的中間項是 \(-36x\)。

Q20. 若 \(4x^2 + kx + 49\) 可以利用和的平方公式因式分解，則 \(k\) 為多少？

解析：答案為 D。\(4x^2 = (2x)^2\)、\(49 = 7^2\)，中間項要是 \[2 \cdot 2x \cdot 7 = 28x\] 所以 \(k = 28\)，\(4x^2 + 28x + 49 = (2x + 7)^2\)。
A 錯：只算了 \(2 \times 7\)，漏乘首項的 \(2x\)。
B 錯：把首末兩項的係數相加 \(4 + 49\)，那不是中間項。
C 錯：算成 \(2 \times 49\)，末項要先開平方。

重點 11：差的平方公式——中間項是負的

重點整理與敘述

差的平方公式 \(a^2 - 2ab + b^2 = (a - b)^2\)
  • 和「和的平方」只差中間項的符號：首末項都是平方、而且都是正的，中間項是 \(-2ab\)。
  • 例：\(x^2 - 8x + 16\)\({}= x^2 - 2 \cdot x \cdot 4 + 4^2\)\({}= (x - 4)^2\)。
  • 例：\(4x^2 - 20x + 25\)\({}= (2x)^2 - 2 \cdot 2x \cdot 5 + 5^2\)\({}= (2x - 5)^2\)。
  • 末項一定是正的：\(x^2 - 8x - 16\) 的末項是負的，不是完全平方式。
  • 常見錯誤：\((a - b)^2 \ne a^2 - b^2\)。用面積看：大正方形扣掉兩條 \(ab\) 時，右下角的 \(b^2\) 被扣了兩次，要補回一次。

解析：答案為 C。首項 \((7x)^2\)、末項 \(3^2\)，中間項 \(-2 \cdot 7x \cdot 3 = -42x\) ✓： \[49x^2 - 42x + 9 = (7x - 3)^2\] A 錯：中間項是負的，不是和的平方。
B 錯：\((7x + 3)(7x - 3) = 49x^2 - 9\)，沒有中間項。
D 錯：首末兩項的係數都沒有開平方。

Q22. 下列哪一個式子可以利用差的平方公式因式分解？

C 錯：末項是 \(-9\)，不是某個數的平方。

小節總結與核心回顧

因式分解速查表

  • 因式與倍式：\(A \div B\) 餘式為 \(0\)，\(B\) 是因式、\(A\) 是倍式。
  • 從乘積讀：\(A = B \times C\)，\(B\)、\(C\) 是因式；同時變號也是，自己也是。
  • 因式分解：寫成兩個一次式的乘積就停，不再乘開。
  • 求係數：用除法，或乘開比較係數。
  • 公因式：拆成乘法積木，兩邊都有的乘起來。
  • 提公因式：\(AB + AC = A(B + C)\)，整項提走留下 \(1\)。
  • 變號：\(a - x = -(x - a)\)、\((a - x)^2 = (x - a)^2\)。
  • 平方差：\(a^2 - b^2 = (a + b)(a - b)\)，括號可以整組當 \(a\)。
  • 和的平方：\(a^2 + 2ab + b^2 = (a + b)^2\)。
  • 差的平方：\(a^2 - 2ab + b^2 = (a - b)^2\)。

回到色塊工作室：拼成長方形就是因式分解

長和寬就是因式

一塊 \(x^2\)、三條 \(x\)、兩塊 \(1\)，拼成長 \(x + 2\)、寬 \(x + 1\) 的長方形，面積沒有變：\(x^2 + 3x + 2\)\({}= (x + 1)(x + 2)\)。把一個式子寫成「長 × 寬」，就是因式分解。

拼成正方形就是完全平方式

長條的數量剛好是 \(2ab\) 時，四塊色塊拼得成一個正方形，邊長就是 \(a + b\)；挖掉一角再剪開重拼，則是平方差公式。這一節的三個乘法公式，都可以用色塊拼出來。
