2-2 圓心角、圓周角與弧的關係

單車修理鋪裡，小輪和阿軸繼續跟車輪打交道。輻條從輪軸放射出去，兩根輻條夾出圓心角，也夾出一段輪框——這段弧的度數就等於圓心角。換個位置，站在輪框上看同一段弧，得到的是圓周角，它剛好是弧的一半。這一節從弧的度數出發，學圓周角的各種性質：同弧的圓周角相等、半圓的圓周角是直角、平行弦截出相等的弧，最後是圓內接四邊形的對角互補。

弧的度數 等弧與等弦 圓周角 同弧圓周角 圓心角的一半 弧的加法 半圓直角 平行弦 圓內接四邊形 外角

課前暖身漫畫：兩個反光片轉了一樣多嗎？

阿軸在同一根輻條上夾了兩個反光片，一個靠近輪軸、一個靠近輪框。輪子轉一下，靠近輪軸的那個走得比較少嗎？小輪說：它們跟著同一根輻條轉，轉過的角度一樣，只是外圈走的路比較長——弧的度數等於圓心角，弧長還要看半徑。

重點 1：弧的度數等於圓心角

重點整理與敘述

  • 把圓周分成 \(360\) 等分，每一等分的弧所對的圓心角是 \(1^\circ\)，就說這段弧的度數是 \(1^\circ\)。所以弧的度數 = 它所對圓心角的度數：\(\angle AOB = x^\circ\) 時，記作 \(\overset{\frown}{AB} = x^\circ\)。
  • \(\overset{\frown}{AB}\) 這個記號有三種意思：弧本身、弧的度數、弧的長度，要看前後文分辨。
  • 弧的長度 \(=\) 圓周長 \(\times \frac{x}{360}\)。
  • 同圓或等圓中：度數相同的弧長度也相同；度數較大的弧也比較長。
  • 半徑不同的兩圓（例如同心圓）：同一個圓心角夾出的兩段弧度數相同、長度不同，長度比 \(=\) 半徑比。
  • 例：同心圓的半徑是 \(8\) 與 \(10\)，\(\angle AOB = \angle COD = 150^\circ\)。兩段弧的度數都是 \(150^\circ\)；長度分別是 \[\begin{aligned} &2\pi \times 8 \times \frac{5}{12} = \frac{20}{3}\pi \\ &2\pi \times 10 \times \frac{5}{12} = \frac{25}{3}\pi \end{aligned}\]
KEY POINT・弧的度數 圓上一弧的度數，就是它所對圓心角的度數

形成性評量 (弧的度數與弧長)

Q1. 兩個同心圓的圓心是 \(O\)，半徑分別為 \(15\) 與 \(6\)。\(A\)、\(B\) 在大圓上，\(C\)、\(D\) 在小圓上，且 \(\angle AOB = \angle COD\)。若 \(\overset{\frown}{AB}\) 的長度是 \(9\pi\)，則 \(\overset{\frown}{CD}\) 的長度是多少？

解析：答案為 C。設 \(\angle AOB = x^\circ\)： \[\begin{aligned} &2\pi \times 15 \times \frac{x}{360} = 9\pi \\ &\frac{x}{360} = \frac{3}{10},\ x = 108 \end{aligned}\] \(\angle COD = 108^\circ\)，所以 \[\overset{\frown}{CD} = 2\pi \times 6 \times \frac{3}{10} = \frac{18}{5}\pi\] 也可以用「長度比 \(=\) 半徑比 \(= 6 : 15 = 2 : 5\)」：\(9\pi \times \frac{2}{5} = \frac{18}{5}\pi\)。
A 錯：兩弧的度數相同，但半徑不同，長度不同。
B 錯：比例倒過來了，小圓的弧應該比較短。
D 錯：算弧長時漏乘了 \(2\)。

Q2. 圓 \(O\) 的半徑是 \(14\)，圓周被等分成 \(8\) 段。\(A\)、\(B\) 是其中兩個分點，劣弧 \(\overset{\frown}{AB}\) 恰好包含 \(3\) 段。\(\overset{\frown}{AB}\) 的度數與長度分別是多少？

解析：答案為 A。每一段是 \(360^\circ \div 8 = 45^\circ\)，\(3\) 段是 \(135^\circ\)，占圓周的 \(\frac{3}{8}\)： \[\overset{\frown}{AB} = 2\pi \times 14 \times \frac{3}{8} = \frac{21}{2}\pi\] B 錯：把直徑 \(28\) 當成半徑代入。
C 錯：只算了 \(1\) 段。
D 錯：\(\pi \times 14^2 \times \frac{3}{8}\) 是扇形面積，不是弧長。

重點 2：等弧對等弦、等弦對等弧

重點整理與敘述

  • 同圓中，\(\overset{\frown}{AB} = \overset{\frown}{CD}\)（度數相等）\(\Rightarrow \angle AOB = \angle COD\)，再加上四條半徑等長，\(\triangle AOB \cong \triangle COD\)（SAS），所以 \(\overline{AB} = \overline{CD}\)：等弧對等弦。
  • 反過來，\(\overline{AB} = \overline{CD}\) \(\Rightarrow \triangle AOB \cong \triangle COD\)（SSS）\(\Rightarrow \angle AOB = \angle COD\)，弧也相等：等弦對等弧。
  • 這兩個性質都要在同圓或等圓中才成立：大圓、小圓裡等長的弦，對的弧不一定一樣大。
  • 正 \(n\) 邊形的頂點都在圓上時，\(n\) 條邊是 \(n\) 條等長的弦，把圓周分成 \(n\) 段相等的弧，每段 \(\frac{360^\circ}{n}\)。例：正五邊形 \(ABCDE\) 中，\(\overset{\frown}{ABC} = 360^\circ \times \frac{2}{5} = 144^\circ\)，所以 \(\angle AOC = 144^\circ\)。
  • 兩弦等長時，它們對的弧相等；兩段弧扣掉共同的部分，剩下的也相等。
同圓或等圓中 弧相等 \(\Leftrightarrow\) 圓心角相等 \(\Leftrightarrow\) 弦相等

形成性評量 (等弧與等弦)

Q3. 正十二邊形 \(ABCDEFGHIJKL\) 的頂點都在圓 \(O\) 上。\(\angle AOE\)（小於 \(180^\circ\) 的那一個）是多少度？

解析：答案為 D。\(12\) 條邊等長，等弦對等弧，每段弧是 \(360^\circ \div 12 = 30^\circ\)。從 \(A\) 到 \(E\) 經過 \(AB\)、\(BC\)、\(CD\)、\(DE\) 共 \(4\) 段： \[\begin{aligned} &\angle AOE = \overset{\frown}{ABE} \\ &= 4 \times 30^\circ = 120^\circ \end{aligned}\] A 錯：只算了一段弧。
B 錯：\(A\) 到 \(E\) 有 \(5\) 個字母，但中間只有 \(4\) 條邊。
C 錯：\(60^\circ\) 是對同一段弧的圓周角，不是圓心角。

Q4. \(A\)、\(B\)、\(C\) 是圓上三點，\(\overline{AB} = \overline{AC}\)，且不含 \(A\) 的 \(\overset{\frown}{BC} = 76^\circ\)。不含 \(C\) 的 \(\overset{\frown}{AB}\) 是多少度？

解析：答案為 B。\(\overline{AB} = \overline{AC}\)，等弦對等弧，兩段弧一樣大。三段弧合起來是整個圓： \[\overset{\frown}{AB} = (360^\circ - 76^\circ) \div 2 = 142^\circ\] A 錯：題目只說 \(\overline{AB} = \overline{AC}\)，弦 \(\overline{BC}\) 不一定和它們一樣長。
C 錯：圓周是 \(360^\circ\)，不是 \(180^\circ\)。
D 錯：弧的度數不必除以 \(2\)，除以 \(2\) 的是圓周角。

重點 3：圓周角是所對弧的一半

重點整理與敘述

  • 圓周角：頂點在圓上、兩邊都是弦的角。\(\angle BAC\) 所對的弧，是夾在兩邊之間、不含頂點 \(A\) 的 \(\overset{\frown}{BC}\)。
  • 圓周角的度數 = 所對弧度數的一半：\(\angle BAC = \frac{1}{2}\overset{\frown}{BC}\)。
  • 證明分三種情形：
    • 圓心在一邊上：\(\triangle OAB\) 等腰，\(\angle BOC\) 是外角：\[\begin{aligned} &\angle BOC = \angle A + \angle OBA \\ &= 2\angle A \end{aligned}\]
    • 圓心在角的內部：作直徑 \(\overline{AD}\)，\(\angle BAC = \angle BAD + \angle DAC\)，兩塊各是一半，加起來還是一半。
    • 圓心在角的外部：作直徑 \(\overline{AD}\)，改用兩角相減，結果一樣。
  • 頂點不在圓上的角（圓心、兩弦在圓內的交點、圓外一點）不是圓周角，不能直接取「弧的一半」。
  • 例：\(\overset{\frown}{BC} = 100^\circ\) \(\Rightarrow \angle BAC = 50^\circ\)。
KEY POINT・圓周角 \(\angle BAC = \frac{1}{2}\overset{\frown}{BC}\)（頂點在圓上，弧不含頂點）

形成性評量 (圓周角)

Q5. \(A\)、\(B\)、\(C\) 是圓 \(O\) 上三點，不含 \(A\) 的 \(\overset{\frown}{BC} = 128^\circ\)。\(\angle BAC\) 是多少度？

解析：答案為 A。\(\angle BAC\) 是圓周角，所對的弧就是不含 \(A\) 的 \(\overset{\frown}{BC}\)： \[\angle BAC = \frac{1}{2} \times 128^\circ = 64^\circ\] B 錯：\(128^\circ\) 是圓心角 \(\angle BOC\)，圓周角只有它的一半。
C 錯：\(116^\circ\) 是 \(180^\circ - 64^\circ\)，那是頂點在另一段弧上的圓周角。
D 錯：\((180^\circ - 128^\circ) \div 2 = 26^\circ\) 是等腰 \(\triangle OBC\) 的底角。

Q6. 如圖，\(A\)、\(B\)、\(C\)、\(D\) 在圓上，弦 \(\overline{AC}\) 與 \(\overline{BD}\) 交於圓內一點 \(E\)，\(\angle AEB = 72^\circ\)。下列敘述何者正確？

解析：答案為 B。\(\angle ACB\) 的頂點 \(C\) 在圓上，兩邊 \(\overline{CA}\)、\(\overline{CB}\) 都是弦，是圓周角；它夾住的是不含 \(C\) 的 \(\overset{\frown}{AB}\)。
A 錯：\(E\) 在圓內，不在圓上，\(\angle AEB\) 不是圓周角，不能用「弧的一半」反推。
C 錯：對頂角相等，但 \(E\) 不在圓上，推不出兩段弧相等。
D 錯：\(\overset{\frown}{ACB}\) 經過 \(D\) 自己；\(\angle ADB\) 夾住的是不含 \(D\) 的 \(\overset{\frown}{AB}\)。

重點 4：同弧所對的圓周角相等

重點整理與敘述

  • 一段弧可以有很多個圓周角：\(\angle APB\)、\(\angle AQB\)、\(\angle ARB\) 的頂點都在 \(\overset{\frown}{AB}\) 以外的圓上，都等於 \(\frac{1}{2}\overset{\frown}{AB}\)，所以同弧所對的圓周角相等。
  • 「同弧」是指夾住同一段弧：頂點跑到 \(\overset{\frown}{AB}\) 上時，它夾住的是另一段弧，角度變成 \(180^\circ - \frac{1}{2}\overset{\frown}{AB}\)。
  • 在同圓或等圓中，等弧所對的圓周角也相等。
  • 找相等的圓周角：看兩個角的兩邊是不是通過同樣的兩個端點，而且頂點在這兩點的同一側。
  • 例：\(A\)、\(B\)、\(C\)、\(D\) 在圓上，\(\angle ADC = 44^\circ\)，\(\angle ABC\) 和它都對 \(\overset{\frown}{AC}\)，所以 \(\angle ABC = 44^\circ\)。
KEY POINT・同弧所對的圓周角 同圓中，同弧所對的圓周角度數相等

Q7. 如圖，\(A\)、\(B\)、\(C\)、\(D\) 依序在圓上，\(\overline{AC}\) 與 \(\overline{BD}\) 交於 \(P\)。若 \(\angle BAC = 38^\circ\)、\(\angle ACD = 29^\circ\)，則 \(\angle BPC\) 是多少度？

解析：答案為 C。\(\angle BDC\) 與 \(\angle BAC\) 都對 \(\overset{\frown}{BC}\)，所以 \(\angle BDC = 38^\circ\)。在 \(\triangle PCD\) 中，\(\angle BPC\) 是 \(P\) 的外角： \[\begin{aligned} &\angle BPC = \angle PCD + \angle PDC \\ &= 29^\circ + 38^\circ = 67^\circ \end{aligned}\] A 錯：\(58^\circ = 2 \times 29^\circ\)，把圓周角當成弧再加一次。
B 錯：\(76^\circ\) 是 \(\overset{\frown}{BC}\) 的度數，不是 \(\angle BPC\)。
D 錯：\(113^\circ\) 是 \(\angle CPD\)，和 \(\angle BPC\) 互補。

Q8. 如圖，\(\overline{AC}\) 是圓 \(O\) 的直徑，\(B\)、\(D\) 在圓上，\(\overline{BD}\) 交 \(\overline{AC}\) 於 \(E\)。下列哪一個推理正確？

解析：答案為 D。\(A\)、\(D\) 都在 \(\overset{\frown}{BC}\) 以外的圓上，\(\angle CAB\)、\(\angle CDB\) 夾住同一段 \(\overset{\frown}{BC}\)，同弧所對的圓周角相等。
A 錯：\(E\) 不在圓上，\(\angle AEB\) 不是圓周角，推不出弧相等。
B 錯：\(A\)、\(C\) 在 \(B\)、\(D\) 的兩側，兩角夾住的是不同的兩段弧（合起來是整個圓），兩角互補而不是相等。
C 錯：頂點相同不代表相等，\(\angle ABD\) 對 \(\overset{\frown}{AD}\)、\(\angle CBD\) 對 \(\overset{\frown}{CD}\)。

重點 5：圓周角是圓心角的一半

重點整理與敘述

  • 圓心角 \(=\) 所對的弧，圓周角 \(= \frac{1}{2}\) 所對的弧。對同一段弧時：圓周角 \(= \frac{1}{2}\) 圓心角，圓心角 \(= 2 \times\) 圓周角。
  • 先確認兩個角對的是不是同一段弧。\(\angle AOC = 140^\circ\) 時：
    • 優弧上的 \(B\)：\(\angle ABC\) 對 \(\overset{\frown}{AC}\)，\(\angle ABC = 70^\circ\)。
    • 劣弧上的 \(D\)：\(\angle ADC\) 對優弧 \(\overset{\frown}{ABC} = 360^\circ - 140^\circ = 220^\circ\)，\(\angle ADC = 110^\circ\)。
  • 已知圓周角反求：\(\angle ABC = 24^\circ\) 對 \(\overset{\frown}{AC}\)，那麼 \(\angle AOC = 48^\circ\)。
  • 搭配等腰三角形：\(\overline{OA} = \overline{OC}\)，所以 \(\angle OCA = (180^\circ - \angle AOC) \div 2\)。例：\(\angle ABC = 65^\circ\) 時，\[\begin{aligned} &\angle AOC = 130^\circ \\ &\angle OCA = 25^\circ \end{aligned}\]
對同一段弧 圓周角 \(= \frac{1}{2}\) 圓心角

Q9. 如圖，\(A\)、\(B\)、\(C\)、\(D\) 是圓 \(O\) 上相異四點，\(\angle AOC = 136^\circ\)，\(B\) 在優弧上、\(D\) 在劣弧上。\(\angle ADC\) 是多少度？

解析：答案為 B。\(D\) 在劣弧上，\(\angle ADC\) 夾住的是不含 \(D\) 的優弧 \(\overset{\frown}{ABC}\)： \[\begin{aligned} &\overset{\frown}{ABC} = 360^\circ - 136^\circ = 224^\circ \\ &\angle ADC = \frac{1}{2} \times 224^\circ = 112^\circ \end{aligned}\] A 錯：\(68^\circ\) 是 \(\angle ABC\)，\(B\) 在優弧上才是對 \(\overset{\frown}{AC}\)。
C 錯：圓周角不等於圓心角。
D 錯：\(224^\circ\) 是弧的度數，還沒除以 \(2\)。

Q10. 如圖，\(A\)、\(B\)、\(C\) 在圓 \(O\) 上，\(C\) 在劣弧 \(\overset{\frown}{AB}\) 上，\(\angle ACB = 116^\circ\)。\(\angle OAB\) 是多少度？

解析：答案為 A。\(\angle ACB\) 夾住的是不含 \(C\) 的優弧，這段優弧是 \(2 \times 116^\circ = 232^\circ\)，所以 \[\begin{aligned} &\angle AOB = 360^\circ - 232^\circ = 128^\circ \\ &\angle OAB = (180^\circ - 128^\circ) \div 2 \\ &= 26^\circ \end{aligned}\] B 錯：\(116^\circ \div 2\)，把 \(\angle ACB\) 當成圓心角。
C 錯：\((180^\circ - 116^\circ) \div 2\)，把 \(\angle ACB\) 當成等腰三角形的頂角。
D 錯：\(180^\circ - 116^\circ\)，沒有用到圓心角。

重點 6：把弧加起來求圓周角

重點整理與敘述

  • 圓周角夾住的弧常常由好幾段組成。步驟：① 找出不含頂點的那段弧；② 把各段加起來；③ 除以 \(2\)。
  • 例：\(A\)、\(B\)、\(C\)、\(D\) 依序在圓 \(O\) 上，\(\angle COD = 80^\circ\)、\(\overset{\frown}{AD} = 70^\circ\)。\(\angle ABC\) 夾住 \(\overset{\frown}{ADC}\)： \[\angle ABC = \frac{1}{2}(70^\circ + 80^\circ) = 75^\circ\]
  • 反過來，已知圓周角可以求弧：上例中若 \(\angle DAB = 110^\circ\)，則 \(\overset{\frown}{DCB} = 220^\circ\)，\(\overset{\frown}{BC} = 220^\circ - 80^\circ = 140^\circ\)。
  • 等分點與比例：圓周被 \(n\) 等分時每段 \(\frac{360^\circ}{n}\)；四段弧的比是 \(a : b : c : d\) 時，每段 \(= 360^\circ \times\) 它所占的比例。
三步驟 找不含頂點的弧 → 各段相加 → 除以 2

Q11. 如圖，\(A\)、\(B\)、\(C\)、\(D\) 依序在圓 \(O\) 上，\(\angle COD = 84^\circ\)、\(\overset{\frown}{AD} = 62^\circ\)、\(\angle DAB = 107^\circ\)。不含 \(A\) 的 \(\overset{\frown}{BC}\) 是多少度？

解析：答案為 D。\(\overset{\frown}{CD} = \angle COD = 84^\circ\)。\(\angle DAB\) 夾住不含 \(A\) 的 \(\overset{\frown}{DCB} = \overset{\frown}{CD} + \overset{\frown}{BC}\)： \[\begin{aligned} &\overset{\frown}{DCB} = 2 \times 107^\circ = 214^\circ \\ &\overset{\frown}{BC} = 214^\circ - 84^\circ = 130^\circ \end{aligned}\] A 錯：\(65^\circ\) 是 \(\frac{1}{2}\overset{\frown}{BC}\)，最後還要乘 \(2\)。
B 錯：多減了 \(\overset{\frown}{AD}\)，但 \(\overset{\frown}{AD}\) 含有頂點 \(A\) 那一側，不在 \(\overset{\frown}{DCB}\) 裡。
C 錯：\(107^\circ - 84^\circ\)，把圓周角和弧的度數直接相減。

Q12. 圓上四點 \(A\)、\(B\)、\(C\)、\(D\) 依序把圓周分成四段：\(\overset{\frown}{AB}\)、\(\overset{\frown}{BC}\)、\(\overset{\frown}{CD}\)、\(\overset{\frown}{DA}\) 的度數比是 \(5 : 3 : 7 : 9\)。\(\angle ABC\) 是多少度？

解析：答案為 C。比例的和是 \(24\)，每一份 \(360^\circ \div 24 = 15^\circ\)，四段弧依序是 \(75^\circ\)、\(45^\circ\)、\(105^\circ\)、\(135^\circ\)。\(\angle ABC\) 夾住不含 \(B\) 的 \(\overset{\frown}{ADC} = \overset{\frown}{CD} + \overset{\frown}{DA}\)： \[\begin{aligned} &\angle ABC = \frac{1}{2}(105^\circ + 135^\circ) \\ &= 120^\circ \end{aligned}\] A 錯：用了含有 \(B\) 的 \(\overset{\frown}{AB} + \overset{\frown}{BC}\)。
B 錯：加錯了段，\(\overset{\frown}{AB}\) 的一端是頂點 \(B\)，不在 \(\angle ABC\) 夾住的弧裡。
D 錯：\(240^\circ\) 是弧的度數，還沒除以 \(2\)。

重點 7：半圓的圓周角是直角

重點整理與敘述

  • \(\overline{AB}\) 是直徑時，\(\overset{\frown}{ADB}\) 是半圓，度數 \(180^\circ\)。圓上任一點 \(C\) 的 \(\angle ACB = \frac{1}{2} \times 180^\circ = 90^\circ\)：直徑（半圓）所對的圓周角是直角。
  • 所以 \(A\)、\(B\)、\(C\) 在圓上且 \(\overline{AB}\) 是直徑 \(\Rightarrow \triangle ABC\) 是直角三角形，斜邊就是直徑。
  • 也可以連 \(\overline{OC}\)，用兩個等腰三角形與內角和 \(180^\circ\) 說明：兩個底角加起來剛好是內角和的一半。
  • 例：半圓中 \(\angle CAB = 36^\circ\)，則 \[\begin{aligned} &\angle ABC = 180^\circ - 90^\circ - 36^\circ \\ &= 54^\circ \end{aligned}\]
  • 應用：過圓外一點 \(P\) 作切線。以 \(\overline{OP}\) 為直徑作圓 \(Q\)，交圓 \(O\) 於 \(M\)、\(N\)，則 \(\angle OMP = \angle ONP = 90^\circ\)，\(PM\)、\(PN\) 就是切線。
KEY POINT・半圓的圓周角 直徑或半圓所對的圓周角是直角

Q13. 如圖，\(\overline{AB}\) 是圓 \(O\) 的直徑，\(C\) 在圓上，\(\angle CAB = 33^\circ\)。不含 \(B\) 的 \(\overset{\frown}{AC}\) 是多少度？

解析：答案為 B。\(\overline{AB}\) 是直徑，\(\angle ACB = 90^\circ\)： \[\begin{aligned} &\angle ABC = 180^\circ - 90^\circ - 33^\circ \\ &= 57^\circ \\ &\overset{\frown}{AC} = 2 \times 57^\circ = 114^\circ \end{aligned}\] A 錯：\(2 \times 33^\circ = 66^\circ\) 是 \(\angle CAB\) 夾住的 \(\overset{\frown}{BC}\)。
C 錯：\(57^\circ\) 是圓周角 \(\angle ABC\)，弧要再乘 \(2\)。
D 錯：\(90^\circ + 33^\circ\) 沒有根據。

Q14. \(P\) 在圓 \(O\) 外。以 \(\overline{OP}\) 為直徑作圓 \(Q\)，與圓 \(O\) 交於 \(M\)、\(N\)。說明「\(PM\) 是圓 \(O\) 的切線」最直接的理由是哪一個？

解析：答案為 A。\(\overline{OP}\) 是圓 \(Q\) 的直徑，\(M\) 在圓 \(Q\) 上，\(\angle OMP\) 對半圓，是直角。\(PM\) 垂直半徑 \(\overline{OM}\) 的外端，所以是切線。
B 錯：等腰三角形說明不了 \(PM\) 和半徑垂直。
C 錯：切線段等長是「已經是切線」之後的性質，不能拿來證明它是切線。
D 錯：\(\angle MON\) 的大小隨 \(\overline{OP}\) 改變，一般不是 \(90^\circ\)。

重點 8：平行弦截出相等的弧

重點整理與敘述

  • 圓中兩弦 \(AB \parallel CD\)：連接 \(\overline{BC}\)，內錯角 \(\angle ABC = \angle BCD\)。這兩個角分別是對 \(\overset{\frown}{AC}\)、\(\overset{\frown}{BD}\) 的圓周角，所以 \(\frac{1}{2}\overset{\frown}{AC} = \frac{1}{2}\overset{\frown}{BD}\)，即 \(\overset{\frown}{AC} = \overset{\frown}{BD}\)。
  • 反過來，\(\overset{\frown}{AC} = \overset{\frown}{BD}\) \(\Rightarrow\) 內錯角相等 \(\Rightarrow AB \parallel CD\)。
  • 被兩條平行弦夾住的，是兩弦之間、左右兩側的那兩段弧（\(A\) 連到 \(C\) 那一側、\(B\) 連到 \(D\) 那一側）。
  • 平行的也可以是直徑或半徑：若 \(AB\) 平行於半徑 \(\overline{OC}\)，就把 \(\overline{CO}\) 延長成直徑，再用這個性質。
平行弦的截弧 \(AB \parallel CD \Leftrightarrow \overset{\frown}{AC} = \overset{\frown}{BD}\)

形成性評量 (平行弦)

Q15. 如圖，圓 \(O\) 中弦 \(AB \parallel\) 半徑 \(\overline{OC}\)，\(\overset{\frown}{AB} = 64^\circ\)，\(D\) 在不含 \(A\)、\(B\) 的那一側。\(\overset{\frown}{CDB}\) 是多少度？

解析：答案為 C。延長 \(\overline{CO}\) 交圓於 \(E\)，\(\overline{CE}\) 是直徑，且 \(AB \parallel CE\)，平行弦截出相等的弧：\(\overset{\frown}{CA} = \overset{\frown}{BE}\)。上半圓是 \(180^\circ\)： \[\begin{aligned} &\overset{\frown}{CA} = \overset{\frown}{BE} \\ &= (180^\circ - 64^\circ) \div 2 = 58^\circ \\ &\overset{\frown}{CDB} = 180^\circ + 58^\circ = 238^\circ \end{aligned}\] A 錯：\(180^\circ - 58^\circ\)，少算了下半圓。
B 錯：\(180^\circ + 64^\circ\)，\(\overset{\frown}{CDB}\) 裡沒有 \(\overset{\frown}{AB}\)。
D 錯：\(58^\circ\) 只是 \(\overset{\frown}{BE}\)。

Q16. 如圖，圓上兩弦 \(AB \parallel CD\)，\(\angle BAD = 41^\circ\)。左側的 \(\overset{\frown}{AC}\)（不含 \(B\)、\(D\)）是多少度？

解析：答案為 D。\(\angle BAD\) 夾住右側的 \(\overset{\frown}{BD}\)，\(\overset{\frown}{BD} = 2 \times 41^\circ = 82^\circ\)。\(AB \parallel CD\)，兩段截弧相等：\(\overset{\frown}{AC} = \overset{\frown}{BD} = 82^\circ\)。
A 錯：\(41^\circ\) 是圓周角，弧要乘 \(2\)。
B 錯：\(180^\circ - 82^\circ\)，平行弦截出的兩段弧相等，不是互補。
C 錯：\(180^\circ - 41^\circ\) 沒有根據。

重點 9：圓內接四邊形的對角互補

重點整理與敘述

  • 四個頂點都在同一個圓上的四邊形，叫做圓內接四邊形。
  • \(\angle A = \frac{1}{2}\overset{\frown}{BCD}\)、\(\angle C = \frac{1}{2}\overset{\frown}{BAD}\)，這兩段弧合起來是整個圓： \[\angle A + \angle C = \frac{1}{2} \times 360^\circ = 180^\circ\] 同理 \(\angle B + \angle D = 180^\circ\)：對角互補。
  • 例：圓內接四邊形中 \(\angle A = 70^\circ\)，則 \(\angle C = 110^\circ\)。
  • 反過來想：如果一個四邊形的對角不互補，它就不可能是圓內接四邊形。
KEY POINT・圓內接四邊形 \(\angle A + \angle C = 180^\circ\)，\(\angle B + \angle D = 180^\circ\)

Q17. 四邊形 \(ABCD\) 是圓內接四邊形，\(\angle A = (3x + 14)^\circ\)、\(\angle C = (2x - 4)^\circ\)。\(\angle C\) 是多少度？

C 錯：\(34\) 是 \(x\)，還要代回去。
D 錯：把兩角的和寫成 \(360^\circ\)，解出 \(x = 70\)。

Q18. 下列各組依序是四邊形 \(ABCD\) 的 \(\angle A\)、\(\angle B\)、\(\angle C\)、\(\angle D\)。哪一組不可能是圓內接四邊形？

解析：答案為 D。四組的內角和都是 \(360^\circ\)，要再檢查對角：\(\angle A + \angle C\) 與 \(\angle B + \angle D\) 都要是 \(180^\circ\)。
A：\(83^\circ + 97^\circ = 180^\circ\)、\(97^\circ + 83^\circ = 180^\circ\)，可以。
B：\(76^\circ + 104^\circ = 180^\circ\)、\(101^\circ + 79^\circ = 180^\circ\)，可以。
C：\(91^\circ + 89^\circ = 180^\circ\)、\(88^\circ + 92^\circ = 180^\circ\)，可以。
D：\(\angle A + \angle C = 72^\circ + 72^\circ = 144^\circ\)，對角不互補。這是一個不是長方形的平行四邊形，不可能內接於圓。

重點 10：圓內接四邊形的外角等於內對角

重點整理與敘述

  • 圓內接四邊形 \(ABCD\) 中，延長 \(\overline{BC}\) 到 \(E\)：\(\angle DCE + \angle BCD = 180^\circ\)（平角），\(\angle BAD + \angle BCD = 180^\circ\)（對角互補），所以 \(\angle DCE = \angle BAD\)：外角等於它的內對角。
  • 例：\(\angle BAD = 115^\circ\) \(\Rightarrow \angle DCE = 115^\circ\)；\(\angle ABC = 70^\circ\) \(\Rightarrow \angle ADC = 110^\circ\)。
  • 兩組對邊延長相交時，搭配三角形的外角：\(AB\)、\(DC\) 延長交於 \(E\)，\(AD\)、\(BC\) 延長交於 \(F\)。若 \(\angle A = 50^\circ\)、\(\angle F = 35^\circ\)：
    • \(\angle DCB = 180^\circ - 50^\circ = 130^\circ\)（對角互補）
    • \(\angle CBE = 50^\circ + 35^\circ = 85^\circ\)（\(\triangle ABF\) 的外角）
    • \(\angle E = 130^\circ - 85^\circ = 45^\circ\)（\(\triangle CBE\) 的外角）
圓內接四邊形的外角 \(\angle DCE = \angle BAD\)（外角 \(=\) 內對角）

Q19. 如圖，四邊形 \(ABCD\) 是圓內接四邊形，\(B\)、\(C\)、\(E\) 三點共線，\(\angle ABC = 73^\circ\)、\(\angle BAD = 118^\circ\)。\(\angle DCE\) 是多少度？

A 錯：\(62^\circ\) 是 \(\angle BCD\)，不是外角。
C 錯：\(107^\circ\) 是 \(\angle ADC = 180^\circ - 73^\circ\)。
D 錯：\(\angle DCE\) 的內對角是 \(\angle BAD\)，不是相鄰的 \(\angle ABC\)。

Q20. 如圖，四邊形 \(ABCD\) 是圓內接四邊形，\(AB\)、\(DC\) 的延長線交於 \(E\)，\(AD\)、\(BC\) 的延長線交於 \(F\)。若 \(\angle A = 46^\circ\)、\(\angle F = 39^\circ\)，則 \(\angle E\) 是多少度？

解析：答案為 C。 \[\begin{aligned} &\angle DCB = 180^\circ - 46^\circ = 134^\circ \\ &\angle CBE = 46^\circ + 39^\circ = 85^\circ \\ &\angle E = 134^\circ - 85^\circ = 49^\circ \end{aligned}\] 第一行用對角互補，第二行是 \(\triangle ABF\) 的外角，第三行是 \(\triangle CBE\) 的外角 \(\angle DCB = \angle CBE + \angle E\)。
A 錯：\(85^\circ\) 是 \(\angle CBE\)。
B 錯：\(95^\circ\) 是 \(\angle ABC\)。
D 錯：\(134^\circ\) 是 \(\angle DCB\)。

小節總結與核心回顧

角與弧速查表

  • 圓心角 \(=\) 所對弧的度數；圓周角 \(= \frac{1}{2}\) 所對弧的度數。
  • 圓周角對的是不含頂點的那段弧；頂點不在圓上就不是圓周角。
  • 同圓或等圓中：等弧 ⇔ 等弦；同弧（或等弧）所對的圓周角相等。
  • 半圓所對的圓周角是直角。
  • 兩弦平行 ⇔ 夾住的兩段弧相等。
  • 圓內接四邊形：對角互補，外角等於內對角。

回到單車行：兩個反光片

轉過的角度一樣

同一根輻條上的兩個反光片，跟著輻條轉過同一個圓心角，所以走過的弧度數相同；外圈的半徑大，走過的弧比較長。

從輪框上看

站在輪框上任何一點看同一段弧，看到的角都一樣大，而且剛好是圓心角的一半——這就是圓周角。
