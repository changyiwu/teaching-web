3-1 證明與推理

古希臘幾何學院的柱廊下，學徒小歐和阿基在沙盤上畫圖、在蠟板上寫推理。量了再多個圖形都一樣，也只是舉例；從已知條件與已確認的性質一步一步推出求證結論，才叫證明。這一節先學幾何證明的三段式寫法與逆推的分析方法，練習用全等、相似、面積、特殊三角形寫證明；再學代數證明：用 \(2k\)、\(2k+1\) 表示偶數與奇數，證明奇偶性質、倍數與平方的大小關係。

已知與求證 逆推與書寫 用全等證明 等量加減 用相似證明 面積與平行四邊形 摺紙與特殊三角形 奇數與偶數 奇偶性質的證明 舉例與反例 證明倍數 平方的大小

課前暖身漫畫：量了三個，就算證明了嗎？

小歐在沙盤上畫了三個等腰三角形，量了量，兩個底角每次都一樣大，就宣布「等腰三角形的底角一定相等」。阿基問她：沙盤上畫得完全部的三角形嗎？量再多個也只是舉例；要從已知條件一步一步推出結論，才能說「每一個都成立」——這就是證明。

重點 1：證明的意義——已知、求證、證明

重點整理與敘述

  • 運用已知條件或已確認性質，推導出求證結論的過程，叫做證明。
  • 幾何證明常寫成三段式：已知（題目給的條件）、求證（要說明的結論）、證明（推理過程，每一步都附上理由）。
  • 題目常寫成「……，說明（證明）……」：「說明」前面是已知，後面是求證。
  • 已確認性質是學過的定理，例如對頂角相等、共用邊、三角形全等性質。它們可以寫進證明當理由，但不是題目給的已知。
  • 圖上看起來相等、垂直的東西，不能當已知；推導過程中才得到的結果，也不是已知。
  • 例（課本）：等腰 \(\triangle ABC\) 中 \(\overline{AB} = \overline{AC}\)，\(\angle BAC\) 的角平分線交 \(\overline{BC}\) 於 \(D\)，說明 \(\overline{AD}\) 平分 \(\overline{BC}\)。
    已知：\(\overline{AB} = \overline{AC}\)、\(\angle BAD = \angle CAD\)；求證：\(\overline{AD}\) 平分 \(\overline{BC}\)。
KEY POINT・證明 已知條件 ＋ 已確認性質 → 求證結論

Q1. 如圖，\(\overline{AC}\) 與 \(\overline{BD}\) 交於 \(O\) 點。題目寫：「若 \(\overline{OA} = \overline{OC}\)、\(\angle A = \angle C\)，說明 \(\overline{AB} = \overline{CD}\)。」下列哪一組全部都是這題的「已知」？

解析：答案為 B。「說明」前面的 \(\overline{OA} = \overline{OC}\)、\(\angle A = \angle C\) 才是題目給的已知。
A、D 錯：\(\overline{AB} = \overline{CD}\) 是要說明的求證結論，不能當已知。
C 錯：\(\overline{OB} = \overline{OD}\) 是證出 \(\triangle AOB \cong \triangle COD\) 之後才得到的結果，題目沒有給。另外 \(\angle AOB = \angle COD\) 是對頂角，屬於已確認性質，也不是已知。

Q2. 關於「證明」，下列敘述何者正確？

解析：答案為 D。證明的依據有兩種：題目給的已知條件，以及已經確認的性質（定理）。
A 錯：量出來的只是這一張圖的樣子，不是題目給的條件。
B 錯：畫再多個圖都只是舉例，沒畫到的圖形不一定成立。
C 錯：拿結論當理由是「繞圈子」，等於什麼都沒證。

重點 2：從求證往回找，再從已知往前寫

重點整理與敘述

  • 分析（逆推）：從求證結論出發，一層一層問「要得到它，需要先知道什麼？」，直到碰到已知條件或已確認性質。
  • 就像走迷宮：從入口找不到路時，從出口倒著走回入口往往比較容易。
  • 書寫（順推）：正式寫證明時方向相反——從已知出發，先證中間的結果，最後才得到求證結論。
  • 每一步都要附上理由，例如（已知）、（共用邊）、（對頂角相等）、（\(\text{SAS}\) 全等性質）、（對應邊相等）。
  • 例（課本）：要說明 \(\overline{AD}\) 平分 \(\overline{BC}\)，逆推是「\(\overline{AD}\) 平分 \(\overline{BC}\) ← \(\overline{BD} = \overline{CD}\) ← \(\triangle ABD \cong \triangle ACD\)」；寫的時候倒過來，先證全等、再得 \(\overline{BD} = \overline{CD}\)。
分析與書寫 分析：求證 → 中間結果 → 已知；書寫：已知 → 中間結果 → 求證

形成性評量 (逆推與書寫)

Q3. 題目：「\(\triangle ABC\) 中 \(\overline{AB} = \overline{AC}\)，\(M\) 是 \(\overline{BC}\) 的中點，證明 \(\overline{AM} \perp \overline{BC}\)。」逆推的分析是：要證垂直，可以先證 \(\angle AMB = \angle AMC\)（兩角互補又相等，就都是 \(90^\circ\)）；要證這兩角相等，可以先證 \(\triangle ABM \cong \triangle ACM\)。正式寫證明時，正確的順序是哪一個？

解析：答案為 C。書寫的方向和分析相反：先用 \(\overline{AB} = \overline{AC}\)、\(\overline{BM} = \overline{CM}\)、\(\overline{AM} = \overline{AM}\) 證出 \(\triangle ABM \cong \triangle ACM\)（\(\text{SSS}\)），得到對應角 \(\angle AMB = \angle AMC\)，再因為兩角互補，各是 \(90^\circ\)。
A 錯：角相等要靠全等才得到，不能先寫。
B 錯：這是分析的方向，把結論寫在第一步等於先假設它成立。
D 錯：垂直是由「兩角相等」推出來的，順序反了。

Q4. 要證明 \(\overline{PA} = \overline{PB}\)，下列哪一個是最常見、也最合理的逆推想法？

解析：答案為 A。兩個三角形全等，對應邊就相等；只要 \(\overline{PA}\)、\(\overline{PB}\) 是對應邊，問題就變成「怎麼證全等」，再往下找三組條件。
B 錯：從結論推出已知，不能反過來保證結論成立。
C 錯：量長度是舉例，不是證明。
D 錯：直角三角形和兩邊相等沒有關係；若要用同一個三角形，應該證 \(\angle PAB = \angle PBA\)（等角對等邊），不是證直角。

重點 3：找出全等三角形，用對應邊（角）相等證明

重點整理與敘述

  • 要證兩條線段（或兩個角）相等：找兩個分別包含它們的三角形，而且它們剛好是對應邊（對應角）。
  • 證兩三角形全等要湊齊三組條件，配上一個全等性質：\(\text{SSS}\)、\(\text{SAS}\)、\(\text{ASA}\)、\(\text{AAS}\)、\(\text{RHS}\)。
  • 條件的來源：已知、共用邊、共用角、對頂角、平行線的截角、「高」給的直角。
  • 不能用的條件：求證的結論本身、還沒證出來的結果、圖上看起來相等的東西。
  • 例（課本）：等腰 \(\triangle ABC\) 中 \(\overline{AB} = \overline{AC}\)，\(\overline{BD}\)、\(\overline{CE}\) 是兩腰上的高。在 \(\triangle ABD\) 與 \(\triangle ACE\) 中，\(\angle A\) 共用、\(\angle ADB = \angle AEC = 90^\circ\)、\(\overline{AB} = \overline{AC}\)，由 \(\text{AAS}\) 得全等，所以 \(\overline{BD} = \overline{CE}\)。
兩段式證明 先證三角形全等 → 再用「對應邊（角）相等」得到結論

形成性評量 (用全等證明)

Q5. 如圖，四邊形 \(ABCD\) 中，\(\angle DAB = \angle CBA\)、\(\overline{AD} = \overline{BC}\)。要證明 \(\overline{AC} = \overline{BD}\)，先證 \(\triangle ABD \cong \triangle BAC\)，所根據的全等性質是？

解析：答案為 C。在 \(\triangle ABD\) 與 \(\triangle BAC\) 中： \[\begin{aligned} &\overline{AD} = \overline{BC}\ (\text{已知}) \\ &\angle DAB = \angle CBA\ (\text{已知}) \\ &\overline{AB} = \overline{BA}\ (\text{共用邊}) \end{aligned}\] 角夾在兩邊中間，是 \(\text{SAS}\)，所以 \(\overline{BD} = \overline{AC}\)（對應邊相等）。
A 錯：第三邊 \(\overline{BD} = \overline{AC}\) 正是要證的，不能拿來用。
B 錯：只有一組角相等，湊不出兩組角。
D 錯：題目沒有直角。

Q6. 如圖，\(\overline{AB}\) 與 \(\overline{CD}\) 交於 \(O\)，\(\overline{AC} /\!/ \overline{DB}\)，\(\overline{AO} = \overline{BO}\)。要證 \(\overline{CO} = \overline{DO}\)，在 \(\triangle AOC\) 與 \(\triangle BOD\) 中，下列哪一組條件與理由正確？

解析：答案為 A。\(\overline{AC} /\!/ \overline{DB}\)，\(\overline{AB}\) 是截線，\(\angle OAC\) 與 \(\angle OBD\) 是內錯角；邊 \(\overline{AO}\) 夾在 \(\angle A\) 與 \(\angle AOC\) 之間，所以是 \(\text{ASA}\)，得 \(\overline{CO} = \overline{DO}\)（對應邊相等）。
B 錯：用了求證的結論。
C 錯：\(\angle A\) 與 \(\angle B\) 是內錯角，不是同位角——理由寫錯，證明就不成立。
D 錯：\(\overline{AC} = \overline{BD}\) 題目沒給，看起來一樣長不能當理由。

重點 4：先用等量加減湊出條件，再證全等

重點整理與敘述

  • 有時候三組條件不會直接出現在題目裡，夾角要先用等量加法或等量減法湊出來。
  • 等量加法：若 \(\angle 1 = \angle 3\)，則 \(\angle 1 + \angle 2 = \angle 3 + \angle 2\)。兩個相等的角各加上同一個角，和仍然相等。
  • 等量減法：兩個相等的量各減去同一個量，差仍然相等（線段也適用）。
  • 常見的圖：兩個正方形或正三角形共用一個頂點，連出兩條線段要證相等。正方形的直角、正三角形的 \(60^\circ\) 就是「相等的那兩個角」。
  • 例（課本）：正方形 \(ABCD\) 與 \(AEFG\) 共用頂點 \(A\)，\(E\) 在 \(\overline{AB}\) 上。\(\overline{AE} = \overline{AG}\)、\(\overline{AD} = \overline{AB}\)、\(\angle DAE = \angle BAG = 90^\circ\)，由 \(\text{SAS}\) 得 \(\overline{DE} = \overline{BG}\)。
等量加法 若 \(\angle 1 = \angle 3\)，則 \(\angle 1 + \angle 2\)\({} = \angle 3 + \angle 2\)

視覺互動探索：外接圖形的夾角

在 \(\triangle ABC\) 的兩邊往外作正三角形（或正方形）。拉動 \(\angle BAC\) 和 \(\overline{AC}\) 的長度，看兩個夾角是不是永遠相等、連出的兩條線段是不是永遠一樣長；再拉「證明步驟」看完整的推理。

形成性評量 (等量加減)

Q7. 如圖，\(\overline{AB} = \overline{AD}\)、\(\overline{AC} = \overline{AE}\)，\(\angle BAD = \angle CAE = 38^\circ\)、\(\angle DAC = 27^\circ\)。下列敘述何者正確？

解析：答案為 D。等量加法：兩個 \(38^\circ\) 各加上同一個 \(\angle DAC\)： \[\begin{aligned} &\angle BAC = 38^\circ + 27^\circ = 65^\circ \\ &\angle DAE = 27^\circ + 38^\circ = 65^\circ \end{aligned}\] 再加上 \(\overline{AB} = \overline{AD}\)、\(\overline{AC} = \overline{AE}\)，夾角相等，\(\text{SAS}\) 得全等（所以 \(\overline{BC} = \overline{DE}\)）。
A 錯：\(\overline{BC} = \overline{DE}\) 還沒證出來，不能用 \(\text{SSS}\)。
B 錯：\(\angle BAC\) 不只是 \(\angle BAD\)，還要加上 \(\angle DAC\)。
C 錯：\(76^\circ\) 是把兩個 \(38^\circ\) 加在一起，加錯了角。

Q8. 如圖，正方形 \(ABCD\) 與正方形 \(CEFG\) 有共同頂點 \(C\)，連接 \(\overline{BG}\)、\(\overline{DE}\)。證明 \(\overline{BG} = \overline{DE}\) 時，說明 \(\angle BCG = \angle DCE\) 的正確理由是？

解析：答案為 B。 \(\angle BCD = \angle GCE = 90^\circ\)，所以 \[\begin{aligned} &\angle BCG = 90^\circ + \angle DCG \\ &\angle DCE = 90^\circ + \angle DCG \end{aligned}\] 兩角相等，再配上 \(\overline{BC} = \overline{DC}\)、\(\overline{CG} = \overline{CE}\)，\(\text{SAS}\) 得 \(\triangle BCG \cong \triangle DCE\)。
A 錯：兩個角沒有共用一條直線，不是對頂角。
C 錯：這兩個角都比 \(90^\circ\) 大，不是正方形的內角。
D 錯：\(\overline{BG} = \overline{DE}\) 是要證的結論。

重點 5：用 AA 相似性質證明——找出相等的角

重點整理與敘述

  • 證兩三角形相似，最常用 \(\text{AA}\) 相似性質：找到兩組對應角相等就夠了。
  • 一組角常常是現成的：直角、正三角形的 \(60^\circ\)、對頂角、共用角。
  • 另一組角常靠「同一個角的餘角（補角）相等」：若 \(\angle 1 + \angle 2 = 90^\circ\)、\(\angle 3 + \angle 2 = 90^\circ\)，則 \(\angle 1 = \angle 3\)。
  • 證出相似之後，就能寫出對應邊成比例，用來求長度。寫比例時對應頂點的順序要一致。
  • \(\text{SAS}\) 相似要的是「夾角相等、夾角的兩邊對應成比例」——比例要用對應邊來寫，不能只看數字湊得出 \(2 : 3\)。
同一個角的餘角相等 \(\angle 1 + \angle 2 = 90^\circ\)\({} = \angle 3 + \angle 2\)\({} \Rightarrow \angle 1 = \angle 3\)

形成性評量 (用相似證明)

Q9. 如圖，正方形 \(ABCD\) 的邊長是 \(12\)，\(E\) 在 \(\overline{BC}\) 上且 \(\overline{BE} = 4\)，過 \(E\) 作 \(\overline{EF} \perp \overline{AE}\)，交 \(\overline{CD}\) 於 \(F\)。\(\overline{CF}\) 的長是多少？

解析：答案為 A。\(\angle B = \angle C = 90^\circ\)；\(\angle BAE\) 與 \(\angle CEF\) 都是 \(\angle AEB\) 的餘角，所以相等，\(\triangle ABE \sim \triangle ECF\)（\(\text{AA}\)）。\(\overline{EC} = 12 - 4 = 8\)： \[\begin{aligned} &\overline{AB} : \overline{EC} = \overline{BE} : \overline{CF} \\ &12 : 8 = 4 : \overline{CF},\ \overline{CF} = \frac{8}{3} \end{aligned}\] B 錯：比例的對應寫反了，\(12 : 8 = \overline{CF} : 4\) 才會得 \(6\)。
C 錯：以為 \(\overline{CF} = \overline{BE}\)，兩個三角形只是相似，不是全等。
D 錯：\(\frac{16}{3} = \frac{8 \times 8}{12}\)，把 \(\overline{EC}\) 乘了兩次。

Q10. 四邊形 \(ABCD\) 的兩條對角線交於 \(O\)，\(\overline{OA} = 6\)、\(\overline{OC} = 9\)、\(\overline{OB} = 4\)。若要 \(\triangle AOB \sim \triangle COD\)（\(A\) 對應 \(C\)、\(B\) 對應 \(D\)），\(\overline{OD}\) 應該是多少？

解析：答案為 C。\(\angle AOB = \angle COD\)（對頂角），夾這個角的兩邊要對應成比例（\(\text{SAS}\) 相似）： \[\begin{aligned} &\overline{OA} : \overline{OC} = \overline{OB} : \overline{OD} \\ &6 : 9 = 4 : \overline{OD},\ \overline{OD} = 6 \end{aligned}\] A 錯：寫成 \(\overline{OA} : \overline{OC} = \overline{OD} : \overline{OB}\)，夾角的兩邊沒有照 \(A\) 對 \(C\)、\(B\) 對 \(D\) 來對應——這正是課本挑錯題的錯法。
B 錯：寫成 \(\overline{OB} : \overline{OA} = \overline{OC} : \overline{OD}\)，那是 \(A\) 對應 \(D\) 的另一種相似，和題目要的對應不同。
D 錯：以為 \(\overline{OD}\) 要等於 \(\overline{OC}\)，相似不是全等。

重點 6：用面積推出等邊，判別平行四邊形

重點整理與敘述

  • 平行四邊形的判別：兩雙對角分別相等、兩雙對邊分別相等、一雙對邊平行且相等、兩對角線互相平分。
  • 兩平行線之間的距離處處相等。底在兩平行線上的三角形等高，所以「面積相等 ⇔ 底相等」。
  • 例（課本）：四邊形 \(ABCD\) 中 \(\angle 1 = \angle 2\)（內錯角）得 \(\overline{AD} /\!/ \overline{BC}\)；設距離 \(h\)，由 \(\triangle ABC\) 與 \(\triangle ACD\) 面積相等，\(\frac{1}{2} \times \overline{BC} \times h = \frac{1}{2} \times \overline{AD} \times h\)，得 \(\overline{BC} = \overline{AD}\)，是一雙對邊平行且相等。
  • 兩個三角形若共用一個頂點、底在同一直線上，也是等高：面積比 \(=\) 底的比。對角線切出的四個三角形就是這樣比出「對角線有沒有互相平分」。
等高的三角形 面積比 \(=\) 底的比；面積相等 \(\Leftrightarrow\) 底相等

形成性評量 (面積與平行四邊形)

Q11. 四邊形 \(ABCD\) 中，\(\overline{AD} /\!/ \overline{BC}\)，兩平行線的距離是 \(9\)，\(\overline{BC} = 14\)，而且 \(\triangle ACD\) 的面積等於 \(\triangle ABC\) 的面積。四邊形 \(ABCD\) 的面積是多少？

解析：答案為 D。兩個三角形的高都是平行線的距離 \(9\)，面積相等所以底相等：\(\overline{AD} = \overline{BC} = 14\)。一雙對邊平行且相等，\(ABCD\) 是平行四邊形： \[\text{面積} = 14 \times 9 = 126\] A 錯：\(63\) 只是 \(\triangle ABC\) 的面積。
B 錯：多乘了 \(2\)，平行四邊形面積是底 \(\times\) 高，不必再乘 \(2\)。
C 錯：題目沒有直接給 \(\overline{AD}\)，但「等高、面積相等」已經推得出 \(\overline{AD} = 14\)。

Q12. 四邊形 \(ABCD\) 的對角線交於 \(O\)，\(\triangle AOB\)、\(\triangle BOC\)、\(\triangle COD\)、\(\triangle DOA\) 的面積依序是 \(12\)、\(18\)、\(27\)、\(18\)。下列敘述何者正確？

解析：答案為 B。\(\triangle AOB\) 與 \(\triangle BOC\) 共用頂點 \(B\)、底在 \(\overline{AC}\) 上，等高：\(\overline{OA} : \overline{OC} = 12 : 18 = 2 : 3\)。\(\triangle AOB\) 與 \(\triangle DOA\) 共用頂點 \(A\)、底在 \(\overline{BD}\) 上：\(\overline{OB} : \overline{OD} = 12 : 18 = 2 : 3\)。
A 錯：\(\triangle BOC\) 與 \(\triangle DOA\) 相等推不出 \(\overline{OA} = \overline{OC}\)。
C 錯：\(\overline{OA}\) 對應的是較小的 \(12\)，比例寫反了。
D 錯：\(\triangle BOC\) 的面積是 \(18\)，不是 \(27\)。

重點 7：摺紙裡的 30°、60°、90° 三角形

重點整理與敘述

  • 摺紙的證明，已知條件藏在摺法裡：摺過去的兩部分全等，對應邊、對應角都相等；對摺一次得到中點。
  • 直角三角形三邊比是 \(1 : \sqrt{3} : 2\) 時，對應的角是 \(30^\circ\)、\(60^\circ\)、\(90^\circ\)；反過來，斜邊是短股的 \(2\) 倍，短股對的角就是 \(30^\circ\)。
  • 例（課本）：正方形 \(ABCD\) 對摺得中線 \(\overline{PQ}\)，再把 \(C\) 摺到 \(\overline{PQ}\) 上的 \(E\)。因為 \(\overline{BE} = \overline{BC} = 2\overline{BQ}\)，直角 \(\triangle EBQ\) 的邊比是 \(1 : 2 : \sqrt{3}\)，\(\angle EBQ = 60^\circ\)，加上 \(\overline{BE} = \overline{BC}\)，\(\triangle BCE\) 是正三角形。

特殊直角三角形 邊長比 \(1 : \sqrt{3} : 2 \Leftrightarrow\) 角 \(30^\circ\)、\(60^\circ\)、\(90^\circ\)

重點 8：用 2k、2k + 1 表示偶數與奇數

重點整理與敘述

  • 每個偶數都是 \(2\) 的倍數：偶數可以寫成 \(2k\)（\(k\) 是整數）。
  • 每個奇數都是某個偶數加 \(1\) 或減 \(1\)：奇數可以寫成 \(2k + 1\) 或 \(2k - 1\)（\(k\) 是整數）。
  • \(k\) 可以是負數和 \(0\)，所以 \(0\)、\(-2\) 也是偶數，\(-1\)、\(-3\) 也是奇數。
  • 判斷一個式子的奇偶：設法把它整理成「\(2 \times\) 整數」（偶數）或「\(2 \times\) 整數 \(+ 1\)」（奇數）。整理不出來，就代入幾個數看看——一個奇、一個偶就是「都有可能」。
  • 例（課本）：\(a\) 是整數時，\(2a + 2 = 2(a + 1)\) 一定是偶數；\(a + 1\) 都有可能。
偶數與奇數（\(k\) 為整數） 偶數 \(= 2k\)；奇數 \(= 2k + 1\) 或 \(2k - 1\)

Q15. 已知 \(m\) 是整數，下列哪一個式子的值一定是奇數？

解析：答案為 C。\(2m + 7 = 2(m + 3) + 1\)，\(m + 3\) 是整數，所以一定是奇數。

Q16. 已知 \(t\) 是整數。下列哪一個式子，可以用來表示所有的奇數？

解析：答案為 A。\(2t + 5 = 2(t + 2) + 1\)，而且 \(t\) 跑遍所有整數時，\(t + 2\) 也跑遍所有整數，所以每一個奇數都寫得出來（例：\(-1 = 2 \times (-3) + 5\)）。

重點 9：證明奇偶性質——兩個任意的數要用不同的字母

重點整理與敘述

  • 代數證明的寫法：先用字母假設（偶數 \(2m\)、奇數 \(2n + 1\)，\(m\)、\(n\) 是整數），再運算整理成 \(2 \times (\ldots)\) 或 \(2 \times (\ldots) + 1\)，最後說明括號裡是整數，下結論。
  • 兩個任意的數要用不同的字母。若設 \(a = 2m\)、\(b = 2m + 1\)，\(b\) 永遠比 \(a\) 大 \(1\)，就只證到「相鄰的偶數和奇數」。
  • 例（課本）：偶數 \(a = 2m\)、奇數 \(b = 2n + 1\)，\(a + b = 2(m + n) + 1\)，\(m + n\) 是整數，所以 \(a + b\) 是奇數。
  • 例（課本）：奇數 \(a = 2k + 1\)，\(a^2 = 4k^2 + 4k + 1\)\({} = 2(2k^2 + 2k) + 1\)，所以奇數的平方是奇數。
  • 結論整理：奇 \(+\) 偶 \(=\) 奇、偶 \(+\) 偶 \(=\) 偶、奇 \(\times\) 奇 \(=\) 奇、偶 \(\times\) 偶 \(=\) 偶。
代數證明三步 用不同字母假設 → 整理成 \(2 \times (\ldots)\) 或 \(2 \times (\ldots) + 1\) → 說明括號裡是整數

Q17. 要證明「任意三個奇數的和是奇數」，下列哪一種假設最恰當？（字母都代表整數）

解析：答案為 C。三個任意的奇數彼此無關，要用三個不同的字母；和是 \(2(p + q + r + 1) + 1\)，是奇數。
A 錯：三個數永遠是相鄰的奇數，只證到「連續三個奇數」。
B 錯：第三個數永遠比第一個大 \(2\)，兩個數被綁在一起了。
D 錯：這是舉例，不是證明。

Q18. 小翊證明「兩個奇數的和是偶數」：設 \(a = 2m + 1\)、\(b = 2n + 1\)（\(m\)、\(n\) 是整數），\(a + b = 2m + 2n + 2\)\({} = 2(m + n + 1)\)。要下結論之前，還需要說明哪一件事？

解析：答案為 D。偶數的定義是「\(2 \times\) 整數」，所以要說明括號裡的 \(m + n + 1\) 是整數（整數相加還是整數）。
A 錯：括號裡是奇數也沒關係，例如 \(2 \times 3 = 6\) 還是偶數。
B 錯：\(m\)、\(n\) 本來就是任意的，不需要相等。
C 錯：\(0\) 和負的偶數也是偶數，不必是正數。

重點 10：舉例不是證明，一個反例就能推翻

重點整理與敘述

  • 「每一個……都……」的說法，舉再多個成立的例子，也不是證明——整數有無限多個，舉不完。
  • 要說它成立，必須用代數或幾何推理證明。
  • 要說它不成立，只要找到一個反例：符合條件、結論卻不對的例子。
  • 例（課本漫畫）：小翊舉了 \(1\)、\(3\)、\(5\)、\(7\)、\(9\) 的平方都是奇數，就說「奇數的平方一定是奇數」——結論恰好是對的，但他做的只是舉例，要用 \(a = 2k + 1\) 才算證明。
  • 找反例時，記得試試負數、\(0\)、\(1\)、分數這類「邊角」的數。
成立與不成立 說「成立」要證明；說「不成立」舉一個反例就夠

形成性評量 (舉例與反例)

Q19. 阿基說：「\(n\) 是正整數時，\(2^n + 1\) 一定是質數，因為 \(n = 1\)、\(2\)、\(4\) 時分別是 \(3\)、\(5\)、\(17\)，都是質數。」下列哪一個回應最能說明他錯了？

解析：答案為 A。一個反例就推翻「一定」：\(n = 3\) 符合條件，\(2^3 + 1 = 9\) 卻不是質數。
B 錯：例子少只代表「還沒證明」，不代表說法錯；要說它錯，得拿出反例。
C 錯：再多一個成立的例子，仍然是舉例。
D 錯：\(n\) 是任意正整數，只看偶數的情形不夠，而且這裡一個反例就夠了。

Q20. 下列哪一個說法可以用一個反例推翻？

解析：答案為 B。反例：\(\frac{1}{2}\) 是正數，\(\left(\frac{1}{2}\right)^2 = \frac{1}{4}\) 比 \(\frac{1}{2}\) 小；\(1^2 = 1\) 也沒有比 \(1\) 大。
A、C、D 都是對的，找不到反例：兩個負數 \(-a\)、\(-b\)（\(a\)、\(b\) 為正數）的和是 \(-(a + b)\)；\((2k)^2 = 2(2k^2)\)；\((2m + 1)(2n + 1)\)\({} = 2(2mn + m + n) + 1\)。

重點 11：用乘法公式證明「是某數的倍數」

重點整理與敘述

  • 要證明一個式子是 \(p\) 的倍數，就把它整理成「\(p \times\) 整數」，並說明括號裡是整數。
  • 常用工具：平方差 \(a^2 - b^2 = (a + b)(a - b)\)、和的平方 \((a + b)^2 = a^2 + 2ab + b^2\)。
  • 例（課本）：直角三角形三邊 \(a\)、\(b\)、\(c\) 都是正整數，\(c\) 是斜邊，\(a^2 = c^2 - b^2 = (c + b)(c - b)\)，所以 \(a^2\) 是 \((b + c)\) 的倍數。
  • 例（課本）：\((k + 1)^2 - k^2 = 2k + 1\) 是奇數；\((k + 2)^2 - k^2 = 4(k + 1)\) 是 \(4\) 的倍數。
  • 展開時別漏掉中間項：\((a + b)^2\) 不是 \(a^2 + b^2\)。
平方差 \((k + d)^2 - k^2 = d(2k + d)\)：一定是 \(d\) 的倍數

形成性評量 (證明倍數)

Q21. 已知 \(n\) 是正整數，關於 \((n + 5)^2 - (n - 5)^2\) 的值，下列敘述何者一定正確？

解析：答案為 C。用平方差： 設 \(a = n + 5\)、\(b = n - 5\)，則 \(a + b = 2n\)、\(a - b = 10\)： \[\begin{aligned} &(n + 5)^2 - (n - 5)^2 \\ &= (a + b)(a - b) \\ &= 2n \times 10 = 20n \end{aligned}\] \(n\) 是整數，所以是 \(20\) 的倍數。
A 錯：\(n = 1\) 時是 \(20\)，不是 \(25\) 的倍數。
B 錯：\(20n\) 一定是偶數。
D 錯：\(n = 1\) 時是 \(20\)，不是完全平方數。

Q22. 已知 \(p\) 是正整數，要證明 \((3p + 1)^2 - 1\) 是 \(3\) 的倍數。下列哪一個過程正確？

解析：答案為 B。和的平方要有中間項： \[\begin{aligned} &(3p + 1)^2 - 1 \\ &= 9p^2 + 6p + 1 - 1 \\ &= 3(3p^2 + 2p) \end{aligned}\] A 錯：漏了中間項 \(2 \times 3p \times 1 = 6p\)，雖然結論碰巧對，過程是錯的。
C 錯：中間項是 \(6p\)，不是 \(3p\)。
D 錯：只是舉例，不是證明。

重點 12：用平方差比較平方的大小

重點整理與敘述

  • 要比較 \(a^2\) 和 \(b^2\)，看 \(a^2 - b^2\) 的正負；而 \(a^2 - b^2 = (a + b)(a - b)\)。
  • 兩個因式同號（都正或都負），乘積是正的，\(a^2 \gt b^2\)；異號時乘積是負的，\(a^2 \lt b^2\)。
  • 例（課本）：\(a\)、\(b\) 是正數且 \(a \gt b\)，則 \(a + b \gt 0\)、\(a - b \gt 0\)，所以 \(a^2 - b^2 \gt 0\)，\(a^2 \gt b^2\)。
  • 反過來也對：\(a\)、\(b\) 是正數且 \(a^2 \gt b^2\)，因為 \(a + b \gt 0\)，必須 \(a - b \gt 0\)，所以 \(a \gt b\)。
  • 「正數」這個條件不能拿掉：有負數時，\(a + b\) 的正負會改變，大的數平方不一定比較大。
兩正數 \(a \gt b \gt 0 \Leftrightarrow a^2 \gt b^2\)（\(a\)、\(b\) 都是正數）

Q23. 小妍說：「若 \(a^2 \gt b^2\)，則 \(a \gt b\)。」下列哪一組數是她這個說法的反例？

解析：答案為 D。反例要「條件成立、結論不成立」：\((-9)^2 = 81 \gt 49 = 7^2\)，但 \(-9 \lt 7\)。
A 錯：\(81 \gt 49\) 且 \(9 \gt 7\)，結論成立，不是反例。
B 錯：\(49 \lt 81\)，條件 \(a^2 \gt b^2\) 本身就不成立。
C 錯：\(81 \gt 49\) 且 \(9 \gt -7\)，結論成立。

Q24. 已知 \(a\)、\(b\) 都是正數，而且 \(a \lt b\)。要證明 \(a^2 \lt b^2\)，下列哪一個推論正確？

解析：答案為 A。\(a^2 - b^2 = (a + b)(a - b)\)，一正一負，乘積是負的，所以 \(a^2 \lt b^2\)。
B 錯：\(a^2 - b^2\) 是兩個因式相乘，只看 \(a - b\) 不夠；正因為 \(a + b \gt 0\) 才能下結論。
C 錯：只看了一個因式，而且結論方向也錯。
D 錯：有負數時就不對，例如 \(-3 \lt 1\)，但 \(9 \gt 1\)。

小節總結與核心回顧

證明與推理速查表

  • 證明：已知條件 \(+\) 已確認性質 → 求證結論；三段式寫「已知、求證、證明」，每一步附理由。
  • 分析逆推、書寫順推：從求證往回找需要的條件，寫的時候從已知往前寫。
  • 幾何證明的工具：全等（對應邊、角相等）、等量加減、\(\text{AA}\) 相似、等高三角形的面積、特殊直角三角形。
  • 偶數 \(2k\)、奇數 \(2k + 1\) 或 \(2k - 1\)；兩個任意的數用不同字母。
  • 倍數：整理成「\(p \times\) 整數」；平方的大小：看 \((a + b)(a - b)\) 的正負，記得「正數」的條件。
  • 舉例不是證明；一個反例就能推翻「一定」。

回到幾何學院：沙盤上畫不完的三角形

推理代替測量

小歐量了三個等腰三角形就下結論，阿基提醒她：三角形有無限多個。從「兩腰相等」出發，作頂角的角平分線、證出兩個三角形全等，底角相等就對每一個等腰三角形都成立——這才是證明。

代數也一樣

奇數有無限多個，用 \(2k + 1\) 一次代表全部，整理成 \(2 \times\) 整數 \(+ 1\)，結論就涵蓋了每一個奇數。
