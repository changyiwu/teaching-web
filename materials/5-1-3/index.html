1-3 縮放與相似

老照相館的小影和見習生阿光，每天都在暗房裡用放大機把底片放大成相片——放大機的燈泡就是縮放中心，放大的倍數就是縮放倍率。這一節先看線段、角與多邊形縮放之後變了什麼、沒變什麼；再定義相似多邊形（對應邊成比例、對應角相等），用它求邊長與角度；最後學三角形的三個判別方法：AA、SAS、SSS 相似性質。

課前暖身漫畫：被拉胖的全家福

客人要把一張全家福放大。阿光想只把相片的寬變成 2 倍、高不變。小影提醒他：這樣每個人都會被拉胖！她調整放大機的燈頭，說明長和寬應乘上同一個倍率，才能保留原來的形狀。長和寬乘上同一個倍率，形狀才不會變——這就是這一節的「縮放」。

重點 1：縮放中心、縮放倍率與線段的縮放

重點整理與敘述

  • 影印機的放大縮小、手電筒照出來的影子：大小可能改變，形狀不變，這叫做縮放。光源、圖形上的點、影子上的對應點，三點在同一條直線上。
  • 平面上固定一點 \(O\)，在射線 \(OA\) 上取一點 \(A'\)，使 \(\overline{OA'} = r\,\overline{OA}\)：\(A'\) 是以 \(O\) 為中心、把 \(A\) 縮放 \(r\) 倍的對應點，\(r\) 叫做縮放倍率。
  • \(r \gt 1\) 是放大，\(0 \lt r \lt 1\) 是縮小。對應點一定在射線 \(OA\) 上，不會跑到 \(O\) 的另一側。
  • 畫線段 \(\overline{AB}\) 的縮放圖形：把兩個端點各自縮放，再把兩個對應點連起來。中心在線段上時畫法也一樣。
  • 射線縮放後仍是射線、直線縮放後仍是直線，而且都跟原來的平行（或重合）。
KEY POINT・線段的縮放 縮放後仍是線段；\(\overline{A'B'} /\!/ \overline{AB}\)（或在同一直線上）；\(\overline{A'B'} = r\,\overline{AB}\)

視覺互動探索：從燈泡拉出來的線段

\(O\) 是放大機的燈泡。選中心的位置，拉動倍率，看 \(A'\)、\(B'\) 怎麼沿著光線移動：\(\overline{A'B'}\) 的長度變成幾倍？方向有沒有改變？

形成性評量 (線段的縮放)

Q1. 點 \(O\) 不在直線 \(AB\) 上。以 \(O\) 為中心，將 \(\overline{AB}\) 縮放 4 倍得到 \(\overline{A'B'}\)。若 \(\overline{OA} = 5\)、\(\overline{AB} = 7\)，下列何者正確？

解析：答案為 A。\(\overline{OA'} = 4 \times 5 = 20\)；線段縮放 4 倍，長度也變 4 倍：\(\overline{A'B'} = 4 \times 7 = 28\)，而且 \(O\) 不在直線 \(AB\) 上，所以 \(\overline{A'B'} /\!/ \overline{AB}\)。
B 錯：縮放是「乘」倍率，不是「加」。
C 錯：縮放後不變的是角度，長度會變 4 倍。
D 錯：\(A'\) 在射線 \(OA\) 上，\(\overline{AA'} = \overline{OA'} - \overline{OA} = 15\)，不是 20。

Q2. 點 \(O\) 在 \(\overline{CD}\) 上，\(\overline{OC} = 6\)、\(\overline{OD} = 9\)。以 \(O\) 為中心，將 \(\overline{CD}\) 縮放 \(\frac{1}{4}\) 倍得到 \(\overline{C'D'}\)。下列敘述何者正確？

解析：答案為 B。\(C'\) 在射線 \(OC\) 上、\(\overline{OC'} = \frac{6}{4} = \frac{3}{2}\)；\(D'\) 在射線 \(OD\) 上、\(\overline{OD'} = \frac{9}{4}\)。兩條射線方向相反，所以 \(C'\)、\(D'\) 分在 \(O\) 的兩側，都在直線 \(CD\) 上： \[\overline{C'D'} = \frac{3}{2} + \frac{9}{4} = \frac{15}{4}\] 剛好是 \(\overline{CD} = 15\) 的 \(\frac{1}{4}\)。
A 錯：中心在線段上時，縮放後與原線段在同一直線上。
C 錯：縮放 \(\frac{1}{4}\) 倍是縮小，不是乘 4。
D 錯：每個對應點都留在自己那條射線上，不會換邊。

重點 2：角經過縮放，度數不變

重點整理與敘述

  • 角的兩邊是兩條射線。以 \(O\) 為中心，把 \(A\)、\(B\)、\(C\) 都縮放 \(r\) 倍得到 \(A'\)、\(B'\)、\(C'\)，連出 \(\angle A'C'B'\)。
  • 射線縮放後互相平行：\(CA /\!/ C'A'\)、\(CB /\!/ C'B'\)。
  • 直線 \(OC\) 同時截這兩組平行線，同位角相等：\(\angle 1 = \angle 3\)、\(\angle 2 = \angle 4\)，所以 \[\begin{aligned} & \angle A'C'B' = \angle 3 + \angle 4 \\ &= \angle 1 + \angle 2 = \angle ACB \end{aligned}\]
  • 會變成 \(r\) 倍的是長度，不是角度。「一個角縮放 2 倍，度數也變 2 倍」是常見的錯誤。
KEY POINT・角的縮放 一個角經過縮放後，角的度數不變

形成性評量 (角的縮放)

Q3. \(\angle PQR = 38^\circ\)。以 \(O\) 為中心，將 \(\angle PQR\) 縮放 3 倍得到 \(\angle P'Q'R'\)，則 \(\angle P'Q'R'\) 是幾度？

解析：答案為 C。縮放後角的兩邊分別與原來的兩邊平行，同位角相等，所以度數不變，仍是 \(38^\circ\)。
A 錯：把角度也乘了 3，會變 3 倍的只有長度。
B 錯：縮放 3 倍是放大，而且角度根本不變。
D 錯：\(142^\circ\) 是 \(38^\circ\) 的補角，與縮放無關。

Q4. 阿光把一個三角形以 \(O\) 為中心縮放 \(\frac{1}{2}\) 倍。他說：「新三角形的三個內角，也都變成原來的一半。」下列哪一個理由最能說明他錯了？

解析：答案為 D。任何三角形的內角和都是 \(180^\circ\)；三個角都減半，和就只剩 \(90^\circ\)，不可能是三角形。事實上縮放後每一組對應邊都平行，同位角相等，三個內角都不變。
A、C 錯：不論放大或縮小，角度都不變。
B 錯：剛好相反，縮放 \(\frac{1}{2}\) 倍時邊長變一半、角度不變。

重點 3：多邊形的縮放——中心在哪裡都一樣

重點整理與敘述

  • 把圖形上每一個點與中心的距離都乘上同一個倍率，得到的圖形叫做原圖形的縮放圖形。
  • 畫多邊形的縮放圖形：先把各頂點縮放，再把對應點依序用線段連起來。
  • 縮放 \(r\) 倍後：每一邊都變 \(r\) 倍（對應邊成比例）、每一個角都不變（對應角相等），所以周長也變成 \(r\) 倍。
  • 中心在圖形的外部、內部、頂點或邊上都可以。只要倍率相同，得到的縮放圖形全等，只是位置不同；所以沒有必要時，不必特別說中心在哪裡。
KEY POINT・縮放圖形 \(n\) 邊形縮放後仍是 \(n\) 邊形，與原圖形對應邊成比例、對應角相等

形成性評量 (多邊形的縮放)

Q5. 小影以同一個四邊形 \(ABCD\) 為原圖，分別以四邊形外部一點、內部一點、頂點 \(B\)、\(\overline{CD}\) 上一點為中心，各縮放 3 倍，得到四個四邊形。下列敘述何者正確？

解析：答案為 A。不管中心在哪裡，縮放 3 倍後每一邊都是原來的 3 倍、每一個角都不變，四個四邊形的邊與角完全一樣，所以全等，只是擺的位置不同。
B 錯：四個全等，面積一樣大。
C 錯：\(B\) 不動，但 \(\overline{BA'} = 3\overline{BA}\)，每一邊仍是 3 倍。
D 錯：角的縮放與中心位置無關，對應角一定相等。

Q6. 一個五邊形的周長是 18 公分。以任一點為中心將它縮放 \(\frac{2}{3}\) 倍，縮放圖形的周長是多少公分？

解析：答案為 C。五條邊都變成原來的 \(\frac{2}{3}\) 倍，加起來的周長也是 \(\frac{2}{3}\) 倍：\(18 \times \frac{2}{3} = 12\) 公分。
A 錯：\(18 \div \frac{2}{3} = 27\)，把縮小算成放大。
B 錯：\(18 \times \frac{2}{3} \times \frac{2}{3} = 8\)，周長只乘一次倍率。
D 錯：周長會跟著邊長變，不會不變。

重點 4：正 \(n\) 邊形縮放後仍是正 \(n\) 邊形

重點整理與敘述

  • 正 \(n\) 邊形縮放 \(r\) 倍：每一邊都變 \(r\) 倍（邊長仍全部相等），每一個內角都不變，所以仍是正 \(n\) 邊形。
  • 正 \(n\) 邊形的一個內角： \[\frac{180^\circ \times (n - 2)}{n}\] 只跟邊數 \(n\) 有關，跟邊長無關。
  • 兩個邊數相同的正多邊形：每一組對應邊的比都一樣（對應邊成比例），內角都相等（對應角相等），所以任意兩個正 \(n\) 邊形都相似。
  • 「邊數相同」不能省：正三角形與正方形連邊數都不同，不會相似。

形成性評量 (正 n 邊形)

Q7. 邊長 2 公分的正十五邊形，以某一點為中心縮放 4 倍。縮放圖形的邊長與一個內角分別是多少？

解析：答案為 D。邊長變 4 倍：\(2 \times 4 = 8\) 公分；內角不變，仍是正十五邊形的內角： \[\frac{180^\circ \times (15 - 2)}{15} = 156^\circ\] A 錯：邊長是乘 4，不是加 4。
B 錯：把內角也乘了 4。
C 錯：\(144^\circ\) 是正十邊形的內角。

Q8. 下列哪一組中的兩個圖形一定相似？

解析：答案為 C。兩個正二十邊形，邊長的比處處相同、內角都相等，一定相似。
A 錯：頂角 \(30^\circ\) 與頂角 \(100^\circ\) 的等腰三角形，角都不一樣。
B 錯：菱形的邊都成比例，但內角可以不同。
D 錯：只知道角都相等，五條邊不一定一樣長，邊不一定成比例。

重點 5：相似多邊形——寫的順序就是對應關係

重點整理與敘述

  • 兩個邊數相同的多邊形，若對應邊成比例且對應角相等，就稱這兩個多邊形相似。
  • 記作「四邊形 \(ABCD \sim\) 四邊形 \(EFGH\)」，讀作「四邊形 \(ABCD\) 相似於四邊形 \(EFGH\)」。
  • 課本一律照對應的順序寫：第 1 個字母對第 1 個、第 2 個對第 2 個……讀相似式就能直接列出 \[\frac{\overline{AB}}{\overline{EF}} = \frac{\overline{BC}}{\overline{FG}} = \frac{\overline{CD}}{\overline{GH}} = \frac{\overline{DA}}{\overline{HE}}\]
  • 反過來，兩個相似的多邊形，對應邊一定成比例、對應角一定相等。縮放圖形與原圖形一定相似。
  • 找對應頂點看的是角的大小與邊的長短，不是圖擺放的位置：圖轉了一個角度，對應關係不變。
KEY POINT・相似多邊形 相似 \(\Leftrightarrow\) 對應邊成比例 且 對應角相等

形成性評量 (相似多邊形)

Q9. 已知四邊形 \(ABCD \sim\) 四邊形 \(PQRS\)，且頂點依序對應。下列何者一定正確？

解析：答案為 C。依序對應：\(A \leftrightarrow P\)、\(B \leftrightarrow Q\)、\(C \leftrightarrow R\)、\(D \leftrightarrow S\)。\(\overline{AD}\) 對 \(\overline{PS}\)、\(\overline{CD}\) 對 \(\overline{RS}\)，對應邊成比例。
A 錯：\(\overline{AB}\) 的對應邊是 \(\overline{PQ}\)，不是 \(\overline{QR}\)。
B 錯：\(\angle B\) 的對應角是 \(\angle Q\)。
D 錯：對應角是相等，不是互補。

Q10. 四邊形 \(KLMN\) 與四邊形 \(WXYZ\) 相似，且 \(K\)、\(L\)、\(M\)、\(N\) 的對應點依序是 \(Y\)、\(Z\)、\(W\)、\(X\)。下列哪一種寫法同時寫出了正確的對應關係？

解析：答案為 B。照對應的順序寫：\(K\) 對 \(Y\)、\(L\) 對 \(Z\)、\(M\) 對 \(W\)、\(N\) 對 \(X\)，右邊依序寫成 \(YZWX\)。
A 錯：照字母順序寫，對應關係就變成 \(K \leftrightarrow W\)。
C、D 錯：順序對不上，例如 C 寫成 \(K \leftrightarrow X\)。

重點 6：只有邊成比例、或只有角相等，不一定相似

重點整理與敘述

  • 判斷兩個多邊形是否相似，兩個條件都要檢查：對應邊成比例、對應角相等。
  • 只有角相等：長方形和正方形的四個角都是 \(90^\circ\)，但長、寬不相等的長方形，怎麼縮放都不會變成正方形，所以不一定相似。
  • 只有邊成比例：菱形和正方形的四組邊都成比例，但內角不是直角的菱形，縮放後仍不是直角，所以不一定相似。
  • 長方形對摺成小長方形時，長邊、短邊可能互換角色：兩種對應方式都要試，都不成比例才能說不相似。
  • 這條提醒是對四邊形以上說的；三角形另有比較簡單的判別方法（重點 8～10）。

形成性評量 (缺一不可)

Q11. 長方形 \(ABCD\) 中，\(\overline{AB} = 8\)、\(\overline{AD} = 12\)，\(E\)、\(F\) 分別是 \(\overline{AD}\)、\(\overline{BC}\) 的中點。長方形 \(ABFE\) 與長方形 \(ABCD\) 是否相似？

解析：答案為 B。長方形 \(ABFE\) 的兩邊是 \(\overline{AB} = 8\)、\(\overline{AE} = 6\)。
① \(\overline{AB}\) 對 \(\overline{AB}\)、\(\overline{AE}\) 對 \(\overline{AD}\)：\(\frac{8}{8} = 1\)，\(\frac{6}{12} = \frac{1}{2}\)，不相等。
② 短邊對短邊、長邊對長邊：\(\frac{6}{8} = \frac{3}{4}\)，\(\frac{8}{12} = \frac{2}{3}\)，也不相等。
兩種對應方式都不成比例，所以不相似。A 錯：只有角相等不夠。C、D 錯：面積、單一邊長的關係都不是相似的條件。

Q12. 小影說：「兩個四邊形的四組對應邊比都是 \(1 : 2\)，所以它們一定相似。」下列哪一組圖形可以說明她說錯了？

解析：答案為 A。正方形與菱形的四組邊比都是 \(3 : 6 = 1 : 2\)，但正方形的角都是 \(90^\circ\)、菱形有 \(72^\circ\) 的角，對應角不相等，所以不相似——邊都成比例，卻不相似，這就說明她錯了。
B、C 錯：這兩組邊成比例、角也都是直角，確實相似，不能當反例。
D 錯：\(3 : 6 \ne 5 : 9\)，連「四組邊比都是 \(1 : 2\)」都不符合，不能拿來說明。

重點 7：已知相似，求邊長與角度

重點整理與敘述

  • 知道兩個圖形相似、也知道對應順序，就能用對應角相等求角度、用對應邊成比例求邊長。
  • 求角：先從相似式找出對應角，直接相等；剩下的角用內角和（四邊形 \(360^\circ\)）算。
  • 求邊：列比例式，再用「內項乘積等於外項乘積」： \[\begin{aligned} & \overline{AB} : \overline{EF} = \overline{BC} : \overline{FG} \\ \Rightarrow \ & \overline{AB} \times \overline{FG} = \overline{EF} \times \overline{BC} \end{aligned}\]
  • 比例式兩邊要同一個方向：左邊是「原圖 : 新圖」，右邊也要「原圖 : 新圖」，寫反就會算錯。
  • 「多幾公分」這類問題：先求出邊長本身，再相減，不能把差直接照比例搬過去。

形成性評量 (求邊與角)

Q13. 四邊形 \(ABCD \sim\) 四邊形 \(EFGH\)，且頂點依序對應。若 \(\angle A = 84^\circ\)、\(\angle F = 77^\circ\)、\(\angle C = 108^\circ\)，則 \(\angle H\) 是幾度？

解析：答案為 D。對應角相等：\(\angle B = \angle F = 77^\circ\)。\(\angle H\) 的對應角是 \(\angle D\)： \[\begin{aligned} & \angle H = \angle D \\ &= 360^\circ - 84^\circ - 77^\circ - 108^\circ \\ &= 91^\circ \end{aligned}\] A 錯：\(77^\circ\) 是 \(\angle B\)。B 錯：\(84^\circ\) 是 \(\angle E\)。C 錯：\(108^\circ\) 是 \(\angle G\)。

Q14. 長方形 \(ABCD \sim\) 長方形 \(EFGH\)，且頂點依序對應，\(\overline{EF} = 4\) 公分、\(\overline{EH} = 10\) 公分。若 \(\overline{AD}\) 比 \(\overline{EH}\) 多 5 公分，則 \(\overline{AB}\) 比 \(\overline{EF}\) 多幾公分？

解析：答案為 A。\(\overline{AD} = 10 + 5 = 15\)。對應邊成比例： \[\begin{aligned} & \overline{AD} : \overline{EH} = \overline{AB} : \overline{EF} \\ & 15 : 10 = \overline{AB} : 4 \\ & 10\,\overline{AB} = 60,\ \overline{AB} = 6 \end{aligned}\] 所以 \(\overline{AB}\) 比 \(\overline{EF}\) 多 \(6 - 4 = 2\) 公分。
B 錯：把「多 5 公分」直接搬過去，相似是成比例，不是差相同。
C 錯：6 是 \(\overline{AB}\) 本身，還要減掉 \(\overline{EF}\)。
D 錯：比例式寫反（\(15 : 10 = 4 : \overline{AB}\)）會得 \(\overline{AB} = \frac{8}{3}\)，再算 \(4 - \frac{8}{3}\) 就是這個數。

重點 8：AAA（AA）相似性質

重點整理與敘述

  • 三角形不必把邊和角全部檢查完。若 \(\angle A = \angle P\)、\(\angle B = \angle Q\)、\(\angle C = \angle R\)：把 \(\angle A\) 疊到 \(\angle P\) 上，\(\angle B = \angle Q\) 是同位角相等，所以 \(\overline{BC} /\!/ \overline{QR}\)，再由平行線截比例線段，三邊成比例 \(\Rightarrow\) 相似。
  • 已知兩組對應角相等，第三組也一定相等（內角和 \(180^\circ\)），所以兩組角就夠了。
  • A 字型：\(\overline{DE} /\!/ \overline{BC}\) \(\Rightarrow\) \(\angle ADE = \angle B\)、\(\angle AED = \angle C\)（同位角）\(\Rightarrow\) \(\triangle ADE \sim \triangle ABC\)。列式時用整條 \(\overline{AC}\)，不是 \(\overline{EC}\)。
  • 反向等角：\(\angle AED = \angle B\) 加上共用的 \(\angle A\) \(\Rightarrow\) \(\triangle AED \sim \triangle ABC\)，這時 \(E\) 對應 \(B\)、\(D\) 對應 \(C\)，比例式要照這個順序列。
  • 只有一組角相等不夠：一個正三角形和一個也有 \(60^\circ\) 角的直角三角形並不相似。
KEY POINT・AAA（AA）相似性質 兩個三角形有三組（或兩組）對應角相等 \(\Rightarrow\) 兩個三角形相似

Q15. 如圖，\(\triangle ABC\) 中，\(D\)、\(E\) 分別在 \(\overline{AB}\)、\(\overline{AC}\) 上，且 \(\overline{DE} /\!/ \overline{BC}\)。若 \(\overline{AE} = 10\)、\(\overline{EC} = 5\)、\(\overline{DE} = 9\)，則 \(\overline{BC} =\)？

解析：答案為 C。\(\overline{DE} /\!/ \overline{BC}\)，同位角相等，\(\triangle ADE \sim \triangle ABC\)（AA）。\(\overline{AC} = 10 + 5 = 15\)： \[\begin{aligned} & \overline{DE} : \overline{BC} = \overline{AE} : \overline{AC} \\ & 9 : \overline{BC} = 10 : 15 \\ & 10\,\overline{BC} = 135,\ \overline{BC} = \frac{27}{2} \end{aligned}\] A 錯：拿 \(\overline{EC}\) 當對應邊（\(9 : \overline{BC} = 10 : 5\)）。
B 錯：\(9 + 5\) 把長度直接相加。
D 錯：\(\overline{AC}\) 是 \(\overline{AE}\) 的 \(\frac{3}{2}\) 倍，不是 2 倍。

Q16. 如圖，\(\triangle ABC\) 中，\(D\) 在 \(\overline{AB}\) 上、\(E\) 在 \(\overline{AC}\) 上，且 \(\angle ABC = \angle AED\)。若 \(\overline{AD} = 7\)、\(\overline{AE} = 8\)、\(\overline{EC} = 6\)，則 \(\overline{BD} =\)？

解析：答案為 A。\(\angle AED = \angle ABC\)、\(\angle A\) 共用，所以 \(\triangle AED \sim \triangle ABC\)（AA），\(E\) 對應 \(B\)、\(D\) 對應 \(C\)。\(\overline{AC} = 8 + 6 = 14\)： \[\begin{aligned} & \overline{AE} : \overline{AB} = \overline{AD} : \overline{AC} \\ & 8 : \overline{AB} = 7 : 14 \\ & 7\,\overline{AB} = 112,\ \overline{AB} = 16 \end{aligned}\] \(\overline{BD} = 16 - 7 = 9\)。
B 錯：16 是 \(\overline{AB}\)，還要減 \(\overline{AD}\)。
C、D 錯：誤把 \(D\) 對 \(B\)、\(E\) 對 \(C\)（\(7 : \overline{AB} = 8 : 14\)），得 \(\overline{AB} = \frac{49}{4}\)，D 是它、C 是它再減 7。

重點 9：SAS 相似性質——角要夾在兩組邊中間

重點整理與敘述

  • 兩個三角形有一組對應角相等，而且夾這個角的兩組對應邊成比例 \(\Rightarrow\) 相似。
  • 理由：把 \(\angle A\) 疊到 \(\angle P\) 上，\(\overline{AB} : \overline{PQ} = \overline{AC} : \overline{PR}\)，所以 \(\overline{BC} /\!/ \overline{QR}\)，同位角相等，再用 AAA。
  • 相似性質的 S 是「對應邊成比例」，全等性質的 S 是「對應邊相等」，意思不一樣。
  • X 字型（剪刀）：兩條線段交於一點，對頂角就是那組夾角。夾邊可能「同一條線對同一條線」，也可能交叉對應，兩種都要試。
  • 兩組邊成比例、但相等的角沒有夾在中間（SSA），不一定相似。
KEY POINT・SAS 相似性質 一組對應角相等，且夾這個角的兩組對應邊成比例 \(\Rightarrow\) 相似

Q17. 如圖，\(\overline{AE}\) 與 \(\overline{BD}\) 交於 \(C\)。若 \(\overline{AC} = 4\)、\(\overline{CE} = 10\)、\(\overline{BC} = 6\)、\(\overline{CD} = 15\)、\(\overline{AB} = 5\)，則 \(\overline{DE} =\)？

解析：答案為 D。\(\overline{AC} : \overline{EC} = 4 : 10 = 2 : 5\)，\(\overline{BC} : \overline{DC} = 6 : 15 = 2 : 5\)，夾角 \(\angle ACB = \angle ECD\)（對頂角），所以 \(\triangle ACB \sim \triangle ECD\)（SAS），\(A\) 對 \(E\)、\(B\) 對 \(D\)： \[\begin{aligned} & \overline{AB} : \overline{ED} = 2 : 5 \\ & 5 : \overline{DE} = 2 : 5,\ \overline{DE} = \frac{25}{2} \end{aligned}\] A 錯：把比例反過來，算成縮小。
B 錯：交叉對應（\(5 : \overline{DE} = 6 : 10\)），但 \(4 : 15 \ne 6 : 10\)，這樣對應不成比例。
C 錯：\(5 + 6\) 把長度直接相加。

Q18. \(\triangle ABC\) 與 \(\triangle DEF\) 中，\(\angle A = \angle D\)，且 \(\overline{AB} : \overline{DE} = \overline{BC} : \overline{EF} = 2 : 3\)。下列何者正確？

解析：答案為 B。夾 \(\angle A\) 的兩邊是 \(\overline{AB}\)、\(\overline{AC}\)，題目給的卻是 \(\overline{AB}\)、\(\overline{BC}\)：\(\angle A\) 不是這兩組邊的夾角（SSA），可能畫出兩種形狀，不一定相似。
A 錯：SAS 的角必須夾在兩組成比例的邊中間。
C 錯：SSS 要三組邊都成比例，這裡只有兩組。
D 錯：也有可能剛好相似，只是不能確定。

重點 10：SSS 相似性質——短對短、長對長

重點整理與敘述

  • 兩個三角形的三組對應邊成比例 \(\Rightarrow\) 相似。
  • 理由：把 \(\triangle ABC\) 縮放 \(r\) 倍得到 \(\triangle A_1B_1C_1\)，它與 \(\triangle PQR\) 三邊相等（SSS 全等），角都相等；而縮放不改變角度，所以 \(\triangle ABC\) 與 \(\triangle PQR\) 的對應角相等。
  • 做法：兩個三角形的邊各自由短排到長，最短對最短、中間對中間、最長對最長，三個比都相等才相似。
  • 找對應頂點：對應邊所對的角是對應角。例如最短邊對面的角，對應另一個三角形最短邊對面的角。
  • 只有兩組邊成比例不夠：一個正三角形和一個等腰直角三角形，可以有兩組邊成比例，卻不相似。
KEY POINT・SSS 相似性質 兩個三角形有三組對應邊成比例 \(\Rightarrow\) 兩個三角形相似

Q20. 四邊形 \(ABCD\) 中，\(\overline{AB} = 4\)、\(\overline{AD} = 7\)、\(\overline{BD} = 8\)、\(\overline{BC} = 16\)、\(\overline{CD} = 14\)。\(\angle A\) 與 \(\triangle BDC\) 的哪一個內角相等？

解析：答案為 A。\(\triangle ABD\) 三邊由短到長是 4、7、8，\(\triangle DBC\) 是 8、14、16，比都是 \(\frac{1}{2}\)，所以 \(\triangle ABD \sim \triangle DBC\)（SSS）。
\(\angle A\) 對著 \(\triangle ABD\) 的最長邊 \(\overline{BD} = 8\)；\(\triangle DBC\) 的最長邊是 \(\overline{BC} = 16\)，它對著的角是 \(\angle BDC\)，所以 \(\angle A = \angle BDC\)。
B 錯：\(\angle DBC\) 對著 \(\overline{CD} = 14\)，對應的是 \(\angle ABD\)。
C 錯：\(\angle BCD\) 對著 \(\overline{BD} = 8\)，對應的是 \(\angle ADB\)。
D 錯：三組邊成比例，對應角一定相等。

重點 11：判別相似，該用哪一個性質？

重點整理與敘述

  • 先整理已知：有幾組角相等？有幾組邊成比例？相等的角是不是夾在兩組邊中間？
已知條件結論
兩組（或三組）角相等AA 相似
兩組邊成比例，夾角相等SAS 相似
三組邊成比例SSS 相似
只有一組角相等不能判定
兩組邊成比例，角沒有夾在中間不能判定
只有兩組邊成比例不能判定
  • 隱藏的條件：共用角、對頂角、平行線的同位角與內錯角、用內角和推出的第三個角。
  • 要「作」一個相似三角形時，角度照抄、邊長照比例。把角也縮成一半，畫出來的三角形就不相似了。
  • 寫相似式時，頂點照對應的順序寫。

Q21. 如圖，\(\triangle ABC\) 中，\(D\) 在 \(\overline{AB}\) 上、\(E\) 在 \(\overline{AC}\) 上，\(\overline{AD} = 3\)、\(\overline{DB} = 5\)、\(\overline{AE} = 4\)、\(\overline{EC} = 2\)。\(\triangle ABC \sim \triangle AED\) 的理由是下列哪一個性質？

B 錯：\(\overline{BC}\)、\(\overline{DE}\) 的長度沒有給。
D 錯：條件剛好夠用 SAS。

Q22. 已知 \(\triangle ABC\) 中，\(\overline{AC} = 12\)、\(\angle A = 70^\circ\)、\(\angle B = 50^\circ\)。小影作 \(\triangle DEF\)：\(\overline{DF} = 6\)、\(\angle D = 35^\circ\)、\(\angle E = 25^\circ\)；阿光作 \(\triangle DEF\)：\(\overline{DF} = 4\)、\(\angle D = 70^\circ\)、\(\angle F = 60^\circ\)。誰作出的三角形一定與 \(\triangle ABC\) 相似？

解析：答案為 D。\(\angle C = 180^\circ - 70^\circ - 50^\circ = 60^\circ\)。阿光的 \(\angle D = 70^\circ = \angle A\)、\(\angle F = 60^\circ = \angle C\)，兩組角相等，根據 AA 相似性質一定相似（邊長是多少都不影響）。
小影把邊和角都減半，但相似圖形的對應角不會變：他的 \(\angle F = 120^\circ\)，與 \(\triangle ABC\) 的角都對不上，不相似。所以 A、B、C 都錯。

小節總結與核心回顧

縮放與相似速查表

  • 縮放：對應點在射線 \(OA\) 上，\(\overline{OA'} = r\,\overline{OA}\)；\(r \gt 1\) 放大、\(0 \lt r \lt 1\) 縮小。
  • 線段縮放後平行（或共線）、長度 \(r\) 倍；角縮放後度數不變。
  • 多邊形縮放後對應邊成比例、對應角相等；中心在哪裡結果都全等。
  • 相似多邊形：對應邊成比例且對應角相等，兩個都要；任意兩個正 \(n\) 邊形都相似。
  • 三角形相似：AA、SAS（角要夾在中間）、SSS（短對短、長對長）。
  • 相似式照對應順序寫，求邊列比例式、求角找對應角。

回到暗房：放大機為什麼不會把人拉胖

燈泡就是縮放中心

放大機的燈泡從一點往下照，底片上每一點的光都沿著直線落到相紙上。燈頭拉高一倍，每一點到燈泡的距離都變成原來的 2 倍——長和寬一起變 2 倍，角度一個也沒變，所以相片和底片相似。

阿光的錯在哪裡

只把寬拉成 2 倍，長寬的比就變了，對應邊不成比例，相片和原圖不相似，人看起來當然變胖。
