3-3 三角形的全等性質

養蜂花園的蜂箱要配兩片一模一樣的三角形山牆板，小蜜和阿蜂想知道：要比對幾個條件，才能確定兩個三角形完全疊合？這一節先認識全等的意義與記號，再用尺規作圖找出五種只要三個條件就夠的全等性質——SSS、SAS、RHS、ASA、AAS，也看看為什麼 SSA 和 AAA 不行，最後學會在圖形裡找出藏起來的條件、用全等算出邊長、角度與面積。

全等的意義 對應邊角 SSS SAS SSA 不行 RHS ASA AAS AAA 不行 判別性質 隱藏條件 全等的應用

課前暖身漫畫：六個條件都要量嗎？

阿蜂要再做一片和舊的一模一樣的三角形山牆板，正煩惱三個邊、三個角是不是都得量。小蜜拿來三根木條：只要三根的長度照抄，釘起來的三角形就怎麼推也推不變形——三邊一確定，三角形就確定了。

重點 1：全等的意義——搬過去能完全疊合

重點整理與敘述

  • 全等：兩個圖形經過平移、旋轉或翻轉後可以完全疊合，就稱這兩個圖形全等。全等的圖形形狀一樣、大小也相等。
  • 記號：\(\triangle ABC\) 與 \(\triangle DEF\) 全等，記作 \(\triangle ABC \cong \triangle DEF\)，讀作「\(\triangle ABC\) 全等於 \(\triangle DEF\)」。
  • 疊合在一起的頂點叫對應點，疊合在一起的邊叫對應邊，疊合在一起的角叫對應角。
  • 若 \(\triangle ABC \cong \triangle DEF\)（\(A\)、\(B\)、\(C\) 依序對應 \(D\)、\(E\)、\(F\)），則
    • 對應邊相等：\(\overline{AB} = \overline{DE}\)、\(\overline{BC} = \overline{EF}\)、\(\overline{AC} = \overline{DF}\)
    • 對應角相等：\(\angle A = \angle D\)、\(\angle B = \angle E\)、\(\angle C = \angle F\)
  • 本書的寫法依對應的順序：記號裡第 1 個字母對第 1 個字母、第 2 個對第 2 個、第 3 個對第 3 個。
  • 面積相等不一定全等：底 \(6\)、高 \(2\) 的三角形和底 \(3\)、高 \(4\) 的三角形面積都是 \(6\)，形狀卻不一樣。
KEY POINT・全等 全等 \(\Leftrightarrow\) 能完全疊合 \(\Rightarrow\) 三組對應邊、三組對應角全部相等。

形成性評量 (全等的意義)

Q1. 已知 \(\triangle PQR \cong \triangle XYZ\)（依對應順序寫）。下列哪一個敘述錯誤？

解析：答案為 D。依記號的順序，\(P\) 對應 \(X\)、\(Q\) 對應 \(Y\)、\(R\) 對應 \(Z\)，所以 \(\angle Q\) 的對應角是 \(\angle Y\)，不是 \(\angle Z\)。
A、C 對：\(\overline{QR}\) 的兩端對應 \(Y\)、\(Z\)；\(\overline{PR}\) 的兩端對應 \(X\)、\(Z\)。
B 對：\(R\) 和 \(Z\) 都排在第 3 個。

Q2. 下列哪一組的兩個三角形一定全等？

解析：答案為 C。邊長都是 \(7\) 公分的正三角形，三個邊、三個角都一樣，搬過去可以完全疊合。
A 錯：底 \(6\)、高 \(4\) 和底 \(8\)、高 \(3\) 面積都是 \(12\)，形狀卻不同。
B 錯：三邊 \(6\)、\(6\)、\(6\) 和 \(5\)、\(6\)、\(7\) 周長都是 \(18\)，卻不能疊合。
D 錯：三個角都是 \(60^\circ\) 的是正三角形，但邊長可以是 \(2\)，也可以是 \(9\)，大小不一定相同。

重點 2：依記號的順序找對應，求出邊與角

重點整理與敘述

  • 先配對，再寫等式：把記號兩邊的字母依位置一個一個配對，不要看圖上的位置猜。例如 \(\triangle ABC \cong \triangle FDE\) 時，\(A \leftrightarrow F\)、\(B \leftrightarrow D\)、\(C \leftrightarrow E\)。
  • 對應邊由兩個頂點一起配對：\(\overline{BC}\) 的兩端 \(B\)、\(C\) 對應 \(D\)、\(E\)，所以 \(\overline{BC} = \overline{DE}\)。
  • 求角：先把題目給的角搬到同一個三角形裡（對應角相等），再用內角和 \(180^\circ\) 求第三個角，最後搬回另一個三角形。
  • 求未知數：邊或角寫成含 \(x\) 的式子時，讓對應的兩個量相等，列方程式解出 \(x\)，再代回去求其他量。
\(\triangle ABC \cong \triangle FDE\)對應角對應邊
第 1 個字母\(\angle A = \angle F\)\(\overline{AB} = \overline{FD}\)
第 2 個字母\(\angle B = \angle D\)\(\overline{BC} = \overline{DE}\)
第 3 個字母\(\angle C = \angle E\)\(\overline{CA} = \overline{EF}\)
KEY POINT・對應 記號裡排在同一個位置的字母就是對應點；對應邊、對應角都由對應點決定。

形成性評量 (依對應求邊與角)

Q3. 已知 \(\triangle KLM \cong \triangle RST\)，其中 \(K\)、\(L\)、\(M\) 的對應點依序是 \(R\)、\(S\)、\(T\)。若 \(\angle K = 47^\circ\)、\(\angle T = 68^\circ\)，則 \(\angle L\) 是幾度？

解析：答案為 B。\(M\) 對應 \(T\)，所以 \(\angle M = \angle T = 68^\circ\)。在 \(\triangle KLM\) 中， \[ \angle L = 180^\circ - 47^\circ - 68^\circ = 65^\circ \] A 錯：\(47^\circ\) 是 \(\angle K\)。
C 錯：\(68^\circ\) 是 \(\angle M\)。
D 錯：\(133^\circ\) 只扣掉了 \(\angle K\)，忘了扣 \(\angle M\)。

Q4. 已知 \(\triangle ABC \cong \triangle DEF\)，\(A\)、\(B\)、\(C\) 依序對應 \(D\)、\(E\)、\(F\)。若 \(\overline{AB} = 9\)、\(\overline{BC} = 3x - 2\)、\(\overline{AC} = 2x + 1\)、\(\overline{EF} = x + 8\)，則 \(\triangle DEF\) 的周長是多少？

解析：答案為 A。\(\overline{BC}\) 的對應邊是 \(\overline{EF}\)： \[ \begin{aligned} & 3x - 2 = x + 8 \\ &\Rightarrow x = 5 \end{aligned} \] 所以 \(\overline{EF} = \overline{BC} = 13\)、\(\overline{DF} = \overline{AC} = 11\)、\(\overline{DE} = \overline{AB} = 9\)，周長 \(9 + 13 + 11 = 33\)。
B 錯：把 \(\overline{AC}\) 當成 \(\overline{EF}\) 的對應邊，會解出 \(x = 7\)，周長算成 \(9 + 19 + 15 = 43\)。
C 錯：\(13\) 只是 \(\overline{EF}\) 的長。
D 錯：\(5\) 只是 \(x\) 的值。

重點 3：SSS——三組邊對應相等就全等

重點整理與敘述

  • 六個條件不必全比：全等時三組邊、三組角都相等；反過來，只要挑其中三個適當的條件就能確定全等。
  • 兩組邊不夠：固定一邊，另一邊繞著共同的頂點轉，第三邊就跟著變，三角形不只一種。
  • SSS 作圖（已知三邊 \(a\)、\(b\)、\(c\)）：
    1. 作一直線 \(L\)，在 \(L\) 上作 \(\overline{BC} = a\)。
    2. 分別以 \(B\)、\(C\) 為圓心，\(c\)、\(b\) 為半徑，在 \(L\) 的同側各畫一弧，兩弧交於 \(A\)。
    3. 連接 \(\overline{AB}\)、\(\overline{AC}\)，\(\triangle ABC\) 即為所求。
  • 作出來的三角形和原來的三角形完全疊合，所以三邊一確定，三角形就只有一種。
  • 有未知數時：先用題目給的那一組相等列式求出 \(x\)，再把每一邊算出來，三組都比對過才能下結論。
KEY POINT・SSS 全等性質 兩個三角形的三組邊對應相等時，這兩個三角形全等。
寫法：\(\because\) 三組邊對應相等，\(\therefore\) 根據 SSS 全等性質，兩三角形全等。

形成性評量 (SSS 全等性質)

Q5. \(\triangle ABC\) 中，\(\overline{AB} = 3x - 4\)、\(\overline{BC} = 15\)、\(\overline{AC} = 2x + 3\)；\(\triangle DEF\) 中，\(\overline{DE} = 11\)、\(\overline{EF} = 15\)、\(\overline{DF} = 13\)。若 \(\overline{AB} = \overline{DE}\)，下列敘述何者正確？

解析：答案為 B。由 \(\overline{AB} = \overline{DE}\)： \[ \begin{aligned} & 3x - 4 = 11 \\ &\Rightarrow x = 5 \end{aligned} \] 於是 \(\overline{AC} = 2 \times 5 + 3 = 13\)。三組邊 \(\overline{AB} = \overline{DE} = 11\)、\(\overline{BC} = \overline{EF} = 15\)、\(\overline{AC} = \overline{DF} = 13\) 全部相等，根據 SSS 全等。
A、D 錯：\(x = 4\) 是把 \(\overline{AC}\) 和 \(\overline{DE}\) 配在一起（\(2x + 3 = 11\)）算出來的，但題目說的是 \(\overline{AB} = \overline{DE}\)。
C 錯：求出 \(x\) 之後第三組邊 \(\overline{AC} = \overline{DF}\) 也相等，三組都相等了。

Q6. 阿蜂要作三邊長為 \(a\)、\(b\)、\(c\) 的 \(\triangle ABC\)，第一步已經作出 \(\overline{BC} = a\)。為了讓 \(\overline{AB} = c\)，下一步應該怎麼畫弧？

解析：答案為 C。\(\overline{AB}\) 的一端是 \(B\)，要讓 \(A\) 到 \(B\) 的距離是 \(c\)，就以 \(B\) 為圓心、\(c\) 為半徑畫弧，\(A\) 一定落在這個弧上。
A 錯：這樣得到的是 \(\overline{AB} = b\)。
B 錯：這樣得到的是 \(\overline{AC} = c\)。
D 錯：半徑 \(a\) 是 \(\overline{BC}\) 的長，和 \(\overline{AB}\) 無關。

重點 4：SAS——兩邊和它們的夾角

重點整理與敘述

  • 已知兩組邊對應相等，再加一組角時要分兩種情況：這個角是兩邊的夾角（重點 4），或是其中一邊的對角（重點 5）。
  • 夾角：夾在兩個已知邊中間的角。\(\angle B\) 是 \(\overline{BA}\) 和 \(\overline{BC}\) 的夾角。
  • SAS 作圖（已知兩邊 \(a\)、\(c\) 及夾角 \(\angle 1\)）：
    1. 作 \(\angle B = \angle 1\)。
    2. 在 \(\angle B\) 的一邊上取 \(A\)，使 \(\overline{AB} = c\)。
    3. 在另一邊上取 \(C\)，使 \(\overline{BC} = a\)。
    4. 連接 \(\overline{AC}\)，\(\triangle ABC\) 即為所求。
  • 記號把 A 寫在兩個 S 中間，就是在提醒：這個角夾在兩邊之間。
  • 共用邊：兩個三角形共用的那一邊，在兩個三角形裡長度當然相同，可以寫成「\(\overline{AD} = \overline{AD}\)（共用邊）」，也可以寫「公用邊」。
KEY POINT・SAS 全等性質 兩個三角形的兩組邊及其夾角分別對應相等時，這兩個三角形全等。

形成性評量 (SAS 全等性質)

Q7. \(\triangle ABC\) 中，\(\overline{AB} = 9\)、\(\overline{BC} = 14\)、\(\angle B = 38^\circ\)。下列哪一個三角形一定與 \(\triangle ABC\) 全等？

解析：答案為 A。\(\triangle ABC\) 的 \(\angle B\) 夾在 \(\overline{AB} = 9\) 和 \(\overline{BC} = 14\) 中間，所以是「兩邊及夾角」，選項 A 的條件完全一樣，根據 SAS 全等。
B、C 錯：\(38^\circ\) 是其中一邊的對角，不是夾角，和 \(\triangle ABC\) 的條件不一樣，不能保證全等。
D 錯：三個角相等只確定形狀，大小可以不同。

Q8. 如圖，四邊形 \(ABCD\) 中連接對角線 \(\overline{BD}\)，\(\overline{AB} = \overline{CD} = 10\)，\(\angle ABD = \angle CDB = 34^\circ\)。若四邊形 \(ABCD\) 的周長是 \(46\)，則 \(\overline{AD}\) 是多少？

解析：答案為 D。在 \(\triangle ABD\) 和 \(\triangle CDB\) 中，\(\overline{AB} = \overline{CD}\)、\(\angle ABD = \angle CDB\)、\(\overline{BD} = \overline{DB}\)（共用邊），根據 SAS 全等，所以 \(\overline{AD} = \overline{CB}\)。 \[ \begin{aligned} & 10 + 10 + 2\overline{AD} = 46 \\ &\Rightarrow \overline{AD} = 13 \end{aligned} \] A 錯：\(26\) 是 \(\overline{AD} + \overline{CB}\)，忘了除以 \(2\)。
B 錯：\(23\) 是周長的一半，沒有先扣掉兩個 \(10\)。
C 錯：\(36\) 只扣掉一個 \(10\)。

重點 5：SSA 不能當全等性質——弧可能交出兩個點

重點整理與敘述

  • SSA：兩組邊對應相等，再加上其中一邊的對角對應相等（角不夾在兩邊中間）。
  • 作作看：作 \(\angle A = \angle 1\)，在一邊上取 \(C\) 使 \(\overline{AC} = b\)，再以 \(C\) 為圓心、\(a\) 為半徑畫弧，看弧和另一邊交在哪裡：
    • \(a\) 比 \(C\) 到另一邊的距離還短：碰不到，作不出三角形。
    • \(a\) 剛好等於這個距離：只碰到一點，那一點的角是直角。
    • \(a\) 比距離長、但比 \(b\) 短：交出 \(B\)、\(B'\) 兩個點，得到 \(\triangle ABC\)、\(\triangle AB'C\) 兩個不同的三角形。
  • 兩個三角形都符合同樣的 SSA 條件卻不全等，所以 SSA 不能作為全等性質。
  • 「不一定全等」不是「一定不全等」：只知道 SSA 時，兩個三角形可能全等、也可能不全等，所以不能拿來判定。
  • 例外：如果那個對角是直角（或鈍角），弧只會在另一邊上交出一點，三角形就只有一種——直角的情形就是下一個重點的 RHS。
KEY POINT・SSA 兩邊及其中一邊的對角對應相等，兩個三角形不一定全等。

形成性評量 (SSA 不一定全等)

Q9. 小蜜依 SSA 的條件作圖：以 \(C\) 為圓心畫弧，交 \(\angle A\) 的一邊於 \(B\)、\(B'\) 兩點（\(B'\) 比較靠近 \(A\)），得到 \(\triangle ABC\) 與 \(\triangle AB'C\)。若 \(\angle AB'C = 117^\circ\)，則 \(\angle ABC\) 是幾度？

解析：答案為 C。\(B\)、\(B'\) 都在同一個弧上，所以 \(\overline{CB} = \overline{CB'}\)，\(\triangle CBB'\) 是等腰三角形，兩底角 \(\angle CBB' = \angle CB'B\)。\(A\)、\(B'\)、\(B\) 在同一直線上， \[ \begin{aligned} \angle CB'B &= 180^\circ - 117^\circ \\ &= 63^\circ \end{aligned} \] 所以 \(\angle ABC = \angle CBB' = 63^\circ\)。兩個三角形 SSA 條件相同，一個角是 \(63^\circ\)、對應的角卻是 \(117^\circ\)，正好說明它們不全等。
A 錯：以為兩個三角形全等、對應角相等。
B 錯：\(54^\circ\) 是 \(180^\circ - 2 \times 63^\circ\)，是 \(\angle BCB'\)。
D 錯：\(27^\circ\) 和題目的角沒有關係。

Q10. \(\angle A\) 是銳角，\(C\) 在 \(\angle A\) 的一邊上，\(\overline{AC} = 13\)，\(C\) 到 \(\angle A\) 另一邊的距離是 \(6\)。要在另一邊上找一點 \(B\)，使 \(\overline{CB} = 9\)，可以作出幾個不同的 \(\triangle ABC\)？

解析：答案為 D。以 \(C\) 為圓心、\(9\) 為半徑畫弧：
半徑 \(9\) 比 \(C\) 到另一邊的距離 \(6\) 長，所以弧會和那條直線交於兩點；
半徑 \(9\) 又比 \(\overline{AC} = 13\) 短，所以 \(A\) 在弧的外面，兩個交點都落在 \(A\) 的同一側、都在 \(\angle A\) 的邊上。
於是作得出 \(2\) 個不同的三角形，這正是 SSA 不能判定全等的原因。

重點 6：RHS——直角三角形的斜邊與一股

重點整理與敘述

  • 為什麼成立：兩個直角三角形的斜邊相等、一股也相等，由畢氏定理 \[ (\text{另一股})^2 = (\text{斜邊})^2 - (\text{一股})^2 \] 另一股也相等，三組邊都相等，就回到 SSS。
  • R、H、S：R 代表直角（Right angle），H 代表斜邊（Hypotenuse），S 代表一邊（Side，這裡是一股）。
  • 三個條件缺一不可：一定要是直角三角形，相等的邊裡一定要有斜邊（直角的對邊）。
  • 作圖：作 \(L \perp M\) 於 \(P\)；以 \(P\) 為圓心、股長為半徑交 \(M\) 於 \(R\)；以 \(R\) 為圓心、斜邊長為半徑交 \(L\) 於 \(Q\)；連 \(\overline{QR}\)。
  • 斜邊一定比兩股都長；股不比斜邊短時，弧碰不到 \(L\)，作不出來。
KEY POINT・RHS 全等性質 兩個直角三角形的斜邊及一股分別對應相等時，這兩個直角三角形全等。

形成性評量 (RHS 全等性質)

Q11. \(\triangle ABC\) 與 \(\triangle DEF\) 中，\(\angle B = \angle E = 90^\circ\)，\(\overline{AC} = \overline{DF} = 26\)，\(\overline{AB} = \overline{DE} = 24\)。兩個三角形根據哪一個性質全等？\(\triangle DEF\) 的面積是多少？

解析：答案為 A。兩個都是直角三角形，\(\overline{AC}\)、\(\overline{DF}\) 是直角的對邊（斜邊），再加一股相等，根據 RHS 全等。另一股 \[ \begin{aligned} \overline{BC} &= \sqrt{26^2 - 24^2} \\ &= \sqrt{100} = 10 \end{aligned} \] 面積 \(= \frac{1}{2} \times 24 \times 10 = 120\)，全等的 \(\triangle DEF\) 面積也是 \(120\)。
B 錯：相等的兩邊是斜邊和一股，直角並不夾在它們中間，不是 SAS。
C 錯：\(240\) 忘了乘 \(\frac{1}{2}\)。
D 錯：直角、斜邊、一股三個條件都有。

Q12. \(\triangle ABC\) 與 \(\triangle DEF\) 中，\(\angle C = \angle F = 90^\circ\)，\(\overline{AB} = \overline{DE} = 17\)，\(\overline{AC} = \overline{DF} = 8\)。\(\overline{EF}\) 的長是多少？

解析：答案為 B。\(\angle C\)、\(\angle F\) 是直角，\(\overline{AB}\)、\(\overline{DE}\) 是斜邊，\(\overline{AC}\)、\(\overline{DF}\) 是一股，根據 RHS，\(\triangle ABC \cong \triangle DEF\)，所以 \(\overline{EF} = \overline{BC}\)： \[ \begin{aligned} \overline{BC} &= \sqrt{17^2 - 8^2} \\ &= \sqrt{225} = 15 \end{aligned} \] A 錯：\(17 - 8 = 9\)，把畢氏定理的平方漏掉了。
C 錯：\(17 + 8 = 25\)。
D 錯：\(17\) 是斜邊，\(\overline{EF}\) 是一股，一定比斜邊短。

重點 7：ASA——兩角和它們的夾邊

重點整理與敘述

  • 兩組角不夠：只知道兩組角對應相等，三角形可以放大縮小，不一定全等。
  • 再加一組邊時也分兩種：這條邊是兩角的夾邊（重點 7），或是其中一角的對邊（重點 8）。
  • ASA 作圖（已知兩角 \(\angle 1\)、\(\angle 2\) 及夾邊 \(a\)）：
    1. 作 \(\overline{BC} = a\)。
    2. 以 \(B\) 為頂點、\(\overline{BC}\) 為一邊，作 \(\angle B = \angle 1\)。
    3. 以 \(C\) 為頂點、\(\overline{BC}\) 為一邊，在同側作 \(\angle C = \angle 2\)。
    4. 兩角的另一邊交於 \(A\)，\(\triangle ABC\) 即為所求。
  • 記號把 S 寫在兩個 A 中間：這條邊夾在兩個角之間。
  • 作得出來的條件：兩個角的和一定要小於 \(180^\circ\)，兩條邊才會相交。
KEY POINT・ASA 全等性質 兩個三角形的兩組角及其夾邊分別對應相等時，這兩個三角形全等。

Q13. 如圖，正方形 \(ABCD\) 中，\(E\)、\(F\) 分別在 \(\overline{AB}\)、\(\overline{AD}\) 上，\(\angle 1 = \angle BCE\)、\(\angle 2 = \angle DCF\)，且 \(\angle 1 = \angle 2 = 17^\circ\)。\(\angle CEF\) 是幾度？

Q14. 阿蜂想用 ASA 作圖：夾邊 \(5\) 公分，兩端的角分別是 \(96^\circ\) 和 \(87^\circ\)。結果會如何？

重點 8：AAS——兩角和其中一角的對邊

重點整理與敘述

  • AAS：兩組角對應相等，再加上其中一個角的對邊對應相等（邊不夾在兩角中間）。
  • 為什麼成立：兩組角相等，由內角和 \(180^\circ\)，第三組角也相等。這時已知的那條邊就夾在另外兩個角中間，變成 ASA。
  • 對應要對好：相等的邊必須對著對應的角。例如 \(\angle B = \angle E\)、\(\angle C = \angle F\) 時，要 \(\overline{AC} = \overline{DF}\)（都是 \(\angle B\)、\(\angle E\) 的對邊）才行；若一個三角形給的是 \(\angle B\) 的對邊、另一個給的是 \(\angle F\) 的對邊，就不能判定。
  • 判定之後：對應邊、對應角都相等，可以拿來求長度、列方程式。
KEY POINT・AAS 全等性質 兩個三角形的兩組角及其中一組角的對邊分別對應相等時，這兩個三角形全等。

Q15. \(\triangle ABC\) 與 \(\triangle DEF\) 中，\(\angle B = \angle E\)、\(\angle C = \angle F\)，\(\overline{AB} = \overline{DE} = 14\)，\(\overline{AC} = 11\)，\(\overline{EF} = 16\)。\(\triangle DEF\) 的周長是多少？

Q16. \(\triangle ABC\) 與 \(\triangle DEF\) 中，\(\angle A = \angle D = 52^\circ\)、\(\angle B = \angle E\)、\(\overline{BC} = \overline{EF}\)；\(\overline{AB} = 9\)、\(\overline{AC} = 19\)、\(\overline{DF} = 4x - 5\)。\(x\) 是多少？

解析：答案為 B。\(\overline{BC}\) 是 \(\angle A\) 的對邊、\(\overline{EF}\) 是 \(\angle D\) 的對邊，由 \(\angle A = \angle D\)、\(\angle B = \angle E\)、\(\overline{BC} = \overline{EF}\)，根據 AAS 全等，所以 \(\overline{DF} = \overline{AC}\)： \[ \begin{aligned} & 4x - 5 = 19 \\ &\Rightarrow x = 6 \end{aligned} \] A 錯：\(\overline{DF}\) 的對應邊是 \(\overline{AC}\)，不是 \(\overline{AB}\)；\(4x - 5 = 9\) 配錯了。
C 錯：\(19\) 是 \(\overline{DF}\) 的長，不是 \(x\)。
D 錯：兩角及其中一角的對邊對應相等，AAS 成立。

重點 9：AAA 不能當全等性質——形狀一樣，大小可以不同

重點整理與敘述

  • 兩個三角形的兩組角對應相等時，由內角和 \(180^\circ\)，第三組角也一定相等。
  • 所以「三組角相等」其實只比「兩組角相等」多了一句廢話，仍然沒有說到任何一條邊。
  • 反例：邊長 \(2\) 和邊長 \(4\) 的兩個正三角形，三個角都是 \(60^\circ\)，卻明顯不能疊合。
  • 三個角只決定三角形的形狀，不決定大小：同一個形狀可以等比例放大、縮小。
  • 到目前為止，能判定全等的只有 SSS、SAS、RHS、ASA、AAS 五種；SSA、AAA 都不能。
KEY POINT・AAA 三組角對應相等，兩個三角形不一定全等——判定全等至少要有一組邊。

Q18. 兩個三角形的三個角都是 \(41^\circ\)、\(76^\circ\)、\(63^\circ\)。其中一個的最短邊是 \(5\) 公分，另一個的最短邊是 \(8\) 公分。這兩個三角形的關係是？

重點 10：判別該用哪一個全等性質

重點整理與敘述

  • 第一步：數一數。相等的邊有幾組（S）、相等的角有幾組（A）。
  • 三組邊：SSS。
  • 兩邊一角：角夾在兩邊中間 → SAS；是直角三角形而且相等的邊有斜邊 → RHS；其他 → SSA，不一定全等。
  • 一邊兩角：邊夾在兩角中間 → ASA；邊是其中一角的對邊 → AAS（要對好對應）。
  • 三組角：AAA，不一定全等。
  • 圖上的記號：刻痕條數相同的邊相等、弧條數相同的角相等、小方塊代表直角。
全等性質全等條件
SSS三組邊分別對應相等
SAS兩組邊及其夾角分別對應相等
RHS直角三角形的斜邊及一股分別對應相等
ASA兩組角及其夾邊分別對應相等
AAS兩組角及其中一組角的對邊分別對應相等
KEY POINT・判別 先數組數，再看「夾」的位置：角夾在兩邊中間是 SAS，邊夾在兩角中間是 ASA。

重點 11：找出圖裡藏起來的條件

重點整理與敘述

  • 很多題目只寫兩個條件，第三個條件藏在圖裡，要自己找出來：
    • 共用邊：兩個三角形共用一條邊，寫成 \(\overline{AD} = \overline{AD}\)（共用邊）。
    • 共用角：兩個三角形用到同一個頂點的同一個角，寫成 \(\angle C = \angle C\)（共用角）。
    • 對頂角：兩條直線相交，對頂角相等。
    • 垂直給直角；中點給兩段等長；正方形給四邊相等、四個直角。
  • 說明的格式：列出三個條件，每一個後面用括號寫理由，最後寫「根據某某全等性質」： \[ \begin{aligned} &\because \overline{AB} = \overline{AC}\ (\text{已知}) \\ &\phantom{\because}\ \overline{BD} = \overline{CD}\ (\text{已知}) \\ &\phantom{\because}\ \overline{AD} = \overline{AD}\ (\text{共用邊}) \end{aligned} \] \(\therefore\) 根據 SSS 全等性質，\(\triangle ABD \cong \triangle ACD\)。
KEY POINT・找條件 題目只給兩個條件時，先找共用邊、共用角、對頂角。

重點 12：全等的應用——先證全等，再求邊、角、面積

重點整理與敘述

  • 兩段式：⑴ 找三個條件，說明兩個三角形全等；⑵ 用「對應邊相等」「對應角相等」求出題目要的量。
  • 求角：全等給的是整個角相等。兩個相等的角若有重疊的部分，各自扣掉重疊的那一塊，剩下的也相等。
  • 求面積：全等的兩個三角形面積相等，可以「一塊換一塊」：
    • 四邊形被對角線分成兩個全等三角形：面積是其中一個的 \(2\) 倍。
    • 切掉一塊、在別處補上一塊全等的，總面積不變。
  • 等腰三角形：證出兩條邊相等後，底角相等，就能接著求角。
KEY POINT・應用 全等是工具：證完全等，才能放心地說「這兩條邊一樣長」「這兩個角一樣大」。

D 錯：\(38^\circ\) 是重疊的 \(\angle ABE\)。

Q24. 如圖，正方形 \(ABCD\) 的邊長是 \(16\)，\(P\)、\(Q\) 分別是 \(\overline{AB}\)、\(\overline{BC}\) 的中點，延長 \(\overline{PQ}\) 交直線 \(DC\) 於 \(R\)。四邊形 \(APRD\) 的面積是多少？

解析：答案為 A。在 \(\triangle BPQ\) 與 \(\triangle CRQ\) 中，\(\angle B = \angle QCR = 90^\circ\)、\(\overline{BQ} = \overline{CQ}\)（\(Q\) 是中點）、\(\angle BQP = \angle CQR\)（對頂角），根據 ASA 全等，兩塊面積相等。四邊形 \(APRD\) 等於正方形切掉 \(\triangle BPQ\)、再補上 \(\triangle CRQ\)，面積不變： \[ 16 \times 16 = 256 \] B 錯：\(224\) 只切掉 \(\triangle BPQ\)（面積 \(32\)），忘了補上 \(\triangle CRQ\)。
C 錯：\(288\) 多加了一塊 \(32\)。
D 錯：\(192\) 扣掉了兩塊 \(32\)。

小節總結與核心回顧

全等性質速查表

  • 全等：平移、旋轉、翻轉後完全疊合；\(\triangle ABC \cong \triangle DEF\) 依對應順序寫。
  • 對應：記號裡同一個位置的字母是對應點；全等 \(\Rightarrow\) 對應邊、對應角都相等。
  • SSS：三組邊。
  • SAS：兩邊及其夾角。
  • RHS：直角三角形的斜邊及一股。
  • ASA：兩角及其夾邊（兩角和小於 \(180^\circ\)）。
  • AAS：兩角及其中一角的對邊（內角和補出第三角，變成 ASA）。
  • 不能用：SSA（可能作出兩個三角形）、AAA（可以放大縮小）。
  • 找條件：共用邊、共用角、對頂角、垂直、中點。

回到養蜂花園：一模一樣的山牆板

三根木條就夠

阿蜂後來明白，要做一片和舊板一模一樣的三角形山牆板，不必把三個邊、三個角全量一遍：照舊板量出三根木條的長度，釘起來就是同一個三角形（SSS）。三根木條釘死的三角形推不變形，這也是蜂箱屋架、橋樑都用三角形的原因。

兩根木條加一個角，要看角在哪

如果只有兩根木條和一個角度，角要夾在兩根木條中間（SAS）才保證一樣；角若在其中一根的另一端（SSA），可能釘出兩種不同的板子。
