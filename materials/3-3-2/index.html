3-2 利用十字交乘法做因式分解

回到蒙德里安的色塊拼板工作室：這一次色塊既不是完全平方、也沒有公因式，要怎麼找出長方形的長和寬？這一節學十字交乘法——口訣是看兩端、湊中間。先做 \(x^2\) 係數是 \(1\) 的（常數項為正、為負），再做 \(x^2\) 係數不是 \(1\) 的，最後綜合運用：先提出 \(-1\) 或公因數、找兩個多項式的公因式、反求係數，以及用紙片拼長方形。

看兩端湊中間 常數項正 常數項負 不能分解 首項不為 1 對調正負號 提出 −1 先提公因數 公因式 反求係數 拼長方形

課前暖身漫畫：六塊黃色方塊怎麼排？

小格倒出 1 塊紅色大正方形、5 條藍色長條、6 塊黃色小方塊，面積合起來是 \(x^2 + 5x + 6\)。阿方先把 6 塊黃色排成一長條，怎麼也拼不起來；小格改把黃色排成 \(2\) 乘 \(3\) 的方陣，2 條藍色直立在紅色右邊、3 條橫放在下面，剛好拼成長 \(x + 2\)、寬 \(x + 3\) 的長方形。黃色要拆成哪兩個數相乘，藍色才剛好用完——這就是十字交乘法要找的那兩個數。

重點 1：十字交乘的由來——看兩端、湊中間

重點整理與敘述

  • 先展開： \[\begin{aligned} & (x + a)(x + b) \\ &= x^2 + ax + bx + ab \\ &= x^2 + (a + b)x + ab \end{aligned}\]
  • 倒過來就是因式分解：要分解 \(x^2 + px + q\)，只要找到兩數 \(a\)、\(b\)，使得 \(a + b = p\)、\(ab = q\)。
  • 十字交乘的直式：左欄寫 \(x\)、\(x\)（相乘得 \(x^2\)），右欄寫 \(a\)、\(b\)（相乘得常數項），交叉相乘的 \(bx\) 與 \(ax\) 加起來就是 \(x\) 項。
  • 口訣：看兩端（\(x^2\) 項與常數項）、湊中間（\(x\) 項）。
  • 例：\((x + 2)(x + 5) = x^2 + 7x + 10\)，其中 \(7 = 2 + 5\)、\(10 = 2 \times 5\)。
  • 習慣上先從乘積找：先列出相乘等於 \(q\) 的兩數，再檢查相加是不是 \(p\)。
KEY POINT・十字交乘法 已知 \(x^2 + px + q\)，若有兩數 \(a\)、\(b\) 使得 \(a + b = p\)、\(ab = q\)，則 \[x^2 + px + q = (x + a)(x + b)\]

形成性評量 (看兩端、湊中間)

Q1. 若 \(x^2 - 2x - 35\) 可以因式分解成 \((x + a)(x + b)\)，則 \(a + b\) 與 \(ab\) 分別為何？

解析：答案為 A。\((x + a)(x + b)\) 展開是 \(x^2 + (a + b)x + ab\)，對照 \(x^2 - 2x - 35\)：\(x\) 項係數 \(-2\) 是 \(a + b\)，常數項 \(-35\) 是 \(ab\)。（實際上這兩數是 \(5\) 與 \(-7\)。）
B 錯：\(x\) 項係數是 \(-2\)，負號不能丟。
C 錯：常數項是 \(-35\)。
D 錯：兩個對調了；兩數的和對應 \(x\) 項係數，兩數的積對應常數項。

Q2. 用十字交乘法分解 \(x^2 + 11x + 24\) 時，要找的兩數 \(a\)、\(b\) 必須滿足哪兩個條件？

解析：答案為 B。看兩端：常數項 \(24\) 是兩數的乘積；湊中間：\(x\) 項係數 \(11\) 是兩數的和。符合的是 \(3\) 和 \(8\)： \[x^2 + 11x + 24 = (x + 3)(x + 8)\] A 錯：和與積對調了。
C 錯：交叉相乘的兩項是相加，不是相減。
D 錯：常數項是 \(+24\)。

重點 2：常數項為正——兩數同號，跟著 \(x\) 項係數的號

重點整理與敘述

  • \(q \gt 0\)：兩數相乘是正的，所以兩數同號（同正或同負）。
  • \(p \gt 0\)：兩數都正；\(p \lt 0\)：兩數都負。所以只要試一半就好。
  • 例：分解 \(x^2 - 9x + 20\)。\(x\) 項係數是負的，只試兩個負數：
兩數（相乘 \(20\)）相加判斷
\(-1\)、\(-20\)\(-21\)不合
\(-2\)、\(-10\)\(-12\)不合
\(-4\)、\(-5\)\(-9\)合
  • 所以 \(x^2 - 9x + 20 = (x - 4)(x - 5)\)。
  • 找到一組就停：只要有一組合，其他組合就不必再試。
  • 驗算：\((-4) \times (-5) = 20\)、\((-4) + (-5) = -9\)，兩端與中間都對上。

形成性評量 (常數項為正)

Q3. 因式分解 \(x^2 - 14x + 45\)，結果為何？

解析：答案為 C。常數項 \(45\) 是正的，兩數同號；\(x\) 項係數 \(-14\) 是負的，兩數都負。\(45\) 的因數對 \(1\)、\(45\)；\(3\)、\(15\)；\(5\)、\(9\) 中，和是 \(14\) 的是 \(5\)、\(9\)：\((-5) + (-9) = -14\)、\((-5) \times (-9) = 45\)。
A 錯：\((-3) + (-15) = -18\)。
B 錯：兩數都正，中間項會是 \(+14x\)。
D 錯：\((-5) \times 9 = -45\)，常數項變成負的。

Q4. 因式分解 \(x^2 - 11x + 18\)，結果為何？

解析：答案為 D。常數項 \(18\) 是正的、\(x\) 項係數 \(-11\) 是負的，兩數都負：\((-2) + (-9) = -11\)、\((-2) \times (-9) = 18\)。
A 錯：兩數都正，中間項會是 \(+11x\)。
B 錯：\((-3) + (-6) = -9\)。
C 錯：\(2 \times (-9) = -18\)，常數項變成負的。

重點 3：常數項為負——一正一負，大的跟著 \(x\) 項係數的號

重點整理與敘述

  • \(q \lt 0\)：兩數相乘是負的，所以兩數一正一負。
  • 一正一負相加，結果的大小是兩數的差，正負號跟著絕對值大的那一個。
  • 步驟：先找「差」是 \(|p|\) 的那一對，再讓大的那個跟 \(p\) 同號。
  • 例：分解 \(x^2 + 5x - 24\)。\(24\) 的因數對 \(1\)、\(24\)；\(2\)、\(12\)；\(3\)、\(8\)；\(4\)、\(6\)，差是 \(5\) 的是 \(3\)、\(8\)。\(x\) 項係數是正的，大的 \(8\) 取正： \[x^2 + 5x - 24 = (x - 3)(x + 8)\]
  • 符號放反：寫成 \((x + 3)(x - 8)\) 的話，中間變成 \(-5x\)。差對了、號錯了，把兩數的正負對調就好。

Q5. 因式分解 \(x^2 + 6x - 27\)，結果為何？

解析：答案為 B。常數項 \(-27\) 是負的，兩數一正一負。\(27\) 的因數對 \(1\)、\(27\)（差 \(26\)）與 \(3\)、\(9\)（差 \(6\)），選 \(3\)、\(9\)；\(x\) 項係數 \(6\) 是正的，大的 \(9\) 取正：\((-3) + 9 = 6\)、\((-3) \times 9 = -27\)。
A 錯：符號放反，中間項會是 \(-6x\)。
C 錯：常數項會是 \(+27\)。
D 錯：中間項會是 \(26x\)。

Q6. 小翊把 \(x^2 - 17x - 60\) 分解成 \((x - 5)(x - 12)\)。下列敘述何者正確？

解析：答案為 D。小翊只檢查了和，沒檢查積：\((-5) \times (-12) = 60\)，不是 \(-60\)。常數項是負的，兩數要一正一負：\(60\) 的因數對裡差是 \(17\) 的是 \(3\)、\(20\)，\(x\) 項係數是負的，大的 \(20\) 取負： \[\begin{aligned} & x^2 - 17x - 60 \\ &= (x + 3)(x - 20) \end{aligned}\] A 錯：兩端也要對上，常數項錯了。
B 錯：\(5 + (-12) = -7\)，中間項不對。
C 錯：符號放反，中間項會是 \(+17x\)。

重點 4：列完因數對都不合，就不能分解；缺 \(x\) 項當作 \(0x\)

重點整理與敘述

  • 把常數項所有的整數因數對都列出來，沒有一組的和等於 \(x\) 項係數，就不能用十字交乘法分解（寫不成兩個整係數一次式的乘積）。
  • 例：\(x^2 + 4x + 8\)。\(8\) 的因數對 \(1\)、\(8\)；\(2\)、\(4\)；\(-1\)、\(-8\)；\(-2\)、\(-4\)，和是 \(9\)、\(6\)、\(-9\)、\(-6\)，沒有 \(4\)，所以不能分解。
  • 缺 \(x\) 項：當成 \(0x\) 照做。\(x^2 - 25 = x^2 + 0x - 25\)，找相乘 \(-25\)、相加 \(0\) 的兩數 \(5\)、\(-5\)： \[x^2 - 25 = (x + 5)(x - 5)\] 和平方差公式的結果一樣。
  • \(x^2 + 25\) 不能分解：常數項是正的，兩數同號，相加不可能是 \(0\)。
  • 缺常數項：\(x^2 + px = x(x + p)\)，直接提公因式。

形成性評量 (不能分解與缺 \(x\) 項)

Q7. 下列哪一個多項式不能用十字交乘法分解成兩個整係數一次式的乘積？

解析：答案為 C。\(30\) 的正因數對 \(1\)、\(30\)；\(2\)、\(15\)；\(3\)、\(10\)；\(5\)、\(6\)，和是 \(31\)、\(17\)、\(13\)、\(11\)，沒有 \(10\)（兩數都負時和是負的，更不可能），所以不能分解。
A 可以：\(3 + 10 = 13\)，得 \((x + 3)(x + 10)\)。
B 可以：看成 \(x^2 + 0x - 36\)，得 \((x + 6)(x - 6)\)。
D 可以：\(5 + (-6) = -1\)，得 \((x + 5)(x - 6)\)。

Q8. 關於 \(x^2 - 36\)，下列敘述何者正確？

解析：答案為 D。缺 \(x\) 項當成 \(0x\)：找相乘 \(-36\)、相加 \(0\) 的兩數，是 \(6\) 與 \(-6\)。
A 錯：缺 \(x\) 項一樣能做十字交乘。
B 錯：\((x - 6)^2 = x^2 - 12x + 36\)。
C 錯：\((x + 6)(x - 6) = x^2 - 36\)；\(x^2 + 36\) 的常數項是正的，兩數同號，和不可能是 \(0\)，不能分解。

重點 5：\(x^2\) 係數不為 \(1\)——左欄也要拆，右欄上下對調要分開試

重點整理與敘述

  • 分解 \(ax^2 + bx + c\)：左欄把 \(a\) 拆成 \(a_1 \times a_2\)，右欄把 \(c\) 拆成 \(c_1 \times c_2\)。
  • 交叉相乘：左下乘右上、左上乘右下，兩項相加要等於 \(bx\)。
  • 右欄上下對調，結果不一樣：同樣是 \(2\)、\(5\)，放「上 \(2\) 下 \(5\)」或「上 \(5\) 下 \(2\)」，交叉相乘的對象不同，中間項也不同，兩種都要試。
  • 例：\(3x^2 + 11x + 10\)，左欄 \(x\)、\(3x\)：
    • 右欄上 \(2\) 下 \(5\)：\(3x \cdot 2 + x \cdot 5 = 11x\)，合。
    • 右欄上 \(5\) 下 \(2\)：\(3x \cdot 5 + x \cdot 2 = 17x\)，不合。
    所以 \[\begin{aligned} & 3x^2 + 11x + 10 \\ &= (x + 2)(3x + 5) \end{aligned}\]
  • \(x^2\) 係數是正的，左欄只拆正因數：拆成 \(-x\)、\(-3x\) 也乘得出 \(3x^2\)，但結果只是兩個因式各差一個負號，跟拆成正的一樣： \[\begin{aligned} & (-x - 2)(-3x - 5) \\ &= (x + 2)(3x + 5) \end{aligned}\]
  • 常數項是正的：右欄同號，跟著 \(b\) 的號。

形成性評量 (\(x^2\) 係數不為 \(1\))

Q9. 因式分解 \(3x^2 + 17x + 10\)，結果為何？

解析：答案為 B。左欄 \(x\)、\(3x\)，右欄上 \(5\) 下 \(2\)：\(3x \cdot 5 + x \cdot 2 = 17x\)，合。
A 錯：同樣是 \(5\)、\(2\)，但位置不同，中間項是 \(6x + 5x = 11x\)。
C 錯：中間項是 \(3x + 10x = 13x\)。
D 錯：中間項是 \(30x + x = 31x\)。

Q10. 因式分解 \(6x^2 - 19x + 10\)，結果為何？

解析：答案為 A。常數項 \(10\) 是正的、\(x\) 項係數是負的，右欄同取負。左欄 \(2x\)、\(3x\)，右欄上 \(-5\) 下 \(-2\)： \[\begin{aligned} & 3x \cdot (-5) + 2x \cdot (-2) \\ &= -15x - 4x = -19x \end{aligned}\] B 錯：右欄同取正，中間項是 \(+19x\)。
C 錯：中間項是 \(-5x - 12x = -17x\)。
D 錯：中間項是 \(-10x - 6x = -16x\)，而且 \(2x - 2\) 還有公因數 \(2\)。

重點 6：常數項為負——中間只差一個號，就對調正負號

重點整理與敘述

  • 常數項是負的：右欄一正一負。
  • 試出來的中間項如果剛好是 \(-b\)（只差一個正負號），把右欄兩個數的正負號對調，交叉相乘的兩項都會變號，中間項就變成 \(b\)——不必重試別的組合。
  • 例：\(3x^2 + 4x - 15\)，左欄 \(x\)、\(3x\)。
    • 右欄上 \(-3\) 下 \(5\)：\(-9x + 5x = -4x\)，只差一個號。
    • 對調成上 \(3\) 下 \(-5\)：\(9x - 5x = 4x\)，合。
    所以 \[\begin{aligned} & 3x^2 + 4x - 15 \\ &= (x + 3)(3x - 5) \end{aligned}\]
  • 絕對值都不對時，對調也沒用，要換一組數字。
  • 每次都要記得驗算兩端：\(x \cdot 3x = 3x^2\)、\(3 \times (-5) = -15\)。

Q11. 因式分解 \(2x^2 + x - 15\)，結果為何？

解析：答案為 C。左欄 \(x\)、\(2x\)，右欄上 \(3\) 下 \(-5\)：\(2x \cdot 3 + x \cdot (-5) = 6x - 5x = x\)，合；兩端 \(2x^2\)、\(-15\) 也對。
A 錯：中間項是 \(-6x + 5x = -x\)，只差一個號——正負對調就是 C。
B 錯：中間項是 \(3x - 10x = -7x\)。
D 錯：中間項是 \(-3x + 10x = 7x\)。

Q12. 分解 \(3x^2 + 7x - 6\) 時，小翊左欄寫 \(x\)、\(3x\)，右欄寫上 \(-3\)、下 \(2\)，交叉相乘得 \(3x \cdot (-3) + x \cdot 2 = -7x\)。他下一步最好怎麼做？

解析：答案為 B。得到 \(-7x\)，跟要的 \(7x\) 只差一個號：右欄改成上 \(3\)、下 \(-2\)，交叉相乘 \(9x - 2x = 7x\)，合： \[3x^2 + 7x - 6 = (x + 3)(3x - 2)\] A 錯：不必重試，對調正負號就好。
C 錯：上 \(2\) 下 \(-3\) 的中間項是 \(6x - 3x = 3x\)，不對。
D 錯：能分解。

重點 7：\(x^2\) 係數為負——先提出 \(-1\)，負號不能丟

重點整理與敘述

  • 先把式子排成降冪（\(x^2\) 項在最前面），看清楚 \(x^2\) 項的係數。例：\(30 - x - x^2\) 排成 \(-x^2 - x + 30\)。
  • 先提出 \(-1\)：括號內每一項都變號，\(x^2\) 係數變成正的： \[\begin{aligned} & -x^2 - x + 30 \\ &= -(x^2 + x - 30) \end{aligned}\]
  • 括號內照平常十字交乘：\(x^2 + x - 30 = (x - 5)(x + 6)\)，所以原式 \(= -(x - 5)(x + 6)\)。
  • 負號不可以丟：也可以把負號併進其中一個因式，三種寫法都對： \[\begin{aligned} & -(x - 5)(x + 6) \\ &= (5 - x)(x + 6) \\ &= (x - 5)(-x - 6) \end{aligned}\]

Q13. 因式分解 \(-x^2 + 4x + 45\)，結果為何？

解析：答案為 C。先提出 \(-1\)： \[\begin{aligned} & -x^2 + 4x + 45 \\ &= -(x^2 - 4x - 45) \\ &= -(x - 9)(x + 5) \end{aligned}\] A 錯：\(-(x + 9)(x - 5)\)\({}= -(x^2 + 4x - 45)\)，中間項變成 \(-4x\)。
B 錯：漏掉了前面的負號。
D 錯：\((x + 9)(-x + 5)\)\({}= -(x + 9)(x - 5)\)，和 A 一樣。

Q14. 因式分解 \(20 - 3x - 2x^2\)，結果為何？

解析：答案為 A。先排成降冪再提出 \(-1\)： \[\begin{aligned} & -2x^2 - 3x + 20 \\ &= -(2x^2 + 3x - 20) \\ &= -(2x - 5)(x + 4) \end{aligned}\] 括號內：左欄 \(2x\)、\(x\)，右欄上 \(-5\) 下 \(4\)，\(-5x + 8x = 3x\)，合。
B 錯：漏掉了負號。
C 錯：\(-(2x + 5)(x - 4)\)\({}= -(2x^2 - 3x - 20)\)，中間項變成 \(+3x\)。
D 錯：\((5 - 2x)(x - 4)\)\({}= -(2x - 5)(x - 4)\)，第二個因式錯了。

重點 8：先提出係數的公因數，再十字交乘

重點整理與敘述

  • 三項係數有公因數時，先提出來，括號內的數字變小、比較好拆： \[\begin{aligned} & 3x^2 - 21x + 36 \\ &= 3(x^2 - 7x + 12) \\ &= 3(x - 3)(x - 4) \end{aligned}\]
  • 括號內若是完全平方式，用乘法公式更快： \[\begin{aligned} & 2x^2 + 20x + 50 \\ &= 2(x^2 + 10x + 25) \\ &= 2(x + 5)^2 \end{aligned}\]
  • 首項是負的，連 \(-1\) 一起提： \[\begin{aligned} & -4x^2 + 8x + 12 \\ &= -4(x^2 - 2x - 3) \\ &= -4(x + 1)(x - 3) \end{aligned}\]
  • 不先提也拆得出來，但拆出的因式裡還藏著公因數，要再提出來才算分解完。
  • 最常見的錯是漏寫提出來的數：寫成 \((x - 3)(x - 4)\) 就只剩原式的 \(\frac{1}{3}\)。

形成性評量 (先提出公因數)

Q15. 因式分解 \(2x^2 + 10x - 72\)，結果為何？

解析：答案為 C。先提出公因數 \(2\)，括號內 \(36\) 的因數對裡差是 \(5\) 的是 \(4\)、\(9\)： \[\begin{aligned} & 2x^2 + 10x - 72 \\ &= 2(x^2 + 5x - 36) \\ &= 2(x + 9)(x - 4) \end{aligned}\] A 錯：漏寫了提出來的 \(2\)。
B 錯：符號放反，括號內會是 \(x^2 - 5x - 36\)。
D 錯：\((x + 12)(x - 3) = x^2 + 9x - 36\)。

Q16. 小妍把 \(3x^2 + 6x - 72\) 分解成 \((3x - 12)(x + 6)\)。下列敘述何者正確？

解析：答案為 D。展開是對的： \[\begin{aligned} & (3x - 12)(x + 6) \\ &= 3x^2 + 18x - 12x - 72 \\ &= 3x^2 + 6x - 72 \end{aligned}\] 但 \(3x - 12 = 3(x - 4)\) 還有公因數，沒有分解完全。先提 \(3\) 比較好做： \[\begin{aligned} & 3x^2 + 6x - 72 \\ &= 3(x^2 + 2x - 24) \\ &= 3(x - 4)(x + 6) \end{aligned}\] A 錯：展開是對的。
B 錯：\(3x - 12\) 還能提出 \(3\)。
C 錯：漏寫了 \(3\)，只剩原式的 \(\frac{1}{3}\)。

重點 9：兩個多項式的公因式——各自分解再比對

重點整理與敘述

  • 把兩個多項式各自因式分解，兩邊都出現的因式就是它們的公因式。
  • 例： \[\begin{aligned} x^2 + 2x - 15 &= (x - 3)(x + 5) \\ 2x^2 - 7x + 3 &= (x - 3)(2x - 1) \end{aligned}\] 兩邊都有 \(x - 3\)，所以 \(x - 3\) 是公因式。
  • 只出現在一邊的因式（例如 \(x + 5\)、\(2x - 1\)）不是公因式。
  • 注意正負號：\(x - 3\) 和 \(x + 3\) 是不同的因式，不能混用。
  • 也可以用 3-1 學過的長除法驗證：公因式能同時整除兩個多項式。

Q17. 有兩個多項式 \(M = x^2 + 3x - 28\)、\(N = 2x^2 - 5x - 12\)，下列何者是 \(M\) 與 \(N\) 的公因式？

解析：答案為 C。各自分解： \[\begin{aligned} M &= (x + 7)(x - 4) \\ N &= (x - 4)(2x + 3) \end{aligned}\] 兩邊都有 \(x - 4\)。
A 錯：\(x + 7\) 只是 \(M\) 的因式。
B 錯：\(2x + 3\) 只是 \(N\) 的因式。
D 錯：正負號不對，\(x + 4\) 兩邊都沒有。

Q18. 若 \(x^2 - 2x - 24\) 與 \(3x^2 + 13x + 4\) 的公因式為 \(x + a\)，則 \(a\) 之值為何？

解析：答案為 D。各自分解： \[\begin{aligned} & x^2 - 2x - 24 \\ &= (x + 4)(x - 6) \\[4pt] & 3x^2 + 13x + 4 \\ &= (x + 4)(3x + 1) \end{aligned}\] 公因式是 \(x + 4\)，所以 \(a = 4\)。
A 錯：\(x - 6\) 只是第一個式子的因式。
B 錯：第一個式子沒有 \(x + 6\) 這個因式。
C 錯：正負號弄反了。

重點 10：已知分解的形式，反求係數

重點整理與敘述

  • 題目給「\(ax^2 + bx + c = (\ldots)(\ldots)\)」而有些係數未知時，一樣看兩端、湊中間：
    • \(x^2\) 項係數 \(=\) 兩個 \(x\) 係數相乘；常數項 \(=\) 兩個常數相乘 → 先定出未知數。
    • \(x\) 項係數 \(=\) 交叉相乘的和 → 再算出中間的係數。
  • 例 1：\(x^2 + kx - 20 = (x - 4)(x + m)\)。常數項 \(-4m = -20\)，\(m = 5\)；中間 \(k = -4 + 5 = 1\)。
  • 例 2：\(10x^2 + 11x - 6\)\({}= (2x + a)(bx + c)\)。\(x^2\) 項 \(2b = 10\)，\(b = 5\)；再用十字交乘找出 \[\begin{aligned} & 10x^2 + 11x - 6 \\ &= (2x + 3)(5x - 2) \end{aligned}\] 所以 \(a = 3\)、\(c = -2\)。
  • 也可以直接把右邊整個乘開，三項係數一一比較。

Q19. 若 \(8x^2 - 2x - 15\) 可因式分解成 \((2x + a)(bx + c)\)，其中 \(a\)、\(b\)、\(c\) 均為整數，則 \(a + b + c\) 之值為何？

解析：答案為 B。\(x^2\) 項 \(2b = 8\)，\(b = 4\)。再用十字交乘：左欄 \(2x\)、\(4x\)，右欄上 \(-3\) 下 \(5\)，\(4x \cdot (-3) + 2x \cdot 5 = -2x\)，合： \[\begin{aligned} & 8x^2 - 2x - 15 \\ &= (2x - 3)(4x + 5) \end{aligned}\] 所以 \(a = -3\)、\(c = 5\)，\(a + b + c = -3 + 4 + 5 = 6\)。
A 錯：寫成 \((2x + 3)(4x - 5)\)，中間項是 \(+2x\)，符號放反。
C 錯：把 \(c\) 當成 \(-5\)，常數項會是 \(+15\)。
D 錯：忽略了 \(a\) 的負號。

Q20. 若 \(x^2 + kx - 39 = (x - 3)(x + m)\)，則 \(k\)、\(m\) 分別為何？

解析：答案為 A。看兩端：常數項 \(-3m = -39\)，\(m = 13\)；湊中間：\(k = -3 + 13 = 10\)。
B 錯：中間是 \(-3 + 13\)，不是 \(3 - 13\)。
C 錯：\((-3) \times (-13) = 39\)，常數項的號不對。
D 錯：\(m\) 的號不對，理由同 C。

重點 11：紙片拼長方形——藍色要幾張才拼得成

重點整理與敘述

  • 紅色紙片面積 \(x^2\)、藍色 \(x\)、黃色 \(1\)。紅、藍、黃各有 \(a\)、\(b\)、\(c\) 張時，面積總和是 \(ax^2 + bx + c\)。
  • 不裁剪、沒有剩下地拼成長方形，就是把 \(ax^2 + bx + c\) 分解成兩個一次式的乘積，長和寬就是兩個因式。
  • 紅、黃的張數固定時，把 \(a\)、\(c\) 的因數排進十字交乘，每一種排法的中間項，就是藍色可以有的張數。
  • 例：紅 \(2\) 張、黃 \(3\) 張。
    • \((x + 1)(2x + 3)\)：藍色要 \(2x + 3x = 5x\)，\(5\) 張。
    • \((x + 3)(2x + 1)\)：藍色要 \(6x + x = 7x\)，\(7\) 張。
    手上有 \(6\) 張藍色的話，再拿 \(1\) 張或退回 \(1\) 張都拼得成。
  • 一定要列完所有排法（含右欄上下對調），才不會漏掉答案。

Q21. 小萱拿了紅色 \(4\) 張、藍色 \(13\) 張、黃色 \(9\) 張（面積分別是 \(x^2\)、\(x\)、\(1\)）。下列敘述何者正確？

解析：答案為 A。面積總和是 \(4x^2 + 13x + 9\)。左欄 \(x\)、\(4x\)，右欄上 \(1\) 下 \(9\)：\(4x + 9x = 13x\)，合： \[\begin{aligned} & 4x^2 + 13x + 9 \\ &= (x + 1)(4x + 9) \end{aligned}\] B 錯：\((2x + 3)^2 = 4x^2 + 12x + 9\)，藍色要 \(12\) 張。
C 錯：能分解，就拼得成。
D 錯：\((x + 9)(4x + 1) = 4x^2 + 37x + 9\)，藍色要 \(37\) 張。

Q22. 小康拿了紅色 \(3\) 張、藍色 \(15\) 張、黃色 \(10\) 張，拼不成長方形。他想再向老師拿藍色紙片，最少要再拿幾張？

解析：答案為 B。面積是 \(3x^2 + bx + 10\)。左欄 \(x\)、\(3x\)，右欄的四種上下排法：
上 \(1\) 下 \(10\)：\(3x + 10x = 13x\)
上 \(10\) 下 \(1\)：\(30x + x = 31x\)
上 \(2\) 下 \(5\)：\(6x + 5x = 11x\)
上 \(5\) 下 \(2\)：\(15x + 2x = 17x\)
藍色可以是 \(11\)、\(13\)、\(17\)、\(31\) 張。手上有 \(15\) 張，比 \(15\) 多的最小一個是 \(17\)，所以最少再拿 \(2\) 張，拼成 \((x + 5)(3x + 2)\)。
A 錯：\(16\) 張拼不成。
C 錯：退回 \(4\) 張變成 \(11\) 張也拼得成，但題目是要再拿。
D 錯：拿到 \(31\) 張也可以，但不是最少。

小節總結與核心回顧

十字交乘速查表

  • 看兩端、湊中間：\(x^2 + px + q = (x + a)(x + b)\)，\(a + b = p\)、\(ab = q\)。
  • 常數項正：兩數同號，跟 \(x\) 項係數的號。
  • 常數項負：一正一負，先找差，大的跟 \(x\) 項係數的號。
  • 列完都不合：不能分解；缺 \(x\) 項當作 \(0x\)。
  • \(x^2\) 係數不為 \(1\)：左欄拆正因數，右欄上下對調都要試。
  • 差一個號：右欄兩數的正負對調。
  • \(x^2\) 係數為負：先提出 \(-1\)，負號不能丟。
  • 有公因數：先提出來，最後別漏寫。
  • 公因式：各自分解，再找兩邊都有的。
  • 反求係數：兩端定未知數，中間算係數。

回到色塊工作室：黃色怎麼排，就是十字交乘

黃色的方陣就是常數項的拆法

六塊黃色排成 \(1\) 乘 \(6\) 的長條，藍色要 \(7\) 條；排成 \(2\) 乘 \(3\) 的方陣，藍色要 \(5\) 條。手上剛好 \(5\) 條，所以 \(x^2 + 5x + 6\)\({}= (x + 2)(x + 3)\)。十字交乘的右欄，就是黃色方陣的兩個邊。

有系統地試

先用正負號縮小範圍，再一組一組列出來；找到一組就停，全部列完都不合就是不能分解。
