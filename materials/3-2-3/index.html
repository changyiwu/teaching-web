2-3 畢氏定理

回到磁磚工坊，這一節的主角是直角三角形。先認識斜邊與股，用方格和拼圖發現畢氏定理；再用它求直角三角形的第三邊、斜邊上的高、等腰與正三角形的高與面積；最後走進生活（螢幕尺寸、靠牆的梯子），以及直角坐標平面上兩點的距離。上一節的根式運算會一直用到。

名詞與方格 拼圖證明 求斜邊 求股 接力 斜邊上的高 等腰三角形 正三角形 複合圖形 對角線 梯子 同線兩點 距離公式

課前暖身漫畫：打了 12 個結的繩子

小瓷要在工坊的牆角鋪磁磚，可是牆角歪一點，整排磚就會越排越斜。阿岩拿出一條繩圈，上面等距打了 \(12\) 個結。兩人把繩圈拉成三段：\(3\) 格、\(4\) 格、\(5\) 格，拉直的瞬間，剛好出現一個直角。古埃及的操繩師就是這樣量土地的。為什麼偏偏是 \(3\)、\(4\)、\(5\)？這一節就來回答。

重點 1：斜邊與股——數方格發現 P + Q = R

重點整理與敘述

  • 直角三角形：有一個角是直角的三角形，例如一般的三角板。
  • 斜邊：直角對面的那一邊，是三邊中最長的。
  • 股：直角兩側的兩邊。
  • 等腰直角三角形：兩股一樣長的直角三角形。
  • 先找直角，再找斜邊：三角形轉了方向、字母換了名字都一樣。\(\angle C = 90^\circ\) 時斜邊是 \(\overline{AB}\)；\(\angle A = 90^\circ\) 時斜邊就變成 \(\overline{BC}\)。
  • 在方格紙上量面積：以三邊為邊長各畫一個正方形，兩股上的叫 P、Q，斜邊上的叫 R。
  • P、Q 是正放的，直接數格子；R 是斜放的，用外框正方形扣掉四個角落的直角三角形。
  • 例：兩股 \(3\)、\(4\) 時，P \(= 9\)、Q \(= 16\)；R 的外框邊長 \(3 + 4 = 7\)， \[\begin{aligned} & \text{R} = 7^2 - 4 \times \frac{1}{2} \times 3 \times 4 \\ &= 49 - 24 = 25 \end{aligned}\] 剛好 \(9 + 16 = 25\)：P + Q = R。

形成性評量 (斜邊與股)

Q1. 直角三角形 \(PQR\) 中，\(\angle Q = 90^\circ\)。下列敘述何者正確？

解析：答案為 A。直角是 \(\angle Q\)，它對面的邊是 \(\overline{PR}\)，所以 \(\overline{PR}\) 是斜邊；夾著 \(\angle Q\) 的 \(\overline{PQ}\)、\(\overline{QR}\) 是兩股。
B 錯：\(\overline{PQ}\) 夾著直角，是股。
C 錯：斜邊 \(\overline{PR}\) 才是最長的邊。
D 錯：\(\overline{PR}\) 是斜邊，兩股是 \(\overline{PQ}\) 與 \(\overline{QR}\)。

Q2. 在每小格面積為 \(1\) 的方格紙上，畫一個兩股長分別為 \(2\)、\(5\) 的直角三角形，並以斜邊為邊長畫正方形 R。用「外框正方形扣掉四個角落」的方法，R 的面積是多少？

解析：答案為 B。外框正方形的邊長是 \(2 + 5 = 7\)，四個角落各是一個兩股 \(2\)、\(5\) 的直角三角形： \[\begin{aligned} & 7^2 - 4 \times \frac{1}{2} \times 2 \times 5 \\ &= 49 - 20 = 29 \end{aligned}\] 也可以驗算：\(2^2 + 5^2 = 4 + 25 = 29\)。
A 錯：只算了外框，沒有扣掉四個角落。
C 錯：把兩股的長相加，那是外框的邊長，不是面積。
D 錯：只扣了 \(2 \times 5 = 10\)，等於只扣兩個三角形；四個三角形合起來是 \(20\)。

重點 2：畢氏定理——用四個三角形拼出來

重點整理與敘述

  • 拼圖：拿 \(4\) 個一模一樣、兩股為 \(a\)、\(b\)、斜邊為 \(c\) 的直角三角形，放進邊長 \(a + b\) 的大正方形。
  • 繞一圈擺好，中間空出的四邊形四邊都是 \(c\)、四個角都是直角，是邊長 \(c\) 的正方形： \[\begin{aligned} c^2 &= (a + b)^2 - 4 \times \frac{1}{2}ab \\ &= a^2 + 2ab + b^2 - 2ab \\ &= a^2 + b^2 \end{aligned}\]
  • 換一種擺法，兩兩拼成長方形，空出的是 \(a^2\) 和 \(b^2\) 兩塊。大正方形和四個三角形都沒變，留白一定一樣大。
KEY POINT　畢氏定理 設直角三角形斜邊長為 \(c\)，兩股長為 \(a\)、\(b\)，則 \[ c^2 = a^2 + b^2 \]
  • 它說的是面積：兩股上的正方形面積加起來，等於斜邊上的正方形面積；不是兩股的長加起來等於斜邊。
  • 只對直角三角形成立：沒有直角的三角形不能用。
  • 名稱：相傳由古希臘的畢達哥拉斯發現，所以叫畢氏定理。中國的《周髀算經》記載商高說「勾廣三，股修四，徑隅五」，所以也叫勾股定理或商高定理。

形成性評量 (畢氏定理)

Q3. 把 \(4\) 個兩股為 \(a\)、\(b\) 的相同直角三角形，繞一圈放進邊長 \(a + b\) 的正方形，中間空出一個正方形。這個中間正方形的面積可以寫成下列哪一個式子？

解析：答案為 D。每個三角形面積 \(\frac{1}{2}ab\)，四個合起來是 \(2ab\)，大正方形扣掉它們就是中間的正方形：\((a + b)^2 - 2ab\)，化簡後正是 \(a^2 + b^2\)。
A 錯：忘了三角形面積要乘 \(\frac{1}{2}\)，四個三角形算成 \(4ab\)。
B 錯：這是整個大正方形 \((a + b)^2\) 展開，沒有扣掉三角形。
C 錯：把四個三角形當成只拼得出一個 \(a \times b\) 的長方形；其實兩個三角形就拼成一個，四個是兩個長方形。

Q4. △ABC 是以 \(\overline{AC}\) 為斜邊的直角三角形，分別以 \(\overline{AB}\)、\(\overline{BC}\)、\(\overline{AC}\) 為邊長畫正方形甲、乙、丙。下列哪一個關係一定成立？

解析：答案為 C。設三邊為 \(a\)、\(b\)、\(c\)，\(a^2 + b^2 = c^2\)。周長是邊長的 \(4\) 倍： \[\begin{aligned} & (4a)^2 + (4b)^2 \\ &= 16(a^2 + b^2) = 16c^2 = (4c)^2 \end{aligned}\] A、D 錯：兩邊相加比第三邊長（以三邊 \(3\)、\(4\)、\(5\) 為例，\(3 + 4 = 7 \ne 5\)），周長也一樣。
B 錯：成立的是「面積相加」，面積再平方就不對了：\(9^2 + 16^2 = 337\)，\(25^2 = 625\)。

重點 3：已知兩股求斜邊——平方相加再開根號

重點整理與敘述

  • 三個步驟：① 列式 \(c^2 = a^2 + b^2\)　② 開平方 \(c = \pm\sqrt{a^2 + b^2}\)　③ 邊長是正數，負的捨去。
  • 例：兩股 \(2\)、\(3\)：\(c^2 = 4 + 9 = 13\)，\(c = \sqrt{13}\)。
  • 例：兩股 \(6\)、\(8\)：\(c^2 = 36 + 64 = 100\)，\(c = \sqrt{100} = 10\)。
  • 答案要化成最簡根式：例如 \(c^2 = 72\) 時，\(c = \sqrt{72} = 6\sqrt{2}\)。
  • 常見錯誤：把兩股直接相加當斜邊（\(2 + 3 \ne \sqrt{13}\)）；或算出 \(c^2\) 就停下來，忘了開根號。
常見的整數三邊（股、股、斜邊）驗算
\(3\)、\(4\)、\(5\)\(9 + 16 = 25\)
\(5\)、\(12\)、\(13\)\(25 + 144 = 169\)
\(8\)、\(15\)、\(17\)\(64 + 225 = 289\)
\(7\)、\(24\)、\(25\)\(49 + 576 = 625\)
  • 整數倍也成立：\(6\)、\(8\)、\(10\) 是 \(3\)、\(4\)、\(5\) 的 \(2\) 倍。
  • 反過來也對：三邊長滿足「兩邊平方和 ＝ 第三邊平方」的三角形，一定是直角三角形。操繩師的 \(3\)、\(4\)、\(5\) 繩圈拉得出直角，就是因為 \(3^2 + 4^2 = 5^2\)。

形成性評量 (求斜邊)

Q5. 直角三角形的兩股長分別為 \(9\) 和 \(40\)，斜邊長是多少？

解析：答案為 B。 \[\begin{aligned} c^2 &= 9^2 + 40^2 \\ &= 81 + 1600 = 1681 \end{aligned}\] \(c = \pm\sqrt{1681} = \pm 41\)，邊長取正，\(c = 41\)。
A 錯：把兩股直接相加。
C 錯：算出 \(c^2\) 就停了，忘了開根號。
D 錯：用減的，\(40^2 - 9^2 = 1519\)；兩股求斜邊要相加。

Q6. 直角三角形的兩股長分別為 \(5\) 和 \(15\)，斜邊長化成最簡根式是多少？

解析：答案為 A。 \[\begin{aligned} c^2 &= 5^2 + 15^2 \\ &= 25 + 225 = 250 \\ c &= \sqrt{250} \\ &= \sqrt{5^2 \times 10} = 5\sqrt{10} \end{aligned}\] B 錯：把兩股直接相加。
C 錯：\(250 = 25 \times 10\)，提到根號外的是 \(\sqrt{25} = 5\)，不是 \(25\)。
D 錯：用減的，\(15^2 - 5^2 = 200\)，\(\sqrt{200} = 10\sqrt{2}\)。

重點 4：求另一股——先確認誰是斜邊

重點整理與敘述

  • 已知斜邊 \(c\) 與一股 \(a\)：由 \(a^2 + b^2 = c^2\) 移項， \[ b^2 = c^2 - a^2 \] 是「斜邊平方減股平方」。
  • 例：斜邊 \(15\)、一股 \(9\)：\(b^2 = 225 - 81 = 144\)，\(b = 12\)。
  • 例：斜邊 \(10\)、一股 \(7\)：\(b^2 = 100 - 49 = 51\)，\(b = \sqrt{51}\)。
先判斷，再列式 第三邊是斜邊 → 兩股平方相加
第三邊是股 → 斜邊平方減股平方
  • 看圖找直角：直角對面的那一邊才是斜邊，跟它畫在哪裡、標什麼字母無關。
  • 沒有圖時，第三邊可能有兩種：「直角三角形的兩邊是 \(3\)、\(4\)」，第三邊不一定是 \(5\)。若 \(4\) 是斜邊，第三邊是 \(\sqrt{16 - 9} = \sqrt{7}\)。
  • 斜邊一定最長：算出來的股若比斜邊長，一定是加減用反了。

形成性評量 (求股)

Q7. 直角三角形的斜邊長為 \(25\)，一股長為 \(20\)，另一股長是多少？

解析：答案為 D。\(25\) 是斜邊，另一股用減的： \[\begin{aligned} b^2 &= 25^2 - 20^2 \\ &= 625 - 400 = 225 \end{aligned}\] \(b = \sqrt{225} = 15\)。
A 錯：把 \(25\) 也當成股，\(20^2 + 25^2 = 1025\)，\(\sqrt{1025} = 5\sqrt{41}\)，比斜邊還長。
B 錯：直接把兩邊相減，\(25 - 20 = 5\)。
C 錯：算出 \(b^2\) 就停了，忘了開根號。

Q8. 已知一個直角三角形有兩邊長分別為 \(9\) 和 \(16\)，但不知道哪一邊是斜邊。第三邊的長可能是多少？

解析：答案為 C。分兩種情形：
⑴ \(9\)、\(16\) 都是股，第三邊是斜邊：\(\sqrt{81 + 256} = \sqrt{337}\)。
⑵ \(16\) 是斜邊，第三邊是股：\(\sqrt{256 - 81} = \sqrt{175} = 5\sqrt{7}\)。
（\(9\) 不能當斜邊，因為斜邊要比股 \(16\) 長。）
A、B 錯：各漏了一種情形。
D 錯：直接把兩邊相減、相加，沒有用畢氏定理。

重點 5：兩個直角三角形接力——先求共用的那一邊

重點整理與敘述

  • 想求的邊所在的三角形資料不夠時，找出它和另一個直角三角形共用或接在一起的邊，先在另一個三角形把它求出來。
  • 例（D 在 BC 上）：\(\angle B = 90^\circ\)，\(\overline{AB} = 4\)、\(\overline{AD} = 5\)、\(\overline{DC} = 4\)，求 \(\overline{AC}\)。
    • ① 在 △ABD：\(\overline{BD}^2 = 5^2 - 4^2 = 9\)，\(\overline{BD} = 3\)。
    • ② 接起來：\(\overline{BC} = 3 + 4 = 7\)。
    • ③ 在 △ABC：\(\overline{AC}^2 = 4^2 + 7^2 = 65\)，\(\overline{AC} = \sqrt{65}\)。
  • 例（四邊形）：\(\angle A = \angle C = 90^\circ\)，\(\overline{AB} = 4\)、\(\overline{AD} = 5\)、\(\overline{BC} = 3\)。對角線 \(\overline{BD}\) 是兩個三角形共用的斜邊： \[\begin{aligned} \overline{BD}^2 &= 4^2 + 5^2 = 41 \\ \overline{CD}^2 &= 41 - 3^2 = 32 \end{aligned}\] 所以 \(\overline{CD} = \sqrt{32} = 4\sqrt{2}\)。
  • 小技巧：下一步要的若是 \(\overline{BD}^2\)，可以不必先開根號再平方回去。

形成性評量 (接力求邊長)

Q9. △ABC 中 \(\angle B = 90^\circ\)，D 在 \(\overline{BC}\) 上。已知 \(\overline{AB} = 15\)、\(\overline{AD} = 17\)、\(\overline{DC} = 12\)，求 \(\overline{AC}\)。

解析：答案為 A。先在 △ABD 求 \(\overline{BD}\)，再接成 \(\overline{BC}\)： \[\begin{aligned} \overline{BD}^2 &= 17^2 - 15^2 = 64 \\ \overline{BD} &= 8 \\ \overline{BC} &= 8 + 12 = 20 \\ \overline{AC}^2 &= 15^2 + 20^2 = 625 \end{aligned}\] 所以 \(\overline{AC} = 25\)。
B 錯：\(20\) 是 \(\overline{BC}\)，還要再用一次畢氏定理。
C 錯：把 \(\overline{DC}\) 當成 \(\overline{BC}\)，\(\sqrt{15^2 + 12^2} = \sqrt{369} = 3\sqrt{41}\)，漏了 \(\overline{BD}\)。
D 錯：\(17\) 是 \(\overline{AD}\)。

Q10. 四邊形 ABCD 中，\(\angle A = \angle C = 90^\circ\)，\(\overline{AB} = 9\)、\(\overline{AD} = 12\)、\(\overline{BC} = 12\)，求 \(\overline{CD}\)。

解析：答案為 C。對角線 \(\overline{BD}\) 是兩個直角三角形共用的斜邊： \[\begin{aligned} \overline{BD}^2 &= 9^2 + 12^2 = 225 \\ \overline{CD}^2 &= 225 - 12^2 = 81 \end{aligned}\] 所以 \(\overline{CD} = 9\)。
A 錯：在 △BCD 把 \(\overline{BD}\) 當成股，\(15^2 + 12^2 = 369\)；\(\angle C\) 是直角，\(\overline{BD}\) 是斜邊。
B 錯：直接相減 \(15 - 12 = 3\)，沒有平方。
D 錯：\(15\) 是 \(\overline{BD}\)，還沒算到 \(\overline{CD}\)。

重點 6：斜邊上的高——面積算兩次

重點整理與敘述

  • 同一個直角三角形，面積有兩種算法：
    • 兩股當底和高：\(\frac{1}{2} \times \overline{AB} \times \overline{BC}\)
    • 斜邊當底、斜邊上的高 \(\overline{BD}\) 當高：\(\frac{1}{2} \times \overline{AC} \times \overline{BD}\)
  • 兩個一定相等，所以 \[ \overline{BD} = \frac{\overline{AB} \times \overline{BC}}{\overline{AC}} \] 也就是斜邊上的高 ＝ 兩股相乘 ÷ 斜邊。
  • 步驟：先用畢氏定理求斜邊，再用面積求高。
  • 例：兩股 \(9\)、\(12\)：斜邊 \(\sqrt{81 + 144} = 15\)，高 \(= \frac{9 \times 12}{15} = \frac{36}{5}\)。
  • 斜邊是根式時，高要分母有理化：兩股 \(1\)、\(2\)，斜邊 \(\sqrt{5}\)，高 \(= \frac{2}{\sqrt{5}} = \frac{2\sqrt{5}}{5}\)。

形成性評量 (斜邊上的高)

Q11. 直角三角形的兩股長分別為 \(12\) 和 \(35\)，求斜邊上的高。

解析：答案為 B。斜邊 \(\sqrt{144 + 1225} = \sqrt{1369} = 37\)。設斜邊上的高為 \(h\)： \[\begin{aligned} \frac{1}{2} \times 12 \times 35 &= \frac{1}{2} \times 37 \times h \\ h &= \frac{420}{37} \end{aligned}\] A 錯：等號左邊乘了 \(\frac{1}{2}\)、右邊忘了乘，等於把面積 \(210\) 直接除以斜邊。
C 錯：斜邊上的高不是斜邊的一半。
D 錯：分母用了 \(12 + 35 = 47\)，要除的是斜邊 \(37\)。

Q12. 直角三角形的斜邊長為 \(13\)，一股長為 \(5\)，求斜邊上的高。

解析：答案為 D。先求另一股：\(\sqrt{169 - 25} = \sqrt{144} = 12\)。斜邊上的高 \[ h = \frac{5 \times 12}{13} = \frac{60}{13} \] A 錯：只用了面積 \(\frac{1}{2} \times 5 \times 12 = 30\)，忘了另一邊也有 \(\frac{1}{2}\)。
B 錯：把 \(13\) 當股、\(12\) 當斜邊來除，斜邊才是分母。
C 錯：\(6\) 是另一股 \(12\) 的一半，跟斜邊上的高無關。

重點 7：等腰三角形的高與面積——中點把底邊切一半

重點整理與敘述

  • 等腰三角形是線對稱圖形：取底邊 \(\overline{BC}\) 的中點 D，連 \(\overline{AD}\)。\(\overline{AD}\) 是對稱軸，也是 \(\overline{BC}\) 的中垂線，所以 \(\overline{AD} \perp \overline{BC}\)，\(\overline{AD}\) 就是底邊上的高。
  • 切出直角三角形 ABD：斜邊是腰，一股是底的一半，另一股就是高。
  • 例：\(\overline{AB} = \overline{AC} = 13\)，\(\overline{BC} = 10\)： \[\begin{aligned} \overline{BD} &= \frac{1}{2} \times 10 = 5 \\ \overline{AD}^2 &= 13^2 - 5^2 = 144 \\ \overline{AD} &= 12 \\ \text{面積} &= \frac{1}{2} \times 10 \times 12 \\ &= 60 \end{aligned}\]
  • 常見錯誤：用整條底邊 \(10\) 去減，或把腰當成高。直角三角形 ABD 的股是 \(5\)，不是 \(10\)。

Q13. 等腰三角形 ABC 中，\(\overline{AB} = \overline{AC} = 17\)，\(\overline{BC} = 16\)，求它的面積。

D 錯：底用了一半 \(8\)，又乘 \(\frac{1}{2}\)，切了兩次。

Q14. 等腰三角形 ABC 中，\(\overline{AB} = \overline{AC} = 11\)，\(\overline{BC} = 18\)，求它的面積。

解析：答案為 B。\(\overline{BD} = 9\)： \[\begin{aligned} \overline{AD}^2 &= 11^2 - 9^2 = 40 \\ \overline{AD} &= 2\sqrt{10} \\ \text{面積} &= \frac{1}{2} \times 18 \times 2\sqrt{10} \\ &= 18\sqrt{10} \end{aligned}\] A 錯：底用了一半 \(9\)，又乘 \(\frac{1}{2}\)。
C 錯：\(2\sqrt{10}\) 是高，題目問的是面積。
D 錯：忘了乘 \(\frac{1}{2}\)。

重點 8：正三角形的高與面積

重點整理與敘述

  • 正三角形也是等腰三角形：照重點 7 的方法，取底邊中點 D，\(\overline{AD}\) 是高。
  • 邊長 \(a\) 時，\(\overline{BD} = \frac{a}{2}\)： \[\begin{aligned} \overline{AD}^2 &= a^2 - \left(\frac{a}{2}\right)^2 = \frac{3}{4}a^2 \\ \overline{AD} &= \sqrt{\frac{3}{4}a^2} = \frac{\sqrt{3}}{2}a \end{aligned}\]
  • 面積 \(= \frac{1}{2} \times a \times \frac{\sqrt{3}}{2}a = \frac{\sqrt{3}}{4}a^2\)。
KEY POINT　正三角形 邊長為 \(a\) 的正三角形
高 \(= \frac{\sqrt{3}}{2}a\)，面積 \(= \frac{\sqrt{3}}{4}a^2\)
  • 例：邊長 \(8\)：高 \(= \frac{\sqrt{3}}{2} \times 8 = 4\sqrt{3}\)，面積 \(= \frac{\sqrt{3}}{4} \times 64 = 16\sqrt{3}\)。
  • 常見錯誤：面積公式的 \(a\) 忘了平方；或把高的 \(\frac{\sqrt{3}}{2}\) 和面積的 \(\frac{\sqrt{3}}{4}\) 用反。
  • 邊長是根式時，先算 \(a^2\)：\((k\sqrt{m})^2 = k^2 \times m\)，不要只平方前面的 \(k\)。

重點 9：複合圖形——正方形與正三角形拼起來

重點 10：長方形的對角線——螢幕尺寸怎麼算

重點整理與敘述

  • 一條對角線把長方形切成兩個直角三角形：長、寬是兩股，對角線是斜邊。 \[ \text{對角線} = \sqrt{\text{長}^2 + \text{寬}^2} \]
  • 螢幕的「尺寸」是對角線的長：例如長 \(6\) 吋、寬 \(3\) 吋的螢幕，尺寸是 \(\sqrt{36 + 9} = \sqrt{45} = 3\sqrt{5}\) 吋。
  • 正方形的對角線：邊長 \(s\) 時是 \(\sqrt{s^2 + s^2} = s\sqrt{2}\)，是邊長的 \(\sqrt{2}\) 倍。
  • 例：\(5\) 個邊長 \(2\) 的正方形連成帶子，每條對角線 \(2\sqrt{2}\)，接起來 \(10\sqrt{2} \approx 14\)（取 \(\sqrt{2} \approx 1.4\)）。
  • 比較兩個螢幕：各自算出對角線再相減。\(3\sqrt{5} - 3\sqrt{2}\) 不是同類方根，不能合併；要知道大約多少就用近似值。
  • 常見錯誤：把長和寬相加當成尺寸。

重點 11：梯子靠牆——移動前後各一個直角三角形

重點整理與敘述

  • 牆和地面垂直：梯子（竹竿）斜靠在牆上，牆、地面、梯子圍成直角三角形，梯子是斜邊。
  • 梯子長度不變：移動前、移動後是兩個不同的直角三角形，斜邊一樣長，各用一次畢氏定理。
  • 例：長 \(2.5\) 公尺的竹竿，底端離牆 \(1.5\) 公尺： \[\begin{aligned} \text{頂端高} &= \sqrt{2.5^2 - 1.5^2} \\ &= \sqrt{4} = 2 \end{aligned}\] 頂端往上移 \(0.4\) 公尺變成 \(2.4\)，底端離牆 \(\sqrt{2.5^2 - 2.4^2} = \sqrt{0.49} = 0.7\)，所以底端往牆移動了 \(1.5 - 0.7 = 0.8\) 公尺。
  • 上面移動多少 ≠ 下面移動多少：頂端移了 \(0.4\)，底端卻移了 \(0.8\)，一定要分開算。
  • 小技巧：小數或大數字的平方很麻煩時，可以先換單位（例：公尺換成公寸）。

Q21. 一把長 \(13\) 公尺的梯子斜靠在牆上，梯腳離牆腳 \(5\) 公尺。若梯頂沿著牆往下滑 \(7\) 公尺，梯腳會往外移動多少公尺？

Q22. 小翊把風箏線放到最長 \(65\) 公尺並拉直。第一次風箏離他的水平距離是 \(25\) 公尺，第二次是 \(39\) 公尺。不計小翊的身高，兩次風箏的高度相差多少公尺？

D 錯：\(60 + 52 = 112\)，要的是相差，不是相加。

重點 12：水平線、鉛垂線上兩點的距離

重點整理與敘述

  • 回顧數線：數線上 \(A(a)\)、\(B(b)\) 的距離是 \(\overline{AB} = |a - b|\)。
  • \(y\) 坐標相同 → 同一條水平線：距離是 \(x\) 坐標差的絕對值。\(A(x_1,\ p)\)、\(B(x_2,\ p)\) 的距離 \[ \overline{AB} = |x_1 - x_2| \]

重點 13：直角坐標平面上兩點的距離公式

KEY POINT　距離公式 \(A(x_1,\ y_1)\)、\(B(x_2,\ y_2)\) 的距離為 \[ \overline{AB} = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2} \]
  • 例：\(A(6,\ 4)\)、\(B(-3,\ -7)\) 的距離 \[\begin{aligned} & \sqrt{[6 - (-3)]^2 + [4 - (-7)]^2} \\ &= \sqrt{9^2 + 11^2} \\ &= \sqrt{81 + 121} = \sqrt{202} \end{aligned}\]

  • 同一條水平線、鉛垂線也適用：其中一項是 \(0\)，就回到重點 12。

小節總結與核心回顧

畢氏定理速查表

  • 名詞：直角對面是斜邊（最長），直角兩側是股。
  • 發現：兩股上的正方形面積和 ＝ 斜邊上的正方形面積。
  • 畢氏定理：\(c^2 = a^2 + b^2\)，只對直角三角形成立。
  • 求斜邊：兩股平方相加再開根號，邊長取正。
  • 求股：先確認斜邊，再用斜邊平方減股平方。
  • 接力：資料不夠就先求共用的邊。
  • 斜邊上的高：兩股相乘 ÷ 斜邊。
  • 等腰三角形：中點把底邊切一半，腰是斜邊。
  • 正三角形：高 \(\frac{\sqrt{3}}{2}a\)，面積 \(\frac{\sqrt{3}}{4}a^2\)。
  • 複合圖形：拆開各算再相加，整數和根式不能合併。
  • 對角線：\(\sqrt{\text{長}^2 + \text{寬}^2}\)；正方形是邊長的 \(\sqrt{2}\) 倍。
  • 梯子：梯長不變，移動前後各算一次。
  • 同線兩點：相同的坐標不管，另一個坐標差取絕對值。
  • 距離公式：\(\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}\)。

回到磁磚工坊：為什麼是 3、4、5？

三段繩子剛好滿足畢氏定理

\(12\) 個結把繩圈分成 \(12\) 等份，拉成 \(3\)、\(4\)、\(5\) 格三段，而 \(3^2 + 4^2 = 9 + 16 = 25 = 5^2\)。三邊滿足「兩邊平方和等於第三邊平方」的三角形一定是直角三角形，直角就在 \(5\) 那一段的對面。

換一組也可以

阿岩說，只要三段的長度滿足畢氏定理就行：\(5\)、\(12\)、\(13\) 格要 \(30\) 個結，\(6\)、\(8\)、\(10\) 格要 \(24\) 個結。結越多，量大面積時越準。
