1-1 連比例

老照相館的暗房裡，小影和阿光每天都要調顯影液：A 液、B 液、清水要照固定的比例倒。兩個量可以用「比」，三個以上的量一起比就叫做連比。這一節先學連比的寫法與化簡、怎麼把兩個比併成連比；再學連比例式 \(x : y : z = a : b : c\)，用「設 \(x = ar\)、\(y = br\)、\(z = cr\)」求未知數與新的連比；最後用連比解分配總量、兩根桿子重疊這類應用問題。

連比的意義 化簡連比 兩個比併連比 由 ax = by 求比 連比例式與設 r 求未知項 連等式與連比 代入求新連比 分配總量 重疊與串接

課前暖身漫畫：顯影液要倒多少？

顯影液的說明寫著「A 液、B 液、清水照 \(1 : 2 : 5\) 調配」，可是顯影盤要裝 \(2\) 公升，三種各要倒多少？小影把三個數加起來：一共 \(8\) 份，一份就是 \(250\) 毫升。三個以上的量一起比，就是連比——這一節就從這裡開始。

重點 1：連比的意義——三個量一起比

重點整理與敘述

  • 三個（或三個以上）的數連續的比，叫做連比，記作 \(a : b : c\)。
  • 顯影液用同一個量杯倒：A 液 \(3\) 杯、B 液 \(2\) 杯、清水 \(5\) 杯，A 液、B 液、清水杯數的連比就是 \(3 : 2 : 5\)。
  • 一個連比同時包含三組比：A 液 : B 液 \(= 3 : 2\)、B 液 : 清水 \(= 2 : 5\)、A 液 : 清水 \(= 3 : 5\)。
  • 連比要照題目說的順序寫，順序一換，連比就不同。
  • 連比只說三個量的倍數關係，不是實際的量：\(x : y : z = 3 : 2 : 5\) 並不代表 \(x = 3\)。
KEY POINT・連比與它包含的三組比 \(x : y : z = a : b : c\) \(\Rightarrow\) \(x : y = a : b\)、\(y : z = b : c\)、\(x : z = a : c\)

形成性評量 (連比的意義)

Q1. 小影用同一支量匙調藥水：A 液 \(6\) 匙、B 液 \(4\) 匙、清水 \(9\) 匙。下列敘述何者正確？

解析：答案為 B。A 液 : 清水 \(= 6 : 9\)，前後項同除以 \(3\)，得 \(2 : 3\)。
A 錯：\(6 : 4\) 是 A 液 : B 液。
C 錯：B 液 : 清水 \(= 4 : 9\)，前後項寫反了。
D 錯：連比要照「A 液、B 液、清水」的順序寫，是 \(6 : 4 : 9\)。

Q2. 照相館裡木框、鐵框、紙框三種相框的個數連比為 \(14 : 21 : 35\)。阿光說：「所以木框一定有 \(14\) 個。」下列何者正確？

解析：答案為 D。連比只說三個量的倍數關係。\(14 : 21 : 35\) 同除以 \(7\) 是 \(2 : 3 : 5\)，而 \(16 : 24 : 40\) 同除以 \(8\) 也是 \(2 : 3 : 5\)，所以兩者相等，木框可能是 \(16\) 個。
A 錯：連比的項不是實際個數，木框可以是 \(2\)、\(4\)、\(6\)、\(8\)、… 個。
B 錯：\(14\)、\(21\)、\(35\) 有公因數 \(7\)，不是最簡整數比；而且就算是最簡，也不代表實際個數。
C 錯：\(2\) 個只是其中一種可能，不是「一定」。

重點 2：同乘同除，連比不變——化成最簡整數比

重點整理與敘述

  • 連比的各項同乘以或同除以同一個不為 \(0\) 的數，連比不變。
  • 一份配方是 \(2 : 3 : 4\)，做 \(3\) 份是 \(6 : 9 : 12\)，做半份是 \(1 : 1.5 : 2\)，三個連比都相等。
  • 化成最簡整數比（各項都是整數、沒有共同的因數）：
    • 整數：同除以三數的最大公因數。\(18 : 24 : 30 = 3 : 4 : 5\)（同除以 \(6\)）。
    • 小數：先同乘以 \(10\)（或 \(100\)）去掉小數點，再約。\(0.4 : 1 : 1.4\)\({}= 4 : 10 : 14\)\({}= 2 : 5 : 7\)。
    • 分數：先同乘以分母的最小公倍數。\(\frac{1}{2} : \frac{2}{3} : \frac{3}{4}\) 同乘以 \(12\)，得 \(6 : 8 : 9\)。
  • 每一項都要乘（或除），只處理其中幾項，比就變了。
KEY POINT・連比的運算性質（m ≠ 0） \(a : b : c\)\({}= (a \times m) : (b \times m) : (c \times m)\)
\(a : b : c\)\({}= (a \div m) : (b \div m) : (c \div m)\)

形成性評量 (化簡連比)

Q3. 把 \(2.2 : 0.8 : 3\) 化成最簡整數比，結果是哪一個？

解析：答案為 A。三項同乘以 \(10\)：\(2.2 : 0.8 : 3 = 22 : 8 : 30\)；三數的最大公因數是 \(2\)，同除以 \(2\) 得 \(11 : 4 : 15\)。
B 錯：\(22\)、\(8\)、\(30\) 還有公因數 \(2\)，不是最簡。
C 錯：\(3\) 也要乘以 \(10\) 變成 \(30\)；只乘有小數點的項，比就變了。
D 錯：看成同除以 \(0.2\) 的話，\(3 \div 0.2 = 15\)，不是 \(1.5\)；而且最簡整數比的每一項都要是整數。

Q4. 把 \(\frac{2}{3} : \frac{3}{4} : \frac{5}{6}\) 化成最簡整數比，結果是哪一個？

解析：答案為 C。分母 \(3\)、\(4\)、\(6\) 的最小公倍數是 \(12\)，三項同乘以 \(12\)：

\[\begin{aligned} & \frac{2}{3} \times 12 : \frac{3}{4} \times 12 : \frac{5}{6} \times 12 \\ &= 8 : 9 : 10 \end{aligned}\]

A 錯：分母不同，不能只拿分子來比。
B 錯：也不能只拿分母來比。
D 錯：順序寫反了，第一項是 \(\frac{2}{3}\) 對應的 \(8\)。

重點 3：由兩個比求連比——把共同項對齊

重點整理與敘述

  • 已知 \(x : y\) 與 \(y : z\)，要併成 \(x : y : z\)，先找兩個比共同的那一項（這裡是 \(y\)）。
  • 共同項對應的數相同：直接併。\(x : y = 5 : 4\)、\(y : z = 4 : 9\) \(\Rightarrow\) \(x : y : z = 5 : 4 : 9\)。
  • 共同項對應的數不同：把它化成兩數的公倍數（通常取最小公倍數），兩個比各自同乘。
    • \(x : y = 2 : 3\)、\(y : z = 4 : 5\)：\(y\) 的 \(3\) 與 \(4\) 化成 \(12\)，得 \(8 : 12\) 與 \(12 : 15\)，所以 \(x : y : z = 8 : 12 : 15\)。
  • 共同項不一定在中間：\(x : z\) 與 \(y : z\) 的共同項是 \(z\)，\(x : y\) 與 \(x : z\) 的共同項是 \(x\)。列直式時，每個數都要對齊到自己的那一欄。
  • 常見錯誤：\(x : y = 2 : 3\)、\(y : z = 4 : 5\) 直接寫成 \(2 : 3 : 5\)——\(y\) 一下是 \(3\)、一下是 \(4\)，根本不是同一個標準。

視覺互動探索：直式對齊台

先選兩個比的共同項是哪一個，再調四個數。框起來的那一欄就是共同項：看兩列各要乘幾倍才對得齊。

Q5. 已知 \(x : z = 11 : 4\)、\(y : z = 3 : 10\)，則 \(x : y : z\) 的最簡整數比為何？

解析：答案為 D。共同項是 \(z\)，對應的數是 \(4\) 與 \(10\)，最小公倍數 \(20\)：\(x : z = 55 : 20\)（同乘 \(5\)）、\(y : z = 6 : 20\)（同乘 \(2\)），所以 \(x : y : z = 55 : 6 : 20\)。
A、B 錯：\(z\) 一下是 \(4\)、一下是 \(10\)，不能直接併。
C 錯：\(110 : 12 : 40\) 是把 \(z\) 化成 \(40\) 的結果，和答案相等，但三數還有公因數 \(2\)，不是最簡整數比。

Q6. 暗房櫃子裡原有大、中、小三種相紙，張數比為 \(8 : 9 : 6\)。小影沖洗相片後（沒有用到小張相紙），三種相紙的張數比變成 \(3 : 4 : 3\)。關於用掉的相紙，下列敘述何者正確？

解析：答案為 C。小張相紙沒用到，張數不變，它就是前後兩個連比的「共同項」。把後來的 \(3 : 4 : 3\) 同乘以 \(2\)，讓小張也是 \(6\)：

\[\begin{aligned} & \text{原來 } 8 : 9 : 6 \\ & \text{後來 } 6 : 8 : 6 \end{aligned}\]

大張少了 \(2\) 份、中張少了 \(1\) 份，兩種都用了，而且大張用得比較多。A、B、D 都不對。

重點 4：由 \(ax = by\) 求比——係數交叉對調

重點整理與敘述

  • 若 \(ax = by\)（\(a\)、\(b\)、\(x\)、\(y\) 皆不為 \(0\)），則 \(x : y = b : a\)：係數要交叉對調。
  • 理由：兩邊同除以 \(ab\)，得 \(\frac{x}{b} = \frac{y}{a}\)，也就是 \(x : b = y : a\)。
  • 例：\(3x = 5y\) \(\Rightarrow\) \(x : y = 5 : 3\)，不是 \(3 : 5\)。驗算：\(x = 5\)、\(y = 3\) 時 \(3 \times 5 = 5 \times 3\)。
  • 兩條關係式各化成一個比，再照重點 3 對齊共同項：\(3x = 5y\)、\(2y = 7z\) \(\Rightarrow\) \(x : y = 5 : 3\)、\(y : z = 7 : 2\)，\(y\) 化成 \(21\)，得 \(x : y : z = 35 : 21 : 6\)。
  • 題目若寫成 \(3x : 2y = 9 : 4\)，先用比例式「外項乘積＝內項乘積」化成 \(12x = 18y\)，再得 \(x : y = 18 : 12 = 3 : 2\)。
KEY POINT・係數交叉對調 \(ax = by\) \(\Rightarrow\) \(x : y = b : a\)

Q7. 設 \(x\)、\(y\)、\(z\) 皆不為 \(0\)，且 \(11x = 4y\)、\(3y = 8z\)，則 \(x : y : z\) 的最簡整數比為何？

解析：答案為 A。\(11x = 4y\) \(\Rightarrow\) \(x : y = 4 : 11\)；\(3y = 8z\) \(\Rightarrow\) \(y : z = 8 : 3\)。共同項 \(y\) 的 \(11\) 與 \(8\) 化成 \(88\)：\(x : y = 32 : 88\)、\(y : z = 88 : 33\)，所以 \(x : y : z = 32 : 88 : 33\)。
B 錯：係數沒有交叉對調，寫成 \(x : y = 11 : 4\)、\(y : z = 3 : 8\)，併出來是 \(33 : 12 : 32\)。
C 錯：\(y\) 一下是 \(11\)、一下是 \(8\)，不能直接併。
D 錯：\(y : z = 8 : 3\) 同乘 \(11\) 時，後項 \(3\) 也要乘成 \(33\)。

Q8. \(\triangle ABC\) 中，\(\angle A = x^\circ\)、\(\angle B = y^\circ\)、\(\angle C = z^\circ\)。若 \(3x = 2y\)、\(10y = 3z\)，下列敘述何者正確？

解析：答案為 B。\(3x = 2y\) \(\Rightarrow\) \(x : y = 2 : 3\)；\(10y = 3z\) \(\Rightarrow\) \(y : z = 3 : 10\)。\(y\) 都是 \(3\)，直接併成 \(x : y : z = 2 : 3 : 10\)，共 \(15\) 份。三角形內角和 \(180^\circ\)，一份是 \(12^\circ\)：\(\angle A = 24^\circ\)、\(\angle B = 36^\circ\)、\(\angle C = 120^\circ\)，是鈍角三角形。
A 錯：\(36^\circ\) 是 \(\angle B\)，\(\angle A = 24^\circ\)。
C 錯：\(24^\circ\) 是 \(\angle A\)，\(\angle B = 36^\circ\)。
D 錯：\(\angle C = 120^\circ\)。

重點 5：連比例式——設每一份是 \(r\)

重點整理與敘述

  • 像 \(x : y : z = 3 : 4 : 5\) 這樣的式子，叫做連比例式。
  • 若 \(x : y : z = a : b : c\)（\(a\)、\(b\)、\(c\) 皆不為 \(0\)），則 \(\frac{x}{a} = \frac{y}{b} = \frac{z}{c}\)，也可以寫成 \(x : a = y : b = z : c\)。
  • 這個共同的值就是「一份」，可設 \(x = ar\)、\(y = br\)、\(z = cr\)（\(r \ne 0\)）。
  • 例：顯影液的 A 液 : B 液 : 清水 \(= 2 : 3 : 5\)，清水用了 \(400\) 毫升。設三者為 \(2r\)、\(3r\)、\(5r\)，由 \(5r = 400\) 得 \(r = 80\)，A 液 \(160\) 毫升、B 液 \(240\) 毫升。
  • 連比的關係是「乘」不是「加」：\(x\) 由 \(2\) 變成 \(4\)（變 \(2\) 倍），\(y\) 也要由 \(3\) 變成 \(6\)，而不是 \(3 + 2 = 5\)。
KEY POINT・連比例式的運算性質 \(x : y : z = a : b : c\) \(\Rightarrow\) \(\frac{x}{a} = \frac{y}{b} = \frac{z}{c}\)
可設 \(x = ar\)、\(y = br\)、\(z = cr\)（\(r \ne 0\)）

視覺互動探索：一份是多少

顯影液的 A 液 : B 液 : 清水 \(= a : b : c\)，每一小格都是一份 \(r\)。選哪一樣是已知的、它用了多少毫升，看一份 \(r\) 是多少、另外兩樣又是多少。

形成性評量 (連比例式與設 r)

Q9. 設 \(x : y : z = 11 : 4 : 3\)，且 \(y = 8\)，則 \(x + z\) 的值為何？

解析：答案為 C。設 \(x = 11r\)、\(y = 4r\)、\(z = 3r\)。由 \(4r = 8\) 得 \(r = 2\)，所以 \(x = 22\)、\(z = 6\)，\(x + z = 28\)。
A 錯：\(22\) 只是 \(x\)。
B 錯：把 \(y = 8\) 當成一份 \(r\)，算成 \((11 + 3) \times 8\)。
D 錯：\(14\) 是 \(x + z\) 的份數，還要乘以一份 \(r = 2\)。

Q10. 若 \(x : y : z = 3 : 8 : 5\)，下列哪一個敘述正確？

解析：答案為 A。連比例式的性質：\(x : y : z = 3 : 8 : 5\) \(\Rightarrow\) \(\frac{x}{3} = \frac{y}{8} = \frac{z}{5}\)。
B 錯：\(x : z = 3 : 5\)，前後項寫反了。
C 錯：\(x\) 由 \(3\) 變 \(6\) 是變成 \(2\) 倍，\(y\) 也要變成 \(8 \times 2 = 16\)；\(8 + 3 = 11\) 是把「乘」當成「加」。
D 錯：設 \(x = 3r\)、\(y = 8r\)，\(y - x = 5r\)，要看 \(r\) 是多少，不一定是 \(5\)。

重點 6：求連比例式的未知項——拆成兩個比例式

重點整理與敘述

  • 兩個連比相等、其中一邊有未知數，例如 \(6 : x : y = 4 : 10 : 7\)。
  • 做法：拿已知的那一項分別和每個未知項配成兩項的比例式，再用「外項乘積＝內項乘積」。
    • \(6 : x = 4 : 10\) \(\Rightarrow\) \(4x = 60\)，\(x = 15\)。
    • \(6 : y = 4 : 7\) \(\Rightarrow\) \(4y = 42\)，\(y = \frac{21}{2}\)。
  • 另一種寫法：\(6 : 4 = x : 10 = y : 7\)，也就是每一項和它對應的數比起來都一樣（重點 5 的 \(x : a = y : b = z : c\)）。
  • 注意：「外項乘積＝內項乘積」只能用在兩項的比例式，三項的連比例式要先拆開（見重點 7）。
KEY POINT・拆成比例式 \(p : x : y = a : b : c\) \(\Rightarrow\) \(p : x = a : b\)，\(p : y = a : c\)

Q11. 若 \(x : 21 : y = 4 : 3 : 11\)，則 \(x\)、\(y\) 的值為何？

解析：答案為 B。拆成兩個比例式：\(x : 21 = 4 : 3\) \(\Rightarrow\) \(3x = 84\)，\(x = 28\)；\(21 : y = 3 : 11\) \(\Rightarrow\) \(3y = 231\)，\(y = 77\)。
A 錯：\(21 : y = 3 : 11\) 的外項是 \(21\) 與 \(11\)、內項是 \(y\) 與 \(3\)，寫成 \(11y = 63\) 就配錯了。
C 錯：\(x : 21 = 4 : 3\) 寫成 \(4x = 63\) 也是配錯。
D 錯：把 \(21\) 當成一份 \(r\)；一份其實是 \(21 \div 3 = 7\)。

Q12. 若 \(\frac{1}{2} : \frac{1}{3} : \frac{1}{5} = x : 4 : y\)，則 \(x\)、\(y\) 的值為何？

解析：答案為 D。先化簡左邊：同乘以 \(30\)，\(\frac{1}{2} : \frac{1}{3} : \frac{1}{5} = 15 : 10 : 6\)，所以 \(15 : 10 : 6 = x : 4 : y\)。

\[\begin{aligned} & 15 : 10 = x : 4 \\ & \Rightarrow 10x = 60,\ x = 6 \\ & 10 : 6 = 4 : y \\ & \Rightarrow 10y = 24,\ y = \frac{12}{5} \end{aligned}\]

A 錯：把「外項乘積＝內項乘積」做成「前項乘前項」：\(\frac{1}{2}x = \frac{1}{3} \times 4\) 得 \(\frac{8}{3}\)，\(\frac{1}{3} \times 4 = \frac{1}{5}y\) 得 \(\frac{20}{3}\)。
B、C 錯：各有一個未知數配錯了項。

重點 7：\(ax = by = cz\) 與連比不是同一回事

重點整理與敘述

  • 若 \(ax = by = cz\)（各數皆不為 \(0\)），設這個共同的值是 \(k\)，則 \(x = \frac{k}{a}\)、\(y = \frac{k}{b}\)、\(z = \frac{k}{c}\)，所以 \(x : y : z = \frac{1}{a} : \frac{1}{b} : \frac{1}{c}\)，再同乘以 \(a\)、\(b\)、\(c\) 的最小公倍數化成整數比。
  • 例：\(3x = 4y = 6z\) \(\Rightarrow\) \(x : y : z = \frac{1}{3} : \frac{1}{4} : \frac{1}{6}\)，同乘以 \(12\) 得 \(4 : 3 : 2\)——不是 \(3 : 4 : 6\)。係數越大，那個數反而越小。
  • 反過來，\(x : y : z = 3 : 4 : 6\) 推不出 \(3x = 4y = 6z\)：設 \(x = 3r\)、\(y = 4r\)、\(z = 6r\)，得 \(9r\)、\(16r\)、\(36r\)，三者不相等。
  • 正確的寫法是 \(\frac{x}{3} = \frac{y}{4} = \frac{z}{6}\)，同乘以 \(12\) 得 \(4x = 3y = 2z\)。
  • 比例式的「外項乘積＝內項乘積」只能用在兩項的比例式，不能直接搬到三項的連比例式上。
KEY POINT・連等式化成連比 \(ax = by = cz\) \(\Rightarrow\) \(x : y : z = \frac{1}{a} : \frac{1}{b} : \frac{1}{c}\)

視覺互動探索：面積一樣的三張相紙

\(ax\) 就像一張寬 \(a\)、高 \(x\) 的長方形相紙的面積。選方向，調三個係數：「\(ax = by = cz\)」時三張面積相等，寬的那張就比較矮；「已知連比」時三張的面積就不一樣了。

形成性評量 (連等式與連比)

Q13. 設 \(x\)、\(y\)、\(z\) 皆不為 \(0\)，且 \(8x = 6y = 9z\)，則 \(x : y : z\) 的最簡整數比為何？

解析：答案為 C。\(x : y : z = \frac{1}{8} : \frac{1}{6} : \frac{1}{9}\)，\(8\)、\(6\)、\(9\) 的最小公倍數是 \(72\)，同乘以 \(72\) 得 \(9 : 12 : 8\)。驗算：\(8 \times 9 = 6 \times 12 = 9 \times 8 = 72\)。
A 錯：把係數直接當成連比；係數越大的那個數反而越小。
B 錯：\(12\) 是 \(y\) 對應的數，順序放錯了。
D 錯：\(8 \times 9 = 72\)、\(6 \times 6 = 36\)，兩者不相等。

Q14. 若 \(x : y : z = 2 : 7 : 8\)，下列哪一個等式一定成立？

解析：答案為 A。設 \(x = 2r\)、\(y = 7r\)、\(z = 8r\)，逐一代入：

\[\begin{aligned} & \text{A：} 56r,\ 56r,\ 56r \\ & \text{B：} 4r,\ 49r,\ 64r \\ & \text{C：} \frac{1}{4}r,\ r,\ 4r \\ & \text{D：} 16r,\ 49r,\ 16r \end{aligned}\]

只有 A 三者相等。A 其實就是 \(\frac{x}{2} = \frac{y}{7} = \frac{z}{8}\) 同乘以 \(56\)。B 把連比的數直接當係數，正是重點 7 提醒的錯誤。

重點 8：設 \(r\) 代入，求新的連比

重點整理與敘述

  • 已知 \(x : y : z\)，要求 \(3x : 2y : z\) 或 \((x + y) : (y - z) : z\) 這類新的連比：設 \(x = ar\)、\(y = br\)、\(z = cr\) 代進去，整理後約掉 \(r\)。
  • 例：\(x : y : z = 5 : 3 : 2\)，設 \(x = 5r\)、\(y = 3r\)、\(z = 2r\)：
    • \(3x : 2y : z\)\({}= 15r : 6r : 2r\)\({}= 15 : 6 : 2\)。
    • \((x - y) : (y - z) : (x + z)\)\({}= 2r : r : 7r\)\({}= 2 : 1 : 7\)。
  • 題目只給兩個比時，先照重點 3 併成連比，再設 \(r\)。
  • 算出負數也照樣寫成連比，負數加括號，例如 \(3 : (-2) : (-1)\)。
  • 不可以把 \(x\)、\(y\)、\(z\) 直接換成連比裡的數就當作答案的「實際值」；設 \(r\) 是為了最後能整個約掉。

形成性評量 (代入求新的連比)

Q15. 設 \(x : y : z = 2 : 7 : 4\)，則 \((3x - y + z) : (x + y - z)\) 的最簡整數比為何？

解析：答案為 B。設 \(x = 2r\)、\(y = 7r\)、\(z = 4r\)：

\[\begin{aligned} & (3x - y + z) : (x + y - z) \\ &= (6r - 7r + 4r) \\ & \quad : (2r + 7r - 4r) \\ &= 3r : 5r = 3 : 5 \end{aligned}\]

A 錯：前後項寫反了。
C 錯：後項把 \(-z\) 當成 \(+z\)，算成 \(2r + 7r + 4r = 13r\)。
D 錯：把所有減號都當成加號，算成 \(17r : 13r\)。

Q16. 已知 \(x : y = 5 : 12\)、\(y : z = 4 : 3\)，則 \(2x : y : 3z\) 的最簡整數比為何？

解析：答案為 D。先併連比：\(y\) 的 \(12\) 與 \(4\) 化成 \(12\)，\(y : z = 12 : 9\)，所以 \(x : y : z = 5 : 12 : 9\)。設 \(x = 5r\)、\(y = 12r\)、\(z = 9r\)：\(2x : y : 3z\)\({}= 10r : 12r : 27r\)\({}= 10 : 12 : 27\)。
A 錯：那只是 \(x : y : z\)，還沒乘上係數。
B 錯：只把 \(x\) 乘了 \(2\)，\(3z\) 漏乘 \(3\)。
C 錯：\(y\) 沒有對齊，直接拿 \(y : z = 4 : 3\) 的 \(4\) 與 \(3\) 來用。

重點 9：應用（一）依連比分配總量

重點整理與敘述

  • 總量 \(T\) 依 \(a : b : c\) 分成三份，有兩種解法，挑自己熟的用：
    • 解法一（設 \(r\)）：三份是 \(ar\)、\(br\)、\(cr\)，由 \(ar + br + cr = T\) 解出 \(r\)。
    • 解法二（占總量的幾分之幾）：第一份占 \(\frac{a}{a + b + c}\)，是 \(T \times \frac{a}{a + b + c}\)。
  • 例：三人沖洗相片共付 \(840\) 元，金額比 \(2 : 5 : 7\)。共 \(14\) 份，一份 \(60\) 元，三人各付 \(120\)、\(300\)、\(420\) 元。
  • 三角形三內角的比、三人的錢數比……只要知道「總和」，都是同一種題型。
  • 如果總量不是三項直接相加（例如每一張大相片要用 \(3\) 個夾子），列式時要把每一項乘上各自的用量再相加。
KEY POINT・依連比分配 \(ar + br + cr = T\) \(\Rightarrow\) \(r = \frac{T}{a + b + c}\)

Q17. 照相館把大、中、小三種相片晾起來，張數比為 \(2 : 3 : 10\)。大張每張用 \(3\) 個夾子、中張每張用 \(2\) 個夾子，小張用磁鐵吸在板子上、不用夾子。若一共用了 \(96\) 個夾子，小張相片有幾張？

解析：答案為 B。設大、中、小分別有 \(2r\)、\(3r\)、\(10r\) 張。夾子數是 \(3 \times 2r + 2 \times 3r = 12r = 96\)，\(r = 8\)，小張有 \(10r = 80\) 張。
A 錯：\(16\) 是大張的張數。
C 錯：把 \(96\) 個夾子直接照張數比分，\(96 \times \frac{10}{15} = 64\)；可是小張根本不用夾子。
D 錯：\(48\) 是中張用掉的夾子數。

Q18. 小影、阿光和老闆合買一批底片，共付 \(1260\) 元，三人所付金額的比為 \(3 : 4 : 11\)。老闆比小影多付多少元？

解析：答案為 A。共 \(3 + 4 + 11 = 18\) 份，一份 \(1260 \div 18 = 70\) 元。小影付 \(210\) 元、老闆付 \(770\) 元，老闆多付 \((11 - 3) \times 70 = 560\) 元。
B 錯：\(770\) 是老闆付的錢，題目問的是「多付多少」。
C 錯：\(490\) 是老闆比阿光多付的錢。
D 錯：\(280\) 是阿光付的錢。

重點 10：應用（二）兩根桿子重疊——以重疊的那段為共同項

重點整理與敘述

  • 兩根桿子部分重疊接成一根：上面那根是 \(\overline{AC}\)、下面那根是 \(\overline{BD}\)，重疊的部分是 \(\overline{BC}\)。
  • 已知 \(\overline{AB} : \overline{BC}\) 與 \(\overline{BC} : \overline{CD}\)：以 \(\overline{BC}\) 為共同項，照重點 3 併成 \(\overline{AB} : \overline{BC} : \overline{CD}\)，再照重點 9 依全長 \(\overline{AD}\) 分配。
  • 上面那根 \(= \overline{AB} + \overline{BC}\)，下面那根 \(= \overline{BC} + \overline{CD}\)；\(\overline{BC}\) 兩根都有，但全長 \(\overline{AD}\) 裡只算一次。
  • 例：\(\overline{AB} : \overline{BC} = 4 : 1\)、\(\overline{BC} : \overline{CD} = 2 : 3\)、全長 \(130\) 公分。\(\overline{BC}\) 化成 \(2\)，得 \(8 : 2 : 3\)，共 \(13\) 份，一份 \(10\) 公分：上面那根 \(100\) 公分、下面那根 \(50\) 公分。
  • 伸縮的桿子（摺疊傘、三腳架）收到最短時，短的那一節整個縮進長的那一節，全長只剩比較長的那一節。

Q19. 小影把兩根木條部分重疊綁成一根長竿 \(\overline{AD}\)，長 \(190\) 公分。上面那根是 \(\overline{AC}\)，下面那根是 \(\overline{BD}\)，重疊的部分是 \(\overline{BC}\)。若 \(\overline{AB} : \overline{BC} = 11 : 2\)、\(\overline{BC} : \overline{CD} = 1 : 3\)，下面那根木條 \(\overline{BD}\) 長多少公分？

解析：答案為 D。共同項 \(\overline{BC}\) 的 \(2\) 與 \(1\) 化成 \(2\)：\(\overline{BC} : \overline{CD} = 2 : 6\)，所以 \(\overline{AB} : \overline{BC} : \overline{CD} = 11 : 2 : 6\)，共 \(19\) 份，一份 \(10\) 公分。\(\overline{BD} = (2 + 6) \times 10 = 80\) 公分。
A 錯：\(110\) 公分是 \(\overline{AB}\)。
B 錯：\(130\) 公分是上面那根 \(\overline{AC}\)。
C 錯：\(60\) 公分是 \(\overline{CD}\)，漏了重疊的 \(\overline{BC}\)。

Q20. 阿光的三腳架有一隻腳，拉到最長時 \(\overline{AD} = 105\) 公分，上節是 \(\overline{AC}\)、下節是 \(\overline{BD}\)，重疊的部分是 \(\overline{BC}\)，且 \(\overline{AB} : \overline{BC} = 7 : 2\)、\(\overline{BC} : \overline{CD} = 1 : 6\)。把下節往上推，直到 \(B\) 點碰到 \(A\) 點（收到最短），這隻腳變成多長？

解析：答案為 C。\(\overline{BC}\) 的 \(2\) 與 \(1\) 化成 \(2\)：\(\overline{AB} : \overline{BC} : \overline{CD} = 7 : 2 : 12\)，共 \(21\) 份，一份 \(5\) 公分：\(\overline{AB} = 35\)、\(\overline{BC} = 10\)、\(\overline{CD} = 60\)。上節 \(\overline{AC} = 45\) 公分，下節 \(\overline{BD} = 70\) 公分。\(B\) 推到 \(A\) 時，兩節的上端對齊，較短的上節整段和下節重疊，全長就是較長的下節 \(\overline{BD} = 70\) 公分。
A 錯：\(35\) 公分是 \(\overline{AB}\)，也就是縮短的長度。
B 錯：\(45\) 公分是上節，比下節短，縮進去後露在外面的是下節。
D 錯：\(60\) 公分是 \(\overline{CD}\)，漏了 \(\overline{BC}\)。

小節總結與核心回顧

連比例速查表

  • 連比：三個以上的數連續的比，只表示倍數關係；同乘、同除一個不為 \(0\) 的數，連比不變。
  • 化簡：小數先乘 \(10\)、分數先乘分母的最小公倍數，再同除以最大公因數。
  • 兩個比併連比：找共同項，化成最小公倍數後對齊。
  • \(ax = by\) \(\Rightarrow\) \(x : y = b : a\)（係數交叉對調）。
  • 連比例式：\(x : y : z = a : b : c\) \(\Rightarrow\) \(\frac{x}{a} = \frac{y}{b} = \frac{z}{c}\)，可設 \(x = ar\)、\(y = br\)、\(z = cr\)。
  • \(ax = by = cz\) \(\Rightarrow\) \(x : y : z = \frac{1}{a} : \frac{1}{b} : \frac{1}{c}\)；反過來不能直接把連比的數當係數。
  • 應用：設 \(r\) 列方程式，或用「占總量的幾分之幾」。

回到暗房：調一整盤顯影液

先看清楚是哪一種比

舊說明書寫「A 液 : B 液 \(= 1 : 2\)、B 液 : 清水 \(= 3 : 8\)」，兩個比的 B 液對不上。小影把 B 液都化成 \(6\)，得到 A 液 : B 液 : 清水 \(= 3 : 6 : 16\)，才敢開始倒。

一份是多少

顯影盤要裝 \(1250\) 毫升：共 \(25\) 份，一份 \(50\) 毫升，A 液 \(150\)、B 液 \(300\)、清水 \(800\) 毫升。阿光倒完，三個量筒的液面高度剛好排成 \(3 : 6 : 16\)。
