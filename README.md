# 課堂教學整合網 (Smart Classroom Portal)

專為中小學課堂教學設計的高效、美觀且具備高度自訂性的靜態網頁整合門戶。適合投影於教室大螢幕智慧觸控白板、平板或個人電腦使用。

## 🌟 核心特色

1. **整合式教學資源與課堂工具**
   - **常用教學資源**：內建三大教科書平台快速連結（**康軒數位高手**、**翰林行動大師**、**南一數位資源入口網**）。
   - **課堂工具**：整合實用互動工具（**班級工具**、**課堂表現登記系統**與**線上文字雲**）。
   - 所有連結均於新分頁開啟，不會覆蓋教學網頁主介面。

2. **第 1 至 6 冊教學資料分頁（高度自訂）**
   - 依學期分為第一冊至第六冊，分頁切換流暢。
   - **跨冊搜尋與狀態篩選**：輸入單元名稱或代號（例如「畢氏」、「2-3」）即可跨 6 冊搜尋 58 個小節，並可只看「已完成」或「待施工」。
   - **自訂書籤功能**：每一冊下方都有「新增連結」卡片，可儲存自訂的 Google Drive、網頁連結或教案路徑，透過瀏覽器 `localStorage` 永久儲存，滑鼠移到卡片上可刪除。

3. **課堂專用數位時鐘**
   - 頁首醒目的即時時鐘，顯示時、分、秒，並提供完整的年月日與星期幾資訊，方便掌控課堂進度。

4. **隨堂備忘錄**
   - 提供教師隨手記錄課堂聯絡簿、待辦事項或下堂課進度。
   - 具備自動儲存機制（Auto-save to LocalStorage），打字即存，重啟網頁或重新開機資料皆不會遺失。

5. **極致美學視覺**
   - 使用 Outfit 與 Noto Sans TC 精緻字型。
   - 採用磨砂玻璃視覺風格（Glassmorphic UI）及流暢的懸停發光微粒子效果，大螢幕呈現質感極佳。

6. **課堂畫筆（螢幕標註）**
   - 右下角浮動筆尖按鈕開啟，可直接在網頁上圈重點、畫線、標註。
   - 工具：**畫筆 / 螢光筆 / 橡皮擦**、6 種高對比顏色、3 段筆寬、復原、全部清除、下載標註圖片。
   - 以 Pointer Events 實作，滑鼠、觸控與觸控筆通用，並修正高解析度（Retina／4K 智慧白板）落筆偏移。
   - 快捷鍵：`S` 捲動、`P` 畫筆、`H` 螢光筆、`E` 橡皮擦、`Ctrl+Z` 復原、`C` 清除、`Esc` 結束（在備忘錄輸入時不會誤觸）。
   - 標註以整頁座標保存，捲動頁面時筆跡跟著內容移動；切到「捲動模式」即可邊捲動邊保留標註。
   - 主網頁與各小節教材頁共用同一組 `annotate.css` / `annotate.js`。

7. **動態課程資料庫與 Canvas 互動教材**
   - **動態課程選擇器**：動態載入國中 6 冊完整 58 個小節課程資料庫，並提供對應的狀態標記（已完成 / 待施工）。
   - **課堂工具隨處可用**：課堂工具側邊欄與課堂畫筆在首頁與 58 個小節頁面都能直接叫出，教材頁另有「上一節 / 下一節」導覽。
   - **1-1-1 負數與數線互動網頁**：內嵌溫度計、數線坐標、相反數鏡像、絕對值距離 4 個 HTML5 Canvas 視覺探索元件（均完成 Retina 觸碰焦點偏位修正），並提供 9 題附詳解的形成性評量與超萌水豚（卡皮巴拉）手繪插圖。
   - **1-1-2 整數的加減互動網頁**：同樣具備課前暖身漫畫、Canvas 互動與形成性評量。
   - **自動化佔位結構**：其餘 56 個小節皆已生成「施工中」預留網頁，共用 `materials/pending.css`。

## 🚀 如何使用與部署

### 本地直接執行
直接於瀏覽器中開啟 [index.html](index.html) 即可開始使用。

### 線上網址（GitHub Pages）
本專案已啟用 GitHub Pages 分支部署，**push 到 `main` 分支即自動發布**，約 1 分鐘後生效：

- 網址：<https://changyiwu.github.io/teaching-web/>
- 部署來源：`main` 分支根目錄（Settings → Pages 設定，採 classic 分支部署，因此沒有 `.github/workflows` 檔案）

> 備忘錄與自訂連結存在瀏覽器的 `localStorage`，屬於「該裝置該瀏覽器」的資料，不會跨裝置同步；換電腦或換瀏覽器要重新設定。
